# 设计

手机顶部沿用单行 Header、当前会话身份、状态点和更多入口。页面导航仍在「会话工具 → 工作与进度」，会话选择仍在右上角会话列表，不另建工作空间选择器。

## 标题交互（2026-11-03）

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01，无例外。主对象为当前 session ID；重命名复用现有 renameSessionOptimistically 和服务端标题接口，模式复用原 ChatControlModePicker 与账号权限，不新增数据源、页面或业务接口。

- 点击标题直接进入原行内编辑框，选中原标题；Enter 或失焦保存，Escape 取消，中文输入法组合确认不提交。空白或未变化标题不写入。桌面标题也支持单击与键盘激活。
- 手机长按 500ms 打开模式浮层，仅展示原模式选项与当前会话/连接信息；移除「切换工作空间」。长按后的合成 click 被消费，不能同时进入重命名；下一次正常点击仍可重命名。
- 移动超过 8px、指针取消、离开按钮、进入桌面断点和组件卸载均取消待触发长按。仅标题禁用原生长按菜单，不禁止系统页面缩放。键盘 Shift+F10 / 菜单键或上下文菜单可打开同一模式浮层；Enter / Space 保持普通点击改名语义。
- 模式浮层沿用 Radix Popover、原模式权限与回调；选择当前模式仅关闭，变更模式仍由原能力承担。Escape、外部点击或选择后关闭并恢复标题焦点；进入桌面关闭手机浮层。无会话时不执行标题写入。
- 移除「会话与分享」中的重复「重命名会话」入口；会话列表内的行重命名仍保留。原分屏和专注模式标题不改变。

## 上下文与结果

编辑开始时固定会话 ID 与原标题，保存时再次核对对象。会话切换取消编辑；Enter 与失焦通过同一编辑目标消费，避免重复写入。异步失败只显示在原会话，沿用已有乐观更新回滚，点击标题可重新编辑；不自动重放未知结果。保存或取消恢复到标题按钮，不改变输入草稿、消息流与正在运行的任务。

## 验证边界

复用并更新 MobileWorkspaceSwitcher、模式权限及 ChatPage 现有用例，覆盖短按/长按互斥、移动取消、模式选择、焦点、断点、改名取消/保存/失败/输入法，以及会话列表和草稿恢复。受上轮菜单收敛影响的旧用例改用仍保留的执行轨迹入口，不重新引入已删除的用量入口。类型检查及质量门禁；生产资源由既有自动构建器生成，交付时独立核对运行版本、HTTP 与稳定观察。实际浏览器未执行时明确标记，既往浏览器记录不能代替本次交互验收。本次无 AI 编程架构契约影响，不执行服务重启。
