## 业务定义

**修订版PRD** = 针对一份已存在的PRD发起的二次修订产出。与首次生成的PRD相比，它的输入除了"原始需求描述"外，还额外携带"原版PRD全文"与"本次修订说明"两部分内容——是否属于修订版，正是由这两部分内容是否存在来判定的。

修订版PRD在标准的九个章节之外，必须在最前面追加一个"实现状态"章节，把本次修订涉及的每一个功能点标注为以下三态之一：

- **已实现**：本次修订之前就已经完成实现的功能点，明确"不用再重新实现"；
- **本版新增**：本次修订新引入、尚待开发实现的功能点；
- **本版修改**：本次修订对原有实现提出了变更，需要说明具体的改动点。

这个三态标注的核心目的，是给"基于PRD进行开发"这一环节划出准确的实现范围边界，防止开发时因为看不出哪些功能点是新增、哪些早已完成，而把已经做完的部分重新实现一遍。

## 适用范围 / 边界

- 三态标注只出现在"修订版"PRD中；首次生成、非修订的PRD不包含"实现状态"章节，也不需要做此标注。
- 该概念只约束PRD文档本身的章节结构和标注方式，不改变PRD澄清会话的状态机（修订版PRD走的仍是同一套"澄清中→生成中→完成/出错"流转）。

## 备注

- 口径来源：kai-toolbox 代码调研起草，待 owner 核实。
- 易混点："已实现"是指相对于**原版PRD而言**已经完成的功能，不是指相对于代码库当前状态——若原版PRD描述的功能实际上从未被开发，仍会被沿用为"已实现"标注，需要人工核实确认，不能盲目信任该标注。
