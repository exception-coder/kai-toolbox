# 设计

适用 OBJ-01、CTX-01、FEED-01、CTRL-01、IDEM-01、EVID-01，无例外。

1. 对象为现有预览 id 与 owner；GET 状态、截图、输入和继续导航均经过既有登录与所有者验证后续期，租约延长至当前时间后 15 分钟且不超过发起该次延长的有效令牌到期时间。正常刷新令牌后的请求可继续延长，旧但尚有效令牌的并发请求不缩短已有合法租约；过期或其他用户的令牌不能续期。
2. 不新增导航、设置或续期弹框，沿用现有预览窗口和读取请求；只更新说明文案。浏览器及页面状态保留，不重新登录、重建或发送业务动作。显式关闭、90 秒启动超时、失去有效登录、服务重启等真实终止条件仍有效。
3. 每个预览保持一条截止时间检查链；旧定时任务执行时重新核对当前租约，避免已续期仍被旧截止时间关闭。过期与关闭不能被后续请求复活。创建清理过期条目时同步释放上下文，不遗留浏览器。
4. document 隐藏时停止画面轮询并中止在途读取，同时关闭该视图的状态查询；返回前台立即恢复同一 id。超出闲置期限显示原恢复入口，由用户重新预览，不自动重放业务输入。前台仅阅读也属于活动；断网/后台不足 15 分钟可恢复，超时仍回收。并发 4、记录 64、账号隔离与凭据不落盘边界不变。
5. 沿用现有 requestKey 幂等复用；不增加独立心跳身份、账户权限或永久后台运行。定向测试用可控时钟覆盖超过初始 15 分钟、旧定时器、闲置回收、刷新令牌、多用户、旧令牌竞争与关闭；前端测试覆盖隐藏中止、暂停和立即恢复。运行版本必须在另行获得重启确认后验收，不用前端样例冒充新后端在线生效。

该修改是现有预览服务内部生命周期纠正，不改变 AI 编程架构的上下文、证据或组件职责契约。

接管区补齐“向上滚动”，与原“向下滚动”并列，分别复用当前预览 id 的 scroll -600/+600，不新增协议或改变只读默认值。沿用 OBJ-01、CTX-01、FEED-01、CTRL-01，按钮均为普通可聚焦控件、保持手机自动换行与既有错误提示，不重建预览或导航。
