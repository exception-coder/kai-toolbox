# 设计

沿用业务系统图谱与原配置面板，项目仍来自现有系统目录，显示选择仍由 fore-consult/system-prefs 持有。只改变缺失偏好的解释：缺失和 false 均不显示，仅 true 显示。配置仍能列出识别目录，供管理员主动选择；不把目录扫描等同于显示意图，不新增配置副本。

适用 OBJ-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01，无例外。对象仍沿用现有 systemName 与 systemSourcePath，不改变身份或同名处理。显示集合同时决定分类、节点、连线端点及链路分析输入；隐藏配置不删除历史咨询，原进行中咨询恢复不依赖图谱节点。重复打开配置只投影已有数据，保存沿用原覆盖式 API，不创建新对象。

加载中保持节点为空并提示；读取失败提示重新加载，禁止进入配置，避免将未读取偏好保存为默认值。读取成功且没有显示项目时，管理员可从空状态进入原配置，普通用户显示联系管理员的提示。保存、关闭、草稿及面板交互沿用原流程；本次不增加导航或更改视觉框架，遵循 quiet-luxury-ui 的状态与恢复约束。

验证覆盖新增根目录、已标记项目、显式隐藏、无记录、偏好异步加载及读取失败重试；确认保存载荷和刷新后的显示结果。执行 frontend typecheck，局部状态文案与过滤调整不单独触发全量构建或服务重启。源码图谱查询因现有 graph.json 超过 CLI 默认读取上限而未执行，已用页面及现有公开目录/偏好调用定向核对，不将推测作为运行证据。无 AI 编程架构契约影响。
