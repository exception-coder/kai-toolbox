# Vibe Coding 会话

业务咨询页在手机/平板使用自己的咨询工作台，因此隐藏PC悬浮聊天条；原聊天引擎和窗口状态继续保留，回到桌面或其他页面恢复展示。后台待确认问题和主动语音界面仍走原入口，不因隐藏悬浮条而取消请求。

## 首屏加载

AI 回复可用完整的 `site-preview` JSON 围栏声明站点；用户点击后在当前对话弹框查看，全屏/缩小保留页面，关闭回原位置。使用方式与公共组件见[站点弹框预览](../../../../docs/development/site-preview.md)。普通链接保持原行为，不自动打开站点或使用已保存密码。

菜单注册只读取元数据与轻量路由入口，不连带加载其他工具的页面组件。悬浮窗、语音界面和后台答题界面按实际状态下载；普通消息只在出现完整 Mermaid 图表块时加载图表库。聊天实例仍跨路由常驻，各界面保留独立错误恢复。

主样式只扫描 `frontend/src`，避免父目录遍历、本地缓存和构建文件拖慢样式生成。入口 HTML 的加载壳沿用手写样式，不需要 Tailwind 扫描。验证构建应输出到已忽略的 `frontend/dist` 子目录，防止开发服务监听临时产物引起重复刷新。

引擎品牌图标使用原 SVG 子集，避免开发服务下载整套图标集合。升级 react-icons 或增补品牌后运行 `node scripts/generate-engine-icons.mjs`，用 `--check` 核对生成资产与许可证。源码加载提速不代表外网真机已经验收；需结合实际启动阶段日志测量。

## 团队仓库初始化

会话工具 → 运行与维护 → 团队依赖，在依赖仓库区执行「初始化 / 拉取」。默认自动创建用户目录 `.kai-toolbox/team-tools` 并克隆缺失的五个团队仓库；配置过依赖目录时沿用配置。已有仓库沿用 origin，仅快进更新；未提交修改或非 Git 占位目录会保留并报告，不删除或重建。拉取独立于下方插件安装及提交推送；打开面板本身不执行写操作。

## 会话项目分组

工具会话的项目列表保留手动分组；未设置分组的会话按主工作目录自动归组，显示目录名和完整路径。Windows 路径大小写、斜杠及尾部斜杠统一识别，同名但路径不同的目录分别显示。只有未记录主目录的会话继续进入「未分组」，附加项目不改变归属。

进入项目、筛选和全局搜索标签沿用同一规则。会话行仍可设置自定义项目 / 需求分组；选择「恢复自动分组」会清除手动分组，并按主目录重新显示。手动项目可继续重命名；自动目录名称随实际主目录变化。分组展示不写入推断名称、不注册新项目，桌面与手机使用同一列表规则。

## Codex 项目与会话同步

在「会话工具 → 运行与维护 → 同步 Codex 项目与会话」选择本机 `.codex*` 授权目录，分页浏览原生项目和未归档会话。项目筛选先读取原生成员，再按真实根目录精确匹配尚无项目 ID 的旧会话，并注明「目录匹配」。导入后保留项目名称，以授权目录和完整项目 ID 派生的身份后缀区分同名项目；“全部会话”按工作目录归组。此目录可能同时包含桌面、CLI 和 VS Code 记录。空项目可以查看根目录或进入既有新建会话流程，不自动注册业务系统。

导入只保存现有会话存储中的恢复元数据：授权目录、工作目录、原生线程 ID、模型和推理强度，不启动模型或复制聊天正文。成功后明确显示「导入成功」及新增 / 复用数量，清空选择；已导入记录保留「打开」入口，不可再次单选或批量选择，整页已导入时显示「本页已全部导入」。后台刷新失败不抹去已确认的导入结果，剩余记录可在刷新恢复后继续导入。服务端仍对重试复用已有会话，保留 Forge 内的标题、收藏、分组、配置及运行状态。打开后使用已有历史和原生恢复链路；继续对话前需由当前客户端释放同一线程的写入连接，目录读取不能证明另一个客户端已释放。

遇到「原生会话被占用」时，占用端可能是 VS Code、Codex 桌面或 Forge 语音连接，不能仅凭报错判定为上一轮或桌面。先在持有该会话的客户端停止任务，再离开或关闭该会话，释放后在 Forge 重试当前消息。仅停止生成或取消订阅可能不会立即卸载线程；不必先关闭整个 Codex 桌面，也不要删除锁文件。Forge 只对尚未发送的启动请求做有界重试，不抢占其他客户端、不自动更换原生会话；占用失败保持待发送队列暂停，语音也不提示用文字绕过同一锁。

通过同步创建的会话在完整列表和最近会话中显示「Codex 导入」。来源根据创建时的授权目录、原生线程 ID 与稳定逻辑身份核对，旧导入无需再次导入；切换引擎后仍可从保存的 Codex 句柄识别。原本就在 Forge 中、同步时被复用的会话保留原来源，不能仅凭当前使用 Codex 就判定为导入。

列表每行保留一个「更多」入口，菜单提供「置顶会话 / 取消置顶」，标题旁用小图钉标记；复制 ID / 配置、规划过期 / 解锁、分组、重命名和删除沿用原浮层。复制 ID 的成功 / 失败反馈保留在菜单内，失败可重试；运行中限制与删除确认沿用原有流程。手机菜单避开屏幕边界，键盘 Esc 关闭菜单后恢复到该会话的操作入口。

选择会话只切换内容和高亮，查看/恢复不再更新活动时间。最近、项目目录及项目内列表在当前浏览期间保持排序和滚动；后台活动继续更新状态，并显示「有新活动 · 更新排序」，点击或重新进入视图才采用最新顺序。置顶在原项目内优先，不增加全局重复分组；仅有置顶时显示该段，最近条数只限制普通项。置顶按登录用户保存在现有模块 KV，刷新可回读，旧收藏只由原会话拥有者兼容继承。lastActivityAt 与兼容字段 lastSeenAt 使用原活动列，不推测回填旧访问时间或最后消息时间；本次加载与运行验收见[导航任务](../../../../openspec/changes/stabilize-session-navigation/tasks.md)。

最近会话和项目会话列表都提供「复制会话配置」。点击立即显示复制进度，继承源会话的工作目录、引擎、模型、服务商、Auth、分组和附加目录，创建独立副本；原会话保留，历史消息和待发送队列不复制。确认副本就绪后切换并显示成功；切换 Auth 仍从当前会话配置进入，沿用原有授权链路复用。

复制期间阻止重复操作；失败保留实际原因，超时提示结果尚未确认，先检查会话列表再决定是否重试。已发送的复制不会在断线重连时再次提交。桌面、手机、专注 / 全屏和悬浮窗共用进度提示。此修复的后端行为待加载新版后验收，不能仅凭前端热更新判断已经生效。

本机账号仅对管理员或关闭认证的本地单用户开放。授权目录必须位于运行用户目录中，排除项目不可导入，预览十分钟过期，可刷新后重新选择。首期不回写桌面、不自动监听同步，不同步归档、图标、收藏或多根目录执行权限。CLI 缺少原生项目接口时明确报错；线程目录不受项目显示名推断影响。此前同步接口的后端和 Sidecar 已加载；本次新增的来源字段及侧栏 / 浮层依赖对齐尚待本次确认重启后加载，真实页面导入 / 续接验收状态见本功能 OpenSpec tasks。

## 订阅额度与本地用量

用量页顶部按已登记引擎和已加载会话的账号配置来源展示 **5 小时剩余 / 本周剩余**。当前会话账号优先；同一引擎同目录的会话共享一行，不同目录分别显示，不相加各账号百分比。可刷新全部或单行，最后获取时间保留真实服务商快照时间，缓存命中不会变成新读数。

Codex 读取账号 App Server 真实窗口；Claude 复用 OAuth usage 的真实五小时/七天窗口。未返回窗口、未登录、API计费、未绑定会话和其他引擎尚无核验接口时明确显示原因，不从本地 Token 或固定价格参照推算余额。不同配置目录也可能登录同一真实账号，汇总不宣称已识别全部本机身份。

本会话 Token 和默认目录日志汇总是独立辅助信息。Claude 新额度链路需后端加载更新后验收；普通前端构建应避免自动发布共享助手 SDK，独立执行 typecheck 和 Vite 验证构建。

页头显示当前对话方式：**开发助手**用于项目代码和任务，**自由对话**用于问答、写作和内容创作。点击名称展开选择；切换保留各自会话和适用草稿，不会把两种方式的消息混在一起。

## 提交记录与推送

在会话工具的 **提交记录** 中选择仓库，查看当前分支的远端目标及领先、落后数量。点击 **Push** 后核对目标地址、固定提交版本和全部待推送提交，再确认推送；此操作推送分支，不是单独推送选中的历史提交。

推送期间禁止重复提交和切换仓库。没有上游、分支落后或没有待推送提交时会说明原因；失败后保留结果，可刷新远端状态再决定是否重试。全屏会话与浮动会话使用同一入口，支持移动端。

在同一弹框中点击 **拉取更新**，会先检查所选工作目录的上游并显示来源、待拉取数量及本地/远端版本；确认后仅以快进方式更新文件，完成后刷新最近提交和推送状态。没有新提交时提示无需拉取。未提交、已暂存或未跟踪文件、分支分叉及未完成 Git 操作会阻止拉取；请先处理并停止正在修改该仓库的 Agent，不会自动 stash、rebase、覆盖改动或创建合并提交。检查/执行期间禁用换仓和关闭；失败或断连后先核对实际状态再重新检查。仅更新当前分支，不更新子模块或标签，不自动部署或重启。

## 新建会话默认选择

手动选择工作区、项目或目录、引擎及服务商后，当前浏览器立即记住工作区完整路径、目录路径、引擎及服务商档案 ID，无需先点击「开始会话」。离开、关闭表单、刷新或重新进入时恢复这些默认值，便于沿用上次配置快速新建；不同 Forge 用户分别保存，不自动同步到其他浏览器、设备或访问地址。只保存选择，不额外存储 Key、服务商地址、模型或会话别名；Codex Auth 目录沿用已有独立偏好。

工作区按路径匹配，顺序变化不会选错；失效工作区提示重新选择或手填。服务商未加载、已删除或引擎当前不可用时明确提示，仍可重新选择或重试，不静默换用官方。读取档案后模型默认值取当前档案，保留已经手填的值。本地存储拒绝时当前表单仍可使用，并说明刷新后可能无法记住。

仅打开表单、功能导览、服务商加载或跨模块程序填充不保存新默认值，也不自动创建会话；离开表单不会撤销已经保存的手动选择。目录和服务商仍受原有后端校验约束。

通过右上角会话工具打开新建表单后，再次点击该入口会收起表单并打开工具菜单；关闭菜单后回到原会话。重新选择新建时保留尚未提交的表单内容和选择，不自动开始会话。

## 工作目录文件树

长文件名保留完整文本与层级缩进，超出宽度时只在文件树内横向滚动；面板标题、筛选和关闭入口固定在原位，不撑宽对话区。聚焦树区域后可用左右方向键滚动，也可使用横向滚动条。文件 / 目录按钮悬停显示完整绝对路径，旧后端没有绝对路径时显示原始相对路径。

点击文件仍打开原文件预览，长标题换行完整显示；大小、定位、右键复制路径和添加到聊天保持可用。桌面侧栏与手机顶部面板共用该呈现策略。

## 会话视图导航

「更多 → 开发待办」以小卡片保存当前会话的开发事项。新增只填写内容或贴图，标题取内容首行（仅图片时为“图片待办”），时间自动记录；不填写来源、参与人和时间。默认最新在前，可搜索、展开卡片查看完整内容及图片，再编辑或引用到草稿。旧记录的标题、时间、来源及备注保留，补充信息按需展开，编辑正文不清空历史元数据。图片可以选择、拖入或粘贴，上传后显示缩略图，最多 10 张、合计 25 MiB，支持放大阅读。一页 20 条，会话最多 1000 条（含已移除）。

选择最多 5 条记录后引用到当前输入草稿，附带记录编号、回看链接、原文、备注及原始截图；保留已有草稿，用户核对后再发送，不启动模型、不自动确认规格。移除可恢复；删除整个会话时清理流水。锁定会话仅可查看。写入使用稳定编号与版本校验，保存超时先刷新核对，重试同一草稿不会新增副本。编辑草稿在同一浏览器标签页按用户与会话保存，关闭或刷新后可继续；截图源文件仍由现有会话附件存储管理，不自动抓取飞书消息或做 OCR。新增后端 API 和启动表尚待本次确认重启后运行验收。

桌面主栏显示对话、推进、用量、会话看板；绑定文档或有评审时显示相应入口。轨迹、站点统一收在末尾的「更多」中，仍查看当前会话；进入后「更多 · 轨迹 / 站点」标明当前位置，可随时切回对话。手机的页面导航统一进入右上角「会话工具 → 工作与进度」，包含对话、推进、会话看板及文档、用量、评审等已有视图；进入该分类后只显示工作视图。

Vibe Coding 已移除数据库页签、SQL 登记 / 管理弹窗及其自动查询，不再后台每 3 秒读取待执行 SQL。已有台账数据、Agent SQL 登记服务和独立数据库工具保留；此次界面清理不会删除或执行历史 SQL。

更多菜单支持键盘、Esc 关闭和焦点恢复；跨手机 / 桌面断点会关闭浮层，保留当前会话、视图、草稿与后台任务。功能导览和完整指南使用相同入口路径。

## 对话工作台的执行摘要与输入

全屏聊天与悬浮窗的完整输入区均支持直接拖入一个或多个文件。拖入时显示「松开即可添加附件」，上传后进入当前会话附件列表，保留已有草稿，核对后再手动发送；原有「＋」选择和粘贴入口继续可用。每条消息最多 10 个附件（含上传中），超出部分不上传并提示分批发送；大小及权限限制沿用原上传接口。文件夹暂不支持，落到输入区以外不会上传或打开文件。失败可重新拖入；上传期间切换会话，结果仍归原会话。精简语音模式没有文件输入区，请恢复完整输入区后添加附件。

附件和上传状态沿用原会话草稿存储，仅补充前端输入方式，不改变模型权限、发送与排队规则。代码检查与定向测试不代表已发布；桌面系统文件拖放的浏览器验收待可用授权环境完成。

桌面底部正常状态仅保留 36px 执行摘要和约 96px 输入区。运行状态、当前任务、已知活动耗时及队列数常驻；工具与文件变更、全链路诊断、记录查询 / 刷新、会话累计指标和队列操作收进 Dock 详情。普通执行活动不再重复铺在消息中，警告、失败和权限确认仍可见。原生语音始终保持连接组件挂载，空闲入口收进详情；连接、断开恢复和异常才显示语音状态。模型配置入口只显示模型简称，完整设置不变。

桌面空闲 Enter 立即发送，运行中 Enter / 主发送按钮默认加入队列；发送按钮旁菜单可选择补充当前轮。官方 Codex 且无附件时，Ctrl/Cmd + Enter 补充当前轮；不支持补充时该快捷键不误发为排队。Shift + Enter、中文输入法和触屏 Enter 保留换行 / 输入行为。异常结束仍暂停队列，不改变后端执行事件与排队策略。详情关闭恢复触发器焦点，手机保留发送选择抽屉和 44px Dock。

### 移动端阅读布局

手机以对话为主体：普通助手消息采用 24px 头像、15px 正文、1.5 行高，主题内容底色与浅色画布分开，单条回复使用 10px 圆角、弱边界且无阴影。原文已有的变化、验证、产物小节用分隔线与排版分层，不自动生成标题或成功结论。复制、分叉、转卡片统一从消息头的更多打开，复制始终取完整原文；失败可重试。桌面保留原操作，悬停或键盘聚焦时显示；触屏宽屏保持可见。正常执行活动集中到输入区上方单一 44px Agent Dock，警告、错误与需要确认的内容仍在消息流中可见；已保存的工具显示偏好继续生效，底层事件与轨迹不删减。

「转卡片」直接在当前对话弹出原 Markdown 卡片编辑器，不切菜单或路由。手机默认全屏并先显示预览，桌面默认弹框；标题栏可全屏/缩小，切换保留本次编辑，关闭回到原消息操作，触发消息被虚拟滚动移除时回到消息区。工具按需加载并提供原位重试；导出期间暂不关闭或切换大小，避免卸载正在捕获的节点。弹框读取原主题偏好，但不覆盖独立工具草稿；本次编辑只用于卡片，不修改对话原文，关闭后再次打开仍以原回复开始。保留原内容工具权限、主题/分页/水印与 PNG 导出和移动分享路径。目标前端加载及真实手机/桌面验收待执行，见 [卡片弹框变更](../../../../openspec/changes/inline-message-card-editor/tasks.md)。

点击 Dock 可查当前执行事件、当前轮输出和活动耗时、累计用量、队列及记录大小，进入监督与推进；记录查询仅按需显示，失败可在抽屉内刷新。已完成结果标为“此轮”，Token、缓存、耗时、复制本轮和本轮变更收进该轮详情，避免与当前运行混淆。监督横栏只在手机对话中收起，推进页和桌面仍可使用。正常输入区约 96px，短屏约 88px，输入限高后内部滚动；保留停止、发送、附件、语音、配置和草稿恢复。权限确认、附件、语音隐私及真正的异常可额外占用空间，不把它们强行隐藏。

最近消息缓存按登录凭据和会话 ID 隔离。切换时先恢复目标会话的缓存，并更换该页面的观察连接；旧会话的迟到输出不进入新消息列表，后台代码任务继续执行。

规划已过期而锁定的会话不进入最近会话或手机快速切换列表；需要查看或解锁时，在完整会话列表筛选「规划已过期」。

上滑阅读时保留当前位置。连接正常且正在生成、已有可见消息并且没有历史请求在途时，点击 **跳到最新** 立即定位当前实时末条并继续跟随，不重新读取可能滞后的落盘历史。空闲、连接尚未恢复、列表为空或历史仍在加载时，先核对最近页，显示获取中，更新完成后定位实际末条底部；失败原位重试。同条数缓存替换也会更新贴底目标，裁掉更早历史时保持消息与虚拟索引对应。长回复、输入区、队列或状态改变消息区尺寸时，通过虚拟列表校正位置；已经贴底便不重复滚动，离底通知只更新按钮状态，避免来回校正。实际贴底后才隐藏按钮并恢复跟随新输出。获取期间主动上滑或切换会话会取消定位，不被迟到响应拉回。

跳转通过 Virtuoso 的公开滚动接口对齐实际滚动底部；长历史测量后的滚动补偿即使没有改变总高度，也会在下一帧重新核对离底距离。监听绑定实际挂载的滚动容器，已经贴底时不再写入；主动滚动、触摸或键盘导航立即取消待执行校正，无持续轮询。消息中的 `/D:/...` 本地文件链接会转换成 Windows 盘符路径后打开，Linux 绝对路径保持原样。

回复里的 `.drawio` / `.drawio.xml` 本地文件链接直接打开只读图形弹框，支持绝对路径、`file:///` 和相对项目路径，复用文档浏览器画布的多页、缩放和全屏能力。关闭恢复原链接焦点；链接已因流式更新移除时回到该消息，且不改变会话或菜单。`GET /api/claude-chat/sessions/{id}/diagram?path=...` 复用 `SessionLocalPathAccessService`，只完整读取会话/附加目录/已登记项目范围内不超过 5 MiB 的 UTF-8 draw.io 文件，不改变原文件树 512 KiB 预览限制。外部 HTTP 图链接保持原链接，不由服务端抓取；失败可重试，关闭或切换会话取消读取，拒绝时不退回系统程序绕过校验。此更新不包含编辑和新渲染服务，正式运行版本验收状态见 [draw.io 预览任务](../../../../openspec/changes/add-drawio-preview/tasks.md)。

手机端优先保留消息阅读区。输入框上方的 **Agent Dock** 汇总运行状态和队列数量；点击后，待发送队列固定在面板标题下方，滚动功能和诊断区域时仍可查看。语音、会话记录、轨迹/用量、监督及会话切换优先展示，运行概览、执行明细和诊断在下方。暂停队列有明确提示，仍可逐条移除、清空或在允许时发送；打开面板不触发发送。桌面共用同一面板顺序。

手机助手头像与身份信息单独占一行，正文使用完整阅读宽度和中性主题底色。适合分层的长回复先显示原文开头及相邻的简短变更、验证段落，点击 **查看回复详情** 展开全部内容；当前轮输出、短回复及以长列表/代码开头的回复保持全文。复制和分叉始终基于完整原文，不会复制摘要替代原文。完成信息归属各自轮次，空闲 Dock 显示 **Agent 状态**，避免重复报完成。

空闲 **语音输入** 收进输入区「＋」，录音、识别或失败时的控制仍留在输入区；关闭更多菜单不卸载录音组件。消息图片显示加载、失败及原地址重试状态。本地图片若没有可访问链接，重试仍可能失败，不会因此扩大本地文件读取权限。

手机官方 Codex 的模型标签显示模型与思考强度，点击优先打开 **快捷组合**：可滑动预览，松手后应用到下一轮，也可点选档位。组合来自当前授权模型目录，缺少模型或不支持的强度不会显示；当前值不属于快捷组合时保留“自定义”。点击组合标题或 **自定义模型与参数**，在同一抽屉内继续选择模型、强度、速度及高级参数。速度沿用当前值，目标模型明确不支持快速模式时回到标准；不会发送聊天消息。桌面、第三方和评审会话保留原配置流程。

运行中点击输入区发送按钮，选择 **加入队列（默认）** 或适用的 **补充到当前轮**；打开或关闭选择器不会发送消息。停止按钮独立保留。手机回车换行；桌面回车在运行中加入队列。队列在本轮正常结束后继续，异常结束暂停。连接、恢复或错误中的语音控制仍显示，空闲语音通过 Dock 开启。

## 最近消息读取

最近消息读取与引擎恢复、累计用量分开。普通 Codex 会话使用 `pagination=cursor` 请求尾部完整轮次的最近窗口，每页最多 30 条；可能不足 30 条，但只要存在 `nextCursor` 就能继续向前。游标是不透明的字节快照，消息 ID 来自文件位置；追加内容不打乱旧分页，服务重启后仍能继续，不需要先建立完整历史索引。窗口从 2 MiB 扩展至最多 32 MiB，不能把中途恢复的上下文当成新轮开始；无法确认完整轮次时原位提示，点击后使用完整历史兼容读取（可能较慢），不会静默截断单轮。文件替换、截断或游标失效后，点击重试会回到最近页。先显示最近页缓存的策略保持不变，正文不因此持久化。

整数 `before`、旧前后端组合、Claude 等其他历史路径及公开评审继续原兼容逻辑；公开评审不能使用普通字节游标绕过继承历史边界。工具配对、去重和统计复用原解析器，累计用量仍可能做完整索引，不能把最近窗口的部分统计当作整会话总量。以上尾部读取需新版后端加载后生效，当前未重启。

## 最近会话看板

工作区页签 **会话看板**（手机为“看板”）按最后活动时间从最新到最早展示最近 20 个未锁定的开发会话，不按收藏置顶。会话标题与项目用于了解近期工作，状态区分进行中、空闲、已中断、已结束与待恢复。

“有待发送”筛选同时包含运行、空闲或中断会话的服务端持久队列，显示条数及前三条任务摘要；尚未核对的队列也保留并明确提示。读取失败不视为零条，可以单独重试。每个队列显示实际获取时间，看板每 15 秒更新，离开后不继续轮询。点击“查看会话”回到对应对话处理；浏览看板不会发送任务。

## 会话记录大小

最近会话、项目内会话列表和会话看板在元信息行显示 **记录大小**。当前对话的输入区上方可以展开统计范围、各引擎已知大小、文件数和读取时间，并单独刷新。查询独立于消息加载，每 30 秒更新；不读取聊天正文，不运行模型。

统计当前 Forge 会话已保存的原生记录，按真实文件去重；Claude 包含主记录和子 Agent JSONL，Codex 按会话保存的授权目录查找 rollout，Pi 和 Antigravity 使用已适配的 transcript，Copilot 包含该会话独立目录的事件、计划及检查点。它是文件逻辑长度，不能代表 Token、模型上下文窗口或磁盘分配空间；工作区源码、Forge 上传附件、认证配置和共享数据库不计入。

本次代码、专项测试和界面夹具验证与真实服务验收分开记录；新查询需后端加载本次版本后才能在实际会话使用，尚未重启。

## 原生语音对话

在 Vibe Coding 的 **Code Agent → 官方 Codex** 会话中，点击输入区上方的 **语音对话**（手机端从 Agent Dock 展开）并允许麦克风。语音发起的代码任务仍在执行时，可以立即重新连接原会话音频，无需等待任务结束。显示“语音已连接”后可以连续说话，听取 Codex 回复并在聊天气泡中查看转写；桌面端同一通话内也可通过原有“补充到当前轮”补充文字。

**静音**只关闭麦克风输入；**结束通话**停止收音和播放，已启动的代码任务继续执行，仍沿用原有工具审批。原有文字草稿保留。你说的话和助手口头回复逐句显示在原有聊天消息列表里，转写过程中更新同一气泡，结束通话后保留在当前视图。语音文字尚未作为独立历史消息保存，刷新或切换会话后以原生线程历史为准；代码任务输出保持独立。

同一会话只保留一路音频，最后主动点击连接的设备接管：在手机点击恢复时，电脑停止收音和播放并显示“语音已转移到另一设备”，代码任务继续执行。旧设备不会自动抢回；连续多端点击以服务端最后收到的合法请求为准。连接仍受麦克风权限、网络和上游能力影响，失败可明确重试。

刷新、切换会话、隐藏页面或网络断开会结束通话，但不停止代码任务。同一浏览器标签页会记住该会话的恢复提示；返回后显示 **恢复语音**，需要点击才会重新收音。原语音线程仍在执行代码时，恢复操作立即协商新音频连接，不新建、排队或中断代码任务。重连会等待旧音频关闭确认，超时可重试；若原线程已退出或任务从未开启语音，会明确提示不能恢复。离开页面、断网或切换会话会释放本地音频；显式结束通话会清除恢复提示。浏览器禁用会话存储时仍可开启语音，但不能保留刷新恢复提示。授权拒绝、设备占用和连接失败会显示原因，可调整浏览器权限后重试，也可继续文字会话。请使用 HTTPS 或 localhost；手机通过局域网访问时也需要 HTTPS。

当前依赖锁定 Codex 0.162.1，语音继续使用实验性 realtime v3 和同一官方登录目录，账号及上游服务须支持 realtime。本次升级已校验语音协议，真实音频往返尚未复测。Claude、第三方网关、咨询、评审和委托会话不开放该入口。原有“语音输入”是转写为文字，仍使用其独立的 Whisper 配置。

## 实现与验证入口

### 彩虹胶囊与会话委托的边界

彩虹胶囊继续作为业务系统内的只读咨询入口；会话委托、邀请码、Grant、公共 Session Client 和委托 SDK 已移除。胶囊使用独立的 `CapsuleRelay*` 组件，复用宿主用户身份、项目绑定和咨询会话，不赋予开发助手权限。

为兼容已部署宿主，胶囊仍使用 `/api/session-client/v1/relay/capsule/ws`，凭据仍从配置中心 `toolbox.claude-chat.session-client.relay` 读取。该命名空间只配置胶囊宿主认证，不恢复其他 Session Client 路由。开关默认关闭；managed 多客户端模式的空列表拒绝所有客户端，配置撤销在下一条消息生效。

排障需要分别验证隧道、WebSocket 握手和会话就绪：普通 `/api/tools` 返回 200 只能证明 HTTP 可达。胶囊固定只读策略、拒绝开发命令，并使用现有会话所有权校验。回归入口：`CapsuleRelay*Test`、`SessionExecutionPolicyTest` 和 `ClaudeChatSessionAccessPolicyTest`。

### 原生语音实现

浏览器 WebRTC 媒体由 `lib/nativeVoice.ts` 管理，`hooks/useNativeVoice.ts` 管理通话状态，`hooks/useVoiceRecovery.ts` 管理显式恢复，`lib/voiceTranscript.ts` 组装语音消息，`hooks/useVoiceTransport.ts` 按通话隔离事件并交给现有聊天列表；Java `SessionVoiceService` 只转发给发起连接，sidecar `codexRealtime.ts` 在当前原生线程上启动或重连 realtime。SDP 不进入消息回放或前端调试记录，音频由 WebRTC 直接传输。

语音轮次包含多个原生代码轮次；只有通话结束且代码收口、受管进程释放后，才释放 Forge 消息队列。浏览器每 10 秒续租，sidecar 在 45 秒无心跳后清理通话；启动超时为 90 秒。

回归入口：前端 `nativeVoice.test.ts`、`useNativeVoice.test.ts`、`useVoiceTransport.test.ts`、`NativeVoiceControl.test.tsx`，sidecar `codexRealtime.test.ts`、`codexAppServer.test.ts`，后端 `SessionVoiceServiceTest`。`npm run app-server:schema:check` 校验锁定 CLI 的实验语音协议，升级 Codex 时必须重新检查并执行真实音频往返验收。

## 轮次变更记录

每轮开发开始时保存 Git 基线，正常结束、失败或中断后保存观察到的文件变化。在「会话工具 → 文件与项目 → 变更记录」按路径检索当前会话的记录；新轮次结果旁的「本轮变更」查看对应记录。记录保留新增、修改、删除、重命名路径及提交区间，不保存文件正文。

共享工作区中的变化不能据此认定由当前 Agent 独占产生。未变化的原有脏文件不会计入；原有修改被提交时明确标注。旧轮次不补造基线，忽略文件、修改后完全还原及采集限制可能形成缺口；断线后未收口的记录保持明确提示。首次启用需要新版后端加载自动建表，服务尚未提供接口时可以重试。

## 移动端顶部

手机顶部只保留导航、当前会话名称、状态点和更多。点击标题打开约 320px 的轻量上下文切换器：显示当前会话与 Agent 状态，直接选择开发助手或自由对话，或从「切换工作空间」进入原会话列表。不嵌套模式菜单，不放页面页签或工具导航；模式选项遵守账号权限，重复选择当前模式只关闭浮层。对话、推进、会话看板、开发待办、执行轨迹、工作站点、Token 用量等进入右上角「会话工具 → 工作与进度」。工作目录与提交记录仍在会话工具中，显示选项归入「阅读与显示」，桌面保留原页签。切换视图保留未发送内容，收起浮层恢复触发器焦点。

手机完成回复从原文突出结果、关键变化和验证，保留风险与待确认信息；文件与执行过程按需展开，复制和分叉保留完整原文。最近一轮的状态、指标、复制本轮和变更集中到 Dock，历史轮次仍可展开。默认隐藏工具时，技术失败和日志在 Dock 查看；会话错误、等待确认及暂停队列保持明确提示。

手机输入区的「＋」提供模型与配置、项目引用、附件和语音入口，Codex 快捷组合与自定义保留；打开配置后菜单收起，关闭恢复「＋」焦点与草稿。发送与运行中断仍常驻，桌面配置位置不变。

## 功能导览

“会话工具 → 阅读与显示 → 专注模式”提供独立阅读布局：正文和输入框默认同为 860px，可切换至 960px 宽版；手机按视口收缩。顶部保留会话标题及实际 OpenSpec/Task 绑定，助手正文去掉卡片框体，正常轮次统计显示为灰色文字。Esc 或“退出专注”恢复工作区，保留草稿和附件；切换宽度不会发起模型请求。

「阅读与显示 → 工作区个性化」按布局与导航、阅读与外观、交互偏好组织已有设置。最近会话、皮肤、工具着色和隐藏工具调用沿用现有浏览器偏好；手势控制复用原有摄像头授权流程，打开偏好弹窗不会开启摄像头。专注模式与全屏、悬浮窗统一在「阅读与显示」中。

工具调用气泡默认隐藏，桌面、手机及悬浮窗共用此偏好；不影响工具执行或轨迹查看。未保存选择或浏览器无法读取存储时使用隐藏默认值；用户曾手动选择显示/隐藏时保留已有选择，可在工作区个性化切换。

左下角用户菜单的「功能导览」提供六类简短导览和可搜索完整指南，说明用途、使用时机及实际入口，会话工具不再重复提供入口。首次仅显示轻提示，选择「跳过导览」后不再重复提示，仍可主动重看；偏好保存在当前浏览器，存储拒绝时说明降级。跨模块入口进入现有 Vibe Coding 工作区，同工作区保留会话及视图参数；一次性导览参数消费后清理，刷新不重复打开。移动侧栏在进入导览时关闭。简短导览直接遮罩页面并高亮真实区域，下一步自动展开对应表单/视图/菜单；退出恢复原布局，不自动执行任务或写操作。专注模式与工作区个性化位于「阅读与显示」。

## 会话工具分类

手机更多首页只保留新建会话、会话列表两项并排快捷操作及五类入口：工作与进度、文件与项目、会话与分享、阅读与显示、运行与维护。进入分类时在同一浮层替换内容，顶部固定返回按钮；返回恢复原分类焦点，Esc 先返回、再关闭。普通重新打开回到首页；导览可直接定位分类，保持导览自身焦点。

工作与进度集中对话、推进、看板、待办、文档、轨迹、站点、用量及自动监督；文件与项目先显示目录与 Git，再显示附加项目及项目准备；会话与分享保留提问定位、命名、导出、评审与规格关联。阅读与显示维护外观、消息显示及通知偏好；运行与维护按连接与能力、服务与依赖、诊断与恢复组织，引擎选项按需展开，重启保留原确认流程。用量和站点不在会话分类重复提供，工作目录与提交记录分别承担文件浏览和 Git 历史。

自动推进提供“按规格推进”和“需求持续推进”。后者在当前会话输入需求与预期结果后持续梳理、实施、验证，项目需要规格或写入绑定时仍须补齐；默认最多 60 轮、8 小时，可调整。支持暂停、停止、预算恢复和后台续跑，关闭弹框不取消运行，同会话需求草稿保留。监督摘要、推进详情及全局看板显示需求、轮次和可用报告；完成标为“Agent 自验完成 · 待复核”，不展示虚构任务百分比，也不代表严格规格验收或已上线。必要重启/发布仍需授权，无新增数据库结构。详见[架构与边界](../../../../docs/ai-coding-architecture.md)及[运行验收状态](../../../../openspec/changes/add-requirement-autopilot/tasks.md)。

菜单限宽、限高并可滚动；每个操作至少 44px，支持方向键、Home/End、Tab 和禁用项说明。没有选择会话时会话与分享不可进入，其余分类只显示适用能力。原事件、授权、会话草稿与执行操作不因分类改变。
