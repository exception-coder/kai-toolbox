# 精简会话视图导航

## Why

数据库预览和 SQL 管理不是当前聊天工作台的常用能力；轨迹、站点直接占用主栏，影响常用视图的定位。用户要求移除数据库页签及其前端操作，将轨迹和站点归入更多。

## What Changes

- 删除 Vibe Coding 数据库页签、SQL 管理入口、轮询及不再使用的前端代码。
- 桌面和手机复用更多视图选择器；轨迹、站点仍在当前会话中打开。
- 保留常用主栏和手机原有次级视图，同步功能导览和模块说明。

## Impact

仅前端导航与说明变化；已有 SQL 台账、Agent 登记服务和独立数据库工具不删除，不修改数据库、SDK、执行治理或上下文分层。此次明确取代 compact-mobile-session-views 中“桌面保留所有直接页签”和 SQL 入口的旧设计。
