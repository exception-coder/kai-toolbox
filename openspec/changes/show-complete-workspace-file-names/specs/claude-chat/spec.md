## ADDED Requirements

### Requirement: 工作目录文件树应能查看完整文件名

文件树 SHALL 保留完整文件名与层级，在自身区域横向滚动查看超宽内容，不通过省略文件名或撑宽页面处理溢出。完整路径提示与文件预览 SHALL 对应原文件。

#### Scenario: 深层同前缀文件

- **WHEN** 用户展开多级 Java 包目录，两份长文件名具有相同前缀
- **THEN** 用户可在文件树中横向滚动区分完整名称、后缀及大小；搜索和关闭入口保持在面板内

#### Scenario: 窄屏查看文件

- **WHEN** 用户在手机顶部文件面板打开长文件名
- **THEN** 页面本身不横向溢出，文件树可滚动查看全名，预览标题换行完整显示，文件操作仍使用原始路径
