# 会话 Markdown 预览设计

## 对象与交互

适用 OBJ-01、NAV-01、CTX-01、FEED-01、EVID-01、IDEM-01，无例外。对象为当前逻辑会话 ID 与规范化文件路径，复用原回复链接、Markdown 渲染、原位弹框和既有文件读取/引用服务，不新增导航或持久文档对象。

点击 `.md` / `.markdown` 本地链接才懒加载预览和读取；HTTP/HTTPS 链接保留网页语义，其他本地文件和 Draw.io 保持原入口。支持盘符、file URI、POSIX、裸/显式相对路径、中文空格和行号后缀；文档链接的片段不进入文件读取路径。本期打开整篇文档，不承诺文件片段定位到行号。

弹框显示文件名及完整路径提示，默认正文；源码仅切换显示，不执行或写入。全屏/缩小调整同一弹框边界，不卸载正文或重复读取；Escape 在全屏时先缩小，再按关闭，关闭恢复原链接焦点与消息位置。文档间导航复用同一弹框，并提供返回入口；路径切换后焦点回标题、取消旧请求，不把旧文档当作新路径显示。路径内图片和文件链接相对该文档目录解析，仍分别调用既有受控接口，不因读到文档而授权整个兄弟目录。

正文滚动区传递 min-height/min-width 与剩余空间，标题截断但保留完整路径 title；手机保持 44px 可触控操作，源码与宽表在阅读区滚动，全屏按钮和关闭入口始终可达。短/长内容及窄/矮视口应由真实浏览器验证，不能以 JSDOM 或编译代替。

## 读取与边界

`GET /api/claude-chat/sessions/{id}/markdown?path=...` 复用 SessionFileController 的完整链接文本读取流程。要求登录与会话访问权限，优先沿用主目录、附加目录和已登记项目；范围外只允许 standard 开发会话助手已核验的精确 Markdown 引用。类型在 `SessionArtifactReferenceService` 单独标记，不能把 Markdown 引用当图片或 Draw.io 引用，用户消息及其他会话也不能授权。

全局排除、真实路径排除、评审与只读咨询边界和有界历史页兜底均沿用已有契约；不全量扫描大历史。仅接受 `.md` / `.markdown`，拒绝 MDX、二进制及非法 UTF-8，完整内容上限 2 MiB，读取前后均检查。Draw.io 仍为 5 MiB，文件树文本仍为 512 KiB 截断接口，不互相替代。

正文沿用会话 Markdown 的 HTML 消毒、图片与 Mermaid 显示，并在文档上下文禁止 style、iframe、object、embed、form 等嵌入及内联样式；源码作为 React 文本显示，不注入 HTML。站点声明仍受既有显式点击机制约束。本次不改变 Mermaid 引擎协议，也不新增文件执行或模型调用。

## 状态与重复操作

加载、空文件、成功、缺失/无权、类型/编码/超限和网络错误分别显示。错误保留路径，可手动重试、返回或关闭，不回退系统程序。请求带取消信号、无自动重试和焦点刷新，关闭后缓存立即可回收，不长期保留文档正文；切换会话立即卸载旧预览。稳定请求身份为会话 ID 与路径，重复点击、源码/全屏切换不创建对象或重新执行任务；手动刷新明确重新读取。

## 验证与交付边界

### SQL 扩展（2026-11-01）

沿用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、IDEM-01，无例外。对象身份仍是会话 ID 与文件路径，新增 SQL 原位只读覆盖层，不新增菜单、数据库连接或登记对象。按已有 L3 规格维护受保护文件读取入口，新增 `/sql` 与独立 SQL 精确引用类型，不能复用其他类型的引用或将用户消息当成范围外授权。

盘符、file URI、POSIX、中文空格及相对路径复用原解析器；行号/片段不进入读取路径，本期不承诺行号定位。Markdown 正文中的 SQL 相对链接以当前文档目录解析。HTTP/HTTPS 保持网页链接，缺少会话不能读取；关闭恢复原链接焦点，切会话取消旧请求。加载、失败重试、空文件及不完整读取保持原恢复流程，查询无自动重试和窗口焦点刷新，关闭后不长期保留内容。

后端同一有界文本方法完整读取 UTF-8（2 MiB），保留登录、会话访问、主/附加/已登记目录、全局排除及范围外精确引用限制。SQL 类型仅接受 `.sql`，不接受 `.sql.exe`、其他扩展、二进制、非法编码及超限正文。没有数据库访问、SQL 语句解析执行、授权变更、脚本写入或待执行状态变化，因此不产生人工 SQL 脚本或 DDL 核验任务。

高亮使用项目已装的 CodeMirror SQL 扩展，只在点击 SQL 后加载；`readOnly` 与 `editable=false` 同时启用，行号和换行便于手机阅读。文本作为代码数据传递，不转成 HTML/Markdown，不增加执行快捷键或按钮。复制直接使用原始文件字符串，保留注释和换行；剪贴板不可用时提供选择复制提示。标题/路径、复制、刷新和关闭保持紧凑，触控目标 44px，正文接收剩余空间并在编辑器内滚动。

验证复用 Markdown/Draw.io 路径回归，补 SQL 点击、只读参数、字面 HTML、复制、取消/迟到结果、错误/空/截断与后端类型/大小/精确引用隔离。CodeMirror 配置依据现有组件及[官方只读说明](https://codemirror.net/examples/readonly/)；真实高亮颜色、长代码滚动、手机键盘/剪贴板须实机验证，替身测试不作为视觉证明。无整体 AI 编程架构契约变更。

覆盖消息链接路由、路径形式、焦点、正文/源码/全屏、返回、空文件、失败重试、取消及迟到响应；后端覆盖完整读取、权限、类型、UTF-8、大小与跨会话引用。复用图片、Draw.io、站点/页面预览回归保护共享 Markdown 组件。执行适用类型检查、前端构建、宿主打包和项目质量门禁。新后端未加载前，不将旧服务探测或入口准备记作功能运行验收；保留当前受管服务，不自行重启。无整体 AI 编程架构契约或数据库脚本变化。
