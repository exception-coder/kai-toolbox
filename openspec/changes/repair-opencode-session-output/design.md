## Context

OpenCode 的阻塞式 `session.prompt` 返回助手消息及 parts，但 Forge 仅依靠独立 SSE 流展示文本。若事件订阅晚于消息或短暂丢失，轮次仍被标记成功，用户看不到回答。现有会话配置也没有 OpenCode 模型选择入口。

适用产品原则：OBJ-01、CTX-01、FEED-01、EVID-01、IDEM-01。主对象是既有 Forge 会话 ID；原生 OpenCode session ID 继续复用，不新建会话或配置页。模型选择附着在现有会话配置中，不增加定位步骤。

## Decision

- 保留 SSE 的实时展示；轮次结束以 `prompt` 响应的 text parts 补齐尚未推送的后缀，不重复输出已有文本。
- 成功响应却没有任何助手文本时返回明确错误，不再误报成功；请求失败沿用原有错误路径。
- 会话配置复用现有模型选择与刷新布局，目录为空时给出 `opencode auth login` 恢复动作。保留“默认模型”，不跨引擎带入模型 ID。
- 保持统一事件与模型目录契约不变，不新增数据库字段或第二套模型清单。

## Interaction and verification

加载使用现有模型刷新状态；成功显示实际回答，失败显示可重试错误，结果未知不解释成成功。关闭配置后仍停留在同一会话和草稿；重复刷新只重读目录，重复发送遵循现有会话轮次约束。选择器保持原生键盘操作和窄屏伸缩。通过 Sidecar 回退单测、TypeScript 与前端构建核验；运行中的 Sidecar 需获得单独重启授权后才能验收真实对话。
