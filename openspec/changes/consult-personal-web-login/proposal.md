# 咨询使用本人个人账号

用户需要以个人账号权限查看非生产站点。咨询内“我的系统账号”表单将账号按用户与系统加密持久绑定，后续同系统咨询复用；每次读取核验登录，失效有界重登，失败引导本人检查或更新密码。复用已有资源校验、隔离浏览器与签名工具，不自动将聊天或截图中的密码存入账号库，不加入公共账号库。

2026-11-17用户明确授权持久绑定，替代最初仅当前咨询15分钟内存授权设计。仍是L3权限与凭据生命周期变更，详细设计见persistence-design.md。旧内存授权不自动落盘，部署与真实站点验收独立记录。

2026-11-18用户要求业务咨询直接使用个人测试地址与账号，去掉资源登记、项目库关联和源码定位的前置要求。允许内网及自定义端口，保留所有者、只读、同源、生产环境及保留地址限制；本次不新增存储或公共账号授权。

最终用户交互以原生授权为先：给出站点、账号并明确要求登录后，实际可用的Codex原生能力直接执行；保存账号改为可选复用方式。避免新增一套模型登录工具、账号审批或业务配置流程。
