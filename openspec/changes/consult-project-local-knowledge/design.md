# 项目资料读取与退役边界

L3：跨模块证据来源与隔离契约调整。使用现有项目目录与咨询sourceRouting授权，不建立第二份知识或检索服务。产品原则：EVID-01证据可追溯、AI-01任务上下文、CTRL-01可恢复。没有新增界面或导航，移动及键盘行为不变。

knowledge_query保留工具名和只读动作兼容，domain动作返回当前授权项目原文候选，不再解析旧引擎继承、评审状态或全局project key。顶层project为source_projects候选ID，嵌套旧project key不参与目录解析。all独立返回项目文件与跨项目关系的结果。文件有路径、截断标识及缺口，不能将缺知识当作确认事实。只读文本限额、真实路径及符号链接检查限制越界；资料不缓存，修改后下次读取生效。跨项目必须再次选择已授权项目，拓扑关系不授予访问权。

冻结流程保留存储，渲染出口覆盖退役工具引导。普通咨询直接读取项目文件、定向源码搜索；Graphify仅用于复杂关系。源码同步只证明检查时本地版本，不证明生产部署。

SQL证据从会话所属项目目录的实际SQL文件定位，排除构建产物和迁入知识快照。多版本、多文件冲突不给确定结构，要求核验迁移顺序或授权数据库元数据；单文件证据也不代表线上已部署。旧evidenceId必须复核当前文件及会话范围。旧知识路径配置不能恢复公共仓库读取。

插件更新不克隆/拉取退役仓库；独立cross-project-topology构建并注册TOPOLOGY_KB_DIR。更新入口移除名为domain-knowledge的旧用户注册，不删除仓库、凭据或其他插件；本次编码不实际运行更新安装。

验证使用临时目录、现有Java/Node测试和受控MCP子进程；不连接真实模型或重启生产。实际目标进程版本与真实咨询验收须另行授权加载后记录。

需求分析的 DomainKnowledgeQueryService 保留接口名和查询开关，但读取已登记项目目录，不再 import 旧仓库 JavaScript。编排使用解析后的 projectPath，避免再次按同名 key 选错项目。DDL 预取仅识别明确的 db/schema.sql 候选，并标注未核验部署版本；其他迁移由按需源码/数据库证据核验，不以历史 Markdown 补齐。旧模块索引同步接口明确返回停用原因，模块列表复用原有源码构建目录扫描；不自动生成第二份 modules.json。

历史咨询的冻结快照不改写：已有 source_read 权限时装配 knowledge_query，沿用同一项目授权；运行装配剔除退役 MCP。历史引用字段与能力 ID 只保留反序列化兼容，不代表服务仍可调用。

知识图谱管理的旧领域状态接口返回 HTTP 410 和项目资料指引；引擎就绪字段改为检查独立拓扑 dist/server.js，状态刷新只读取独立引擎 listModules，不执行已不存在的 bootstrap.mjs，不将旧领域登记缓存作为新咨询依据。历史状态仍保留检测时间，刷新后为拓扑状态。
