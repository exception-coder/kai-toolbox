# 设计

## 现状与选择

咨询已有运行时会话映射、ConsultResourceAccess 服务端 HMAC、consult-readonly MCP 和咨询会话所有权检查。复用该链路，新增 `generate_consult_document`；不把沙箱改为 workspace-write，不授权 Write/Bash，不新建通用文件服务或项目配置。

Apache POI 的 XSSF、XWPF、XSLF 对应 xlsx、docx、pptx（[官方组件说明](https://poi.apache.org/components/index.html)，2026-10-15 查阅）。当前官方稳定版为 5.5.1；宿主现有两个 Office 模块使用 5.2.5。本次沿用宿主兼容版本，只从受限数据生成全新文档，不解析上传模板，避免在本功能中引入混合版本；统一升级及存量解析模块回归属于独立后续维护，不宣称本次使用最新版。

## 权限和存储

1. 后端只向真实关联的咨询运行时装配工具、会话 ID 和 HMAC；模型参数无会话 ID、路径或凭据。
2. Sidecar 复用现有 MCP 会话环境，只有显式装配且有凭据时暴露工具；标注 readOnlyHint=false，保留幂等和非破坏性语义。
3. 后端重新验证 HMAC、关联会话、未结束状态、闭合格式、字段和数据上限；未知字段（含 path/script/template）拒绝。
4. 固定根为 `${user.home}/.kai-toolbox/consult-artifacts/<consultId>/`。模型不可选根目录；内容 SHA-256 为文档 ID。文件名为 ID 加固定格式后缀，展示名称不参与磁盘定位。拒绝符号链接及 Windows 重解析路径；这不是针对拥有操作系统写权限的管理员的隔离沙箱。
5. 文档与 JSON 索引写临时文件后原子发布，索引最后发布。相同规范化内容重复调用、重连和应用重启复用已有文件；内容变化产生新文件，不覆盖旧内容。应用内串行生成防并发重复，不引入分布式锁。
6. 请求最多30万字符，文件10 MB；Word 总段落1000、总表格单元格10000，Excel 总单元格10000。会话最多100份/250 MB，全局最多2000份/2 GB（额度含索引，按预留单文件上限保守核算）。达到上限明确提示管理员整理受控目录，不自动删除用户文件。
7. 下载只接受咨询 ID 和文档 ID，通过原有登录及 owner/admin 校验；不接受 path 参数，不走通用附件读文件 API。attachment + 精确 MIME + no-store + nosniff。
8. Excel 文本不执行公式；超过15位有效精度的数值拒绝并要求传字符串，避免单号和金额静默失真。PPT 每页最多6条单行要点，超长要求拆页。

## 交互原则

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、EVID-01、CTRL-01、IDEM-01，无例外。

- 主对象是原咨询（consultId），产物身份是内容哈希；列表复用原咨询和归档，不另建下载管理页面。
- 文档列表放在咨询消息区，空列表不占位；实际有文件才显示轻量行及下载操作，保存位置按需展开。
- 生成反馈来自原工具执行/回答；工具失败不伪造成功或链接。网络结果未知时重试同内容复用，关闭咨询不会取消已完成文件。
- 下载按钮忙碌时禁用重复点击，失败保留文件与重试入口；列表失败局部重试，不影响追问草稿。
- Markdown 下载链接仅拦截同源固定路由，通过 authFetch 下载，凭据不发送给外部 URL。列表与回答链接均可使用键盘，下载失败在局部可读提示，移动端目标至少44px，文件名换行。
- 切换咨询按 ID 隔离查询和组件状态；归档文件复用同一服务。下载到浏览器由浏览器控制本地位置，服务端保存位置显示用户目录下的受控相对路径。

## 验证与边界

回归真实 Office 包可被 POI 重新打开、中文正文/表格/幻灯片/数据类型；测无效身份、路径、跨用户、重复调用、额度、公式及精度。两引擎装配、MCP HTTP 桥接和权限拒绝定向测试；前端下载/失败重试及窄屏浏览器组件验证。宿主装配检查防依赖冲突。当前运行服务保持不变，重启后真实 AI 生成与下载待用户本次明确授权再执行。
