## Scope and decisions

从功能 manifest 删除入口，从 Maven reactor、依赖管理和 starter 删除模块引用，删除模块的实现、测试和启动 schema 资源。同步删除仅被此模块调用的采集、发现与导入脚本及专属模型条目；共用服务保持原实现。

已有 SQLite 表、数据和本机业务/模型配置不做迁移或删除。旧的实施 change 保留历史证据，并标明由本次退役取代。旧 API 不提供兼容实现；源代码退役与运行部署分别记录。

本机被 Git 忽略的 `.forge/verify.yml` 含 8 个要求已退役 API 返回 200 的检查，随退役移除这些过期场景，保留通用工具 API 检查；原文件备份到 `.run/remove-procurement-verify-before.yml`。移除后的构建与制品检查承接源码退役验证，运行实例中旧 API 的退出仍需获准切换版本后单独验收。

## Product principles

- NAV-01、DENS-01：移除用户明确放弃的入口，不增加替代导航。
- EVID-01：菜单与制品检查只证明源码/构建退出；未重启时不宣称现有运行实例已退出该功能。
- CTX-01：功能退出后旧前端 URL 使用现有全局未匹配路由处理，不新增独立恢复页。
- 无新增交互或原则例外。

## Verification

检查当前源码无招采注册或调用残留，生成菜单与启动导航同步；执行前端类型检查和独立输出目录生产打包，以及包含宿主装配的 Maven 构建。检查产物不含招采模块和菜单，执行项目质量门禁与 OpenSpec 校验。不得为本次移除自行重启受管服务。
