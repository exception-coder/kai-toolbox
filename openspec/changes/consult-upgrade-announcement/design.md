# 固定升级便签

适用原则：OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01，无例外。

主对象仍为业务咨询，重大变更使用登记文件中的稳定ID。右上角固定浅纸色便签直接展示最新五条，无标题标签、抽屉、复制按钮或新的导航。每条仅日期、标题及一句变化/用法，避免打开页面后还需寻找公告入口。同日保留登记顺序，日期倒序后截取五条，不删除历史。不足五条按实际条数展示，无记录不显示便签。

首次综合公告拆为同一批升级的五条具体记录，不编造新能力。内容唯一来源为`data/upgradeNotes.ts`，新能力或重大变化同次追加，纠正原内容保留ID；未部署、未验收和资源依赖写入摘要。公告不构成能力上线或验收证据。

便签作为图谱的补充信息区域，使用语义aside/list，不是模态窗口，没有加载、提交或失败请求，不改变咨询、草稿和键盘焦点。桌面位于工具栏下方右上角，窄屏限制宽高、正文区域滚动，避免横向溢出；标题始终可见，末项通过滚动可达。便签低于对话/输入/配置层，保持咨询操作优先，不自动关闭、切换或停止咨询。

交付约定继续要求重磅更新同次登记；根AGENTS路由咨询README，整体架构交付流程不变。不引入后端、数据库、自动推送、在线管理或新的机器门禁，不改变重启与发布授权。
