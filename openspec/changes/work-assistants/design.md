# 工作助理首期设计

## 产品与边界

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、EVID-01、CTRL-01、IDEM-01。对象为当前用户的助理会话与任务，使用持久 ID。首页呈现两个可操作机器人对象；Shell 仅挂一个轻量助理坞，面板按需加载。开关面板保留目标和草稿，关闭恢复焦点，窄屏使用同一工作区。任务后台执行不因关闭取消，取消必须明确操作。

## 会话与 Skill

助理会话与编码会话分别保存；不抢占 ChatRuntime 的当前会话。每个新会话绑定平台随包发布的 SKILL.md 全文与 SHA-256，执行时显式加载该快照；缺失或损坏拒绝启动，不声称引擎自动发现代表已加载。首期采用平台逻辑会话：每轮通过 AgentOneShotRunner 调用已接入的官方 Claude/Codex，携带有界近期历史；不冒充原生 thread 连续运行。默认工具关闭，模型没有终端或资源写权限。

重复打开复用同一用户的最近助理会话；显式新任务才创建新会话。请求 ID 与会话共同唯一，重复提交返回同一任务；单会话最多一项运行。切换会话不串响应。失败、取消、重启中断保留输入和错误状态，重试明确创建新任务请求。旧 Skill 快照不随部署静默替换。

## 周报闭环

项目来自 ProjectCatalog 并在执行时重新检查 ProjectAccess；按完整 Git 根去重。日期按 Asia/Shanghai，结束日包含；作者须明确填写，不把全团队算作个人。受控 Git 只读取已有本地与远端引用，不 fetch/pull，不修改工作区。收集提交 SHA、作者邮箱、提交时间、标题与正文，有项目数、时间、条数、输出和进程超时上限，溢出明确要求缩小范围。模型按绑定 Skill 归并，结果保留证据与覆盖范围，不据提交推断已上线。初次生成后修改沿用原证据，重新采集需要新任务。支持正文复制与 Markdown 下载。

## 资源闭环

首期覆盖原资源中心的中间件实例与应用站点账号，其他类别明确未支持。资源元数据只向有管理权限的用户展示；账号密码使用专用登记表单，不混入普通聊天。登记预览不持久化秘密、不发给模型，用户确认后调用 ops 自有登记用例；稳定请求 ID 防止重复创建，重复资源拒绝并给出原记录入口，不静默覆盖。系统分组必须是已存在对象，环境取固定选项，登记 PROD 不授予查询或执行权。

新写入密码在原仓储用 AES-GCM 加密，服务端读取时解密，历史未加密值兼容读取并在下一次保存时转换。密钥保存在数据库外的服务账号私有文件，备份必须同时保留密钥，缺失或损坏不生成替代密钥解密旧值。明文不得进入 API 元数据、模型、会话、异常或审计；审计只记身份、记录 ID、动作和结果。普通聊天对明显凭据输入在落库前拒绝，不能声称规则能识别所有未标注秘密；界面明确引导专用入口。

## 验收与后续

首期验收：独立会话与重连、幂等与并发、跨用户拒绝、Skill 缺失、Git 边界与作者时间口径、取消与中断恢复、凭据加密兼容和确认登记、语音回填不误发、手机焦点与返回。语音复用已有转写，只有用户点击才录音；首期不新增实时通话、常听唤醒、定时任务或企微入口。文本附件允许明确支持的格式与大小，不将不支持的 Office 文件伪装成已解析。
