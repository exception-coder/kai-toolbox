# 业务咨询仅显示明确选择的项目

## Why

业务系统图谱将缺少显示偏好的项目默认为可见；新增扫描根目录后，所有新识别目录自动进入图谱，配置中也默认开启。

## What Changes

- 图谱与系统配置均以已保存的 visible=true 作为显示条件；新识别项目默认不选中。
- 保留已保存的显示、隐藏、别名及排序，不迁移数据或删除项目。
- 显示配置加载期间不闪现识别项目，失败提供重试；读取成功前不能编辑保存默认配置。
- 无选择时说明如何在原配置入口标记项目，普通用户联系管理员。

## Impact

仅 fore-consult 前端的项目呈现与配置初值，复用现有项目目录和显示偏好 API。不修改项目扫描、后端、数据表、权限或咨询会话恢复。
