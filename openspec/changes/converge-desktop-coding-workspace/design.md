# 桌面执行摘要与发送策略

适用原则：OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01，无例外。

主对象为当前 sessionId。复用 MobileAgentDock / MobileSessionStatus 的运行判定和会话查询，不建立平行状态。详情依附当前会话，通过覆盖层查看，无新增页签和二次选择。

页面结构沿用 Header、会话页签及侧栏；MessageList 占剩余空间并拥有主要纵向滚动。桌面底部正常状态 Dock 36px + Composer 96px；输入多行时限高并内部滚动。常规 900px 高视口以对话占比至少 70% 为目标；短屏、权限确认、附件和活跃语音按真实需要分配空间，不承诺所有状态固定比例。手机延续 44px Dock 与 88–96px Composer。

摘要只显示当前状态、任务、真实可用活动耗时和队列数。完整执行事件、文件变更、累计指标、队列操作、记录查询与刷新、恢复诊断放入详情；状态未知或异常仍如实展示，不把旧 result 判为正在执行的轮次完成。普通活动去重展示，消息警告、错误和失败工具保留。旧轮结果标为“此轮”，指标按需展开。

语音组件保持挂载，收起详情不会释放媒体连接；空闲入口不占一行，连接 / 恢复 / 异常仍有直接控制。记录只在展开时查询，失败保留刷新入口。详情关闭恢复焦点，限高滚动；桌面发送菜单关闭回按钮，草稿清空使按钮禁用时恢复输入框。断点转换关闭发送菜单，保留草稿与会话。

空闲 Enter 发送；运行中主按钮与 Enter 排队；菜单或 Ctrl/Cmd + Enter 补充当前轮，仅沿用官方 Codex 无附件的已有能力约束。Shift+Enter、IME、触屏与指令选择优先处理。不支持补充的快捷键不偷偷变成另一个动作。调用现有发送、补充和排队方法，每次明确操作一次；打开 / 关闭菜单不发请求，异常结束暂停队列的语义不变。

验证复用现有组件和 ChatPage 行为测试，核对队列 / 补充、焦点、隐藏语音不卸载、错误保留与嵌入兼容；浏览器检查桌面常规和短屏、手机的实际比例、展开详情 / 记录失败恢复、发送菜单与停止入口。运行服务不重启，隔离前端样例不视为真实会话端到端验收。无 AI 编程架构契约影响。

新建表单与会话工具菜单互斥展示：再次打开右上角工具入口时只收起 `new` 面板，不清空草稿 / 选择，不更换当前会话，也不影响其他工具面板。菜单自身的二次点击与 Escape 关闭、焦点恢复保持原有行为。沿用 CTX-01 / DENS-01 / FEED-01，避免大表单与菜单同时占用手机空间。
