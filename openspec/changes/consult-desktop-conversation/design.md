# 交互与上下文交接

适用原则：OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、EVID-01、CTRL-01、IDEM-01，无例外。

- 主对象为 consult_session.session_id；管理员自动恢复也只读取本人最新创建的记录。PC 对话占据工作区，图谱与配置按需展开。手机原有布局不变。
- 最近记录已绑定则恢复原底层会话；归档只读。无绑定则打开原归档读取器及其等待、失败恢复路径。历史失败保留重试，不把缓存空列表当作不存在会话。
- 新建仅打开独立草稿，不归档、不取消原会话。返回保留原咨询追问草稿，首问草稿保留。北京时间跨日显示建议，可继续原会话、独立新建、延续新建；午夜或重新进入前台重新检查。
- 延续由用户显式选择，填写新问题后提交。服务端重新核验来源归属（管理员也不得延续他人记录），读取最近六轮问答，每列至多1000字符，JSON摘录最多16000字符。缺少已同步问答返回可恢复错误，不虚构上下文。
- 新会话 prompt_snapshot 冻结来源ID、标题和有界摘录；evidence_route_snapshot.continuation 仅存来源元数据、捕获时间、轮数和请求指纹，不含授权。纠正系统时保留此引用。旧会话内容、权限、工具日志和附件二进制不复制；当前流程、资源与源码范围重新装配。历史回答属于不可信参考，不是核实事实或高优先级指令。
- 延续请求的目标UUID按用户、来源、请求正文及附件元数据SHA-256在sessionStorage保存，内存保留存储禁用时的页面内重试。成功收到响应后清除此重试映射，后续明确新建相同问题使用新UUID；丢失响应继续使用原UUID。后端使用此UUID作为唯一会话主键，事务冻结当前流程；同ID同来源同指纹返回原对象，其他内容冲突，不改绑底层会话。并发冲突允许按原ID重试，不另建对象。重试返回已绑定会话时只恢复原运行会话，不重发首问。普通新建保持原接口契约。
- 来源详情复用现有受鉴权读取器；旧记录删除后明确失败，不扩大读取权限。新会话不递归复制祖先记录，只带直接来源摘录。没有人工执行SQL或Schema变更。
- 操作使用原生button，支持键盘激活；新建聚焦输入区，更多支持Escape关闭。容器传递剩余高度，问答独立滚动，操作区可达。拖放、语音、输入、发送仍复用原路径。浏览器与实际引擎验证待授权环境完成，单测不代替视觉验收。
