# 设计

Page Anatomy：会话 Header → 44px 视图导航 → 消息列表 → 44px Agent Dock → 约 96px 输入区。移动端 Standard 密度，头像 24px，助手正文 14px/1.5，无普通卡片边框阴影；单个消息对象可复制、分叉及展开更多。桌面沿用原排列。

消息列表是默认工作区唯一主要纵向滚动容器，编辑输入限高；Dock 详情是显式打开的独立抽屉，关闭回到触发器并保持草稿、消息位置。正常工具/命令/文件活动不再重复显示在移动端消息列表；警告、错误和需要确认的内容保留。工具气泡仍遵循已保存的个人偏好，原始事件不被过滤出数据或轨迹。

主对象为当前服务器会话 ID；当前运行摘要与历史 result 分别归属当前执行及“此轮”记录。运行中不从旧 result 推断完成；状态仍复用既有运行状态查询，不新增第二份状态。指标进入 Dock 和轮次详情，队列和记录大小可在 Dock 查询操作；监督状态在推进页面和 Dock 导航中可达，不在手机对话页独占横栏。

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01，无例外。新增/隐藏操作不跨会话，不执行后台写操作；错误重试、停止生成、手动队列发送和语音授权沿用既有流程。抽屉继承 Radix 焦点管理，按钮 Enter/Space 展开、Esc 关闭；手机和桌面 resize 关闭移动浮层。

验收采用真实生产组件配合隔离 API 样例，覆盖运行/空闲/失败、旧轮完成与新轮运行共存、队列操作和详情恢复。390×844、360×640 及短屏检查消息占比、无横向溢出、末条和保存/停止入口可达，桌面检查布局不受影响。正常无键盘/附件/权限警告时，消息区域争取达到应用可用高度 60%；浏览器地址栏和键盘占用需单列，不假报所有设备都达标。

已核对 [WAI Disclosure 键盘与展开语义](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) 和 [MDN 动态视口长度](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length)（2026-10-13）。沿用 React 19、Radix Sheet 和现有虚拟列表，不引入 UI 或滚动库。
