# 变更提案

## Why

现有 SDK 使用真实用户的流式咨询合同，不能替代 yoooni-agent 的应用后端认证、企业隔离和结构化分析任务。补齐服务端合同，调用方无需员工密码、模型密钥或完整聊天历史即可提交 IT 问题并查询分析。

## What Changes

- 管理员签发绑定应用、企业、有效期及项目范围的独立服务凭据，短期票据只用于分析 API。
- 补充原业务咨询配置下的应用凭据管理页面，支持安全元数据查看、颁发、一次性配置交付、轮换/续期和撤销；管理员可在分析接口未启用时先准备授权。
- 提供持久化、幂等的异步提交、查询及取消，重启中断不自动重放。
- 复用 AgentOneShotRunner 和业务咨询默认账号策略；禁用模型工具，只分析有界输入与显式授权的源码证据，不发消息、不修改业务、不隐式查询数据库。
- SDK 增加独立后端客户端，保持既有 WSS 用户客户端兼容；补完整合同及脱敏示例。

## Capabilities

### New Capabilities

- `consult-backend-analysis`: 应用身份下的只读 IT 问题分析任务。
