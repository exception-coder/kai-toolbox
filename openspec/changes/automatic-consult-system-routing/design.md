# 自动系统定位设计

## 范围与交互

会话13846853-ec73-4a4f-accb-d99c04201e01的调查显示，单目录绑定限制了前端探索，图谱预热和排队也使定位停滞。单项目未命中或图谱未就绪不等于用户必须提供 URL。

一期实现有界候选、跨项目源码读取、服务端焦点、用户纠正和授权校验。不引入向量库、独立路由模型、全磁盘扫描或新的项目关系页面。扩大候选上限等待实际命中和耗时数据。

适用原则：OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、EVID-01、CTRL-01、IDEM-01，无权限例外。

- 主对象是原咨询sessionId，项目使用ProjectCatalog的id和完整路径；运行cwd仅为启动锚点。提问始终自动识别，移除首问系统下拉和模式切换。用户点击图谱系统仅标记首查源码上下文，标题可从问题生成；无需理解或选择识别模式。
- 原对话展示候选与焦点，低频纠正渐进展开。切换只改咨询元数据，不新建咨询、切换WS或清空草稿/附件。失败原地重选，读取失败可重试；关闭不取消已经发出的请求。
- 图谱系统支持指针和键盘/辅助技术激活，输入与附件保持原草稿；窄屏无需容纳模式选择器。恢复历史咨询收起首问面板，避免双输入区覆盖；旧咨询不轮询新范围，恢复旧咨询不把原系统隐式作为下一首问偏好。
- 焦点持久化，重复用户选择产生相同结果；比较原快照并限定PENDING，拒绝并发旧写和归档后写。用户纠正优先，模型不得覆盖。创建沿用既有链路，不新增重连创建逻辑。

桌面首问普通Enter发送、Shift+Enter换行，组合输入回车不发送，沿用canStart及原接口。创建失败在原输入区显示真实错误与重试，保留问题和附件；不以静默失败让用户误认为键盘无效。该反馈不自动重启或重试服务。

## 候选与证据快照

ConsultSourceRoutingService投影ProjectCatalog：目录可用、未排除、ProjectAccess允许、咨询配置已显示且完整源码路径唯一一致；登记名、目录名及别名不同不影响路径关联。无路径旧记录只在目录名唯一时兼容，同路径配置歧义不授予范围。按管理员sortOrder排列，同序按稳定名称/id兜底，不读取使用历史排序。用户在图谱标记发问的系统移到首位，其余保留管理员相对顺序，再截取最多八个；选择位于原前八之外的项目仍包含在首位。无标记直接按管理员顺序。标记只决定首查顺序，焦点仍为空；不授予数据库权限。无效、已隐藏或被排除的首查优先项只取消优先权，按管理员有效候选顺序继续，不要求用户重新选系统；换用启动锚点时清除原优先项的模块标签。无有效候选仍明确报错，指定单项目旧模式仍严格拒绝无效目录。恢复会话逐次核验也采用相同的路径关联，保留冻结候选顺序，不补入新项目。

管理员在原配置抽屉通过上移/下移调整原列表，复用sortOrder持久化，不建平行配置。已显示候选集中置顶，其相对顺序保持原配置；新启用项目追加到候选末尾。各组首尾按钮禁用，键盘焦点跟随原项目，别名与显示状态随行保留。保存时禁止编辑，失败保留当前顺序并可重试，取消不保存；批量保存使用原事务能力，PUT接口要求ADMIN，普通用户仍可读取。排序冻结在新咨询快照，后续配置修改只影响新咨询，当前项目撤销继续即时校验。

复用consult_session.evidence_route_snapshot，不改表：版本2对象含routes（原确认的数据归属）和sourceRouting（automatic、focusedProject、projects、evidencePath、reason、selectedBy）。旧数组兼容读取，保留原单目录。模型焦点标为MODEL_INFERRED，用户指定标为USER，不能把推断转成人工确认的业务规则。

source_projects返回有序候选id及显示名，不向模型暴露根路径。助手必须按返回列表从上往下，逐项结合截图、菜单及源码核对，未命中再查下一项，不再按截图猜测重新排列或只探索前三项。找到前端后沿请求核对服务端，以真实服务端相对文件和理由select焦点。文件存在只证明可引用，不能证明语义判断正确。首问选择是探索偏好，显式autoDetect=false的旧API请求仍保持原单目录；新UI创建始终启用候选后备。对话内“纠正系统”仍是用户确认焦点，不等同于首问优先项；保留候选用于关联证据，但模型不得自动改回焦点。证据仍不能区分时才请求URL等最少信息。

## 工具与权限

source_context/source_search/source_read/source_git_history增加候选id。每次通过原HMAC会话签名向后端核验当前范围；具体文件/子目录校验真实路径及排除策略。Sidecar用AsyncLocalStorage隔离并发根，路由映射缓存按根隔离。未知项目、越界、撤销或核验失败均拒绝，不回退锚点。旧咨询范围以JSON null返回，继续原目录并复查目录策略。

source_projects(select)是受限咨询具名元数据写入例外，readOnlyHint=false；不开放终端、Git或业务写入。新默认流程登记；旧冻结流程仅具备source_read时由服务端追加，原快照不变。两引擎共用白名单，不接受模型指定任意根。

AUTO无焦点时拒绝数据库发现和查询；定位后仍使用原流程冻结的resourceBindingIds，并校验对应系统、环境、能力及当前启用状态。源码候选不授予数据库范围，生产禁用与凭据保护保持原约束。

自动探索每项目图谱预算最多10秒。预热/排队不是未命中，不缓存为完成证据，不反复等待同一项目。source_context返回最多20个根层结构线索，允许沿已确认子目录定位，仍禁止根目录扫描；支持小程序wxml/wxss/wxs。既有图谱和输出上限保持。
