# 业务与架构候选

| 候选 | 置信度 | 证据 | 后续确认方式 |
|---|---|---|---|
| 将存量 `prd_session` 三类路径幂等回填到 `prd_artifact` | 高 | 当前实现只为新增写入建账，设计保留旧读兼容 | 对运行库做只读计数和文件摘要盘点后单独设计迁移 |
| API 返回 `artifactStatus` 并从账本读取 | 高 | 旧视图仍以路径非空推断产物存在 | 完成回填后增加双读校验，再切换权威读取 |
| 删除会话时保留或清理历史产物需要明确策略 | 中 | 账本未声明外键且当前不自动删除孤儿 | 结合产品对审计留存和磁盘回收的要求确认 |
| “需求类型”统一指 AI 澄清策略分类 `RequirementType`，业务原始分类固定称“业务需求分类” | 高 | `prd_session.req_type` 与 `business_requirement_type` 已有正交语义，公共契约进一步固化 | 产品确认术语后迁入正式 glossary |
