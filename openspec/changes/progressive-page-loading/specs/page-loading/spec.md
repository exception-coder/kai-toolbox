## ADDED Requirements

### Requirement: 页面下载前有可恢复的结构占位

HTML 响应 MUST 包含静态骨架和工作台恢复入口，不等待脚本或后端业务接口。

#### Scenario: 无登录快照或脚本尚未就绪

- **WHEN** 用户首次打开首页或任意模块链接
- **THEN** HTML 显示骨架与返回工作台入口，不能暴露未授权菜单

#### Scenario: 直达已授权模块

- **WHEN** 本地有有效结构的登录、权限和菜单快照
- **THEN** 可在主应用就绪前展开同源功能导航，权限仍由原路由及服务端核验

### Requirement: 页面代码局部加载

工具页和展示页首次下载代码 MUST 使用骨架，不隐藏已就绪外壳；慢加载可返回或重试。

#### Scenario: 页面代码尚未下载

- **WHEN** 目标页面触发 lazy 加载
- **THEN** 内容区展示骨架与页面身份，侧栏保留；十秒未就绪提供恢复操作

### Requirement: 聊天引擎下载不阻塞外壳

引擎 MUST 仅在首次激活时下载，接管不能卸载页面、清空草稿或重复创建实例。

#### Scenario: 首页激活并切换页面

- **WHEN** 用户输入草稿后激活引擎，随后切换路由
- **THEN** 草稿及页面实例保持，引擎只挂载一次，原会话与通道规则不变

### Requirement: 点击立即提交目标位置

工作台 MUST 在导航点击后立即更新路由位置与高亮，不等待目标页面模块完成初始化。

#### Scenario: 慢页面尚未就绪时继续切换

- **WHEN** 用户点击尚未下载的页面菜单
- **THEN** 移动抽屉关闭、路径与高亮更新、内容显示骨架；可再切换其他菜单，旧加载完成不得拉回页面

### Requirement: 按导航意图预加载入口代码

平台 MUST 在明确的导航意图下复用目标页面加载请求，不提前挂载业务组件；弱网与省流量跳过。

#### Scenario: 聚焦或触摸后访问页面

- **WHEN** 用户聚焦、触摸或持续悬停已展示菜单入口
- **THEN** 只下载该入口代码；重复意图和实际访问共用请求，未挂载页面不执行其业务查询

#### Scenario: 取消与恢复

- **WHEN** 悬停意图取消、入口卸载、网络要求省流量或预加载失败
- **THEN** 取消待发定时器或跳过预加载；保留真实菜单导航和现有页面失败恢复
