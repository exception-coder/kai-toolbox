## ADDED Requirements

### Requirement: 新建咨询独立于归档

移动工作台 MUST 提供可发现的新建咨询入口。打开新草稿 MUST NOT 归档、停止或重建原咨询；仅在发送新问题时创建新咨询。

#### Scenario: 保留原咨询开始新问题

- **WHEN** 用户在已恢复的咨询中点击新建
- **THEN** 显示独立的问题编辑器，允许返回当前咨询，原咨询及回答保持有效
- **AND** 新旧草稿各自保留，历史刷新不会强制关闭新问题编辑器

#### Scenario: 发送与恢复

- **WHEN** 用户发送独立新问题
- **THEN** 使用现有自动识别创建接口，旧咨询不自动归档
- **AND** 用户可通过历史咨询恢复旧会话，其页面内追问草稿不混入新会话

### Requirement: 历史咨询在主工作区阅读

系统 MUST 优先展示已关联底层会话的原始消息流。已归档咨询 MUST 只读，不因浏览而重新登记缺陷、同步问答或恢复执行；进行中咨询 MAY 继续追问。

#### Scenario: 手机打开归档

- **WHEN** 用户打开已归档咨询
- **THEN** 在咨询内容区展示原会话，并明确只读状态
- **AND** 没有底层会话的旧记录使用全宽归档内容兜底，正文可滚动，加载失败可重试，可返回历史列表

#### Scenario: 进行中记录的列表关联尚未刷新

- **WHEN** 用户打开进行中的咨询，而历史列表未带回底层会话关联
- **THEN** 自动读取最新详情，关联可用后直接进入原会话
- **AND** 不展示只读归档或要求用户回图谱找操作入口；关联暂缺时有界刷新并支持原地重新连接，不创建重复会话
