## 业务定义

为避免录制无限制占用资源，录制设有硬性上限：单次录制时长达到 60 分钟，或抓取到的请求数量达到 5000 条，任一条件先触发，系统即自动结束该次录制（并通知前端）。

同一个浏览器会话在任意时刻只允许存在一个"进行中"的录制；如果对同一个会话再次发起开始录制，系统会先自动结束上一个仍在进行的录制，再开始新的录制，而不是报错拒绝。

应用重启后，所有上次未能正常结束（仍标记为进行中）的录制会被统一标记为异常终止状态，避免留下"僵尸录制"。

## 适用范围 / 边界

上限数值（60 分钟 / 5000 条）是当前配置值，属于可调业务口径，规则的核心是"存在硬上限、触达即自动停止"与"单会话单进行中录制"这两条约束本身。用户手动主动停止录制、与系统自动因超限停止录制，是两种不同的结束原因，但都会将录制置为已结束状态。
