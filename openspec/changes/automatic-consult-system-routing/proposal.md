# 咨询按截图自动探索相关系统

截图可能来自小程序、ERP、SCM 或 SRM。原咨询把一个源码目录同时作为启动目录和问题归属，未命中时容易要求用户补 URL。改为默认直接提问，由服务端汇聚常用候选，助手逐个定位前端并追到服务端；确实无法区分时才询问用户。

复用项目库、咨询可见配置、现有会话及只读工具，不新增系统关联配置或数据库授权。用户可在原咨询纠正系统，保留问题、附件和草稿。旧咨询继续使用原目录，新行为适用于新建自动识别咨询。

候选顺序由管理员在原配置中维护。用户首问选中的系统排首位，未命中按其余管理员顺序逐个核查截图；不再按历史使用频次或模型猜测重排。没有选择时直接采用管理员顺序。
