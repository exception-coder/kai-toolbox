# 设计

## 当前范围

前端依据已有会话字段生成默认目录分组，历史数据刷新后直接生效。显式的 group 始终优先；不把用户自定义分组改名，也不将目录同名视为同一项目。

分组键区分手动名称、完整目录和缺失目录三个来源。自动分组只读取主目录 cwd，附加目录不参与归属。Windows 盘符和 UNC 路径忽略大小写，POSIX 路径保留大小写；统一分隔符和尾部斜杠，保留根目录。符号链接、真实路径别名不自行推定为同一目录。

项目导航与搜索标签使用同一解析器。目录分组显示路径作为辨识信息，手动项目继续使用原重命名接口；自动目录的显示名称来自目录，用户仍可在会话行设置自定义分组。清除自定义分组后恢复目录分组。最近会话按用户最新要求跨项目平铺，目录只作为行内辨识标签，查看次序与手动置顶遵循[会话导航设计](../stabilize-session-navigation/design.md)；项目列表分组不变。

## 产品原则

- **OBJ-01 / CTX-01**：分组保持会话和主目录上下文，完整路径是自动分组身份，不根据名称猜测项目注册信息。
- **NAV-01 / DENS-01**：复用现有项目列表、返回、搜索和会话分组入口，目录信息在现有列表内显示。
- **FEED-01 / IDEM-01**：清除自定义分组的入口明确说明恢复自动分组，导航不产生写入。
- **EVID-01**：目录来自实际会话字段，缺失时继续明确显示「未分组」。

无原则例外；不改变 AI 编程架构的证据、权限、执行或交付契约。

## 验证

定向检查目录等价、同名目录隔离、手动优先、根目录及缺失信息；组件检查项目进入、搜索、刷新归属和已有重命名接口。复用最近会话与手机状态回归，执行类型和项目质量检查；不自动构建或发布共享 SDK。
