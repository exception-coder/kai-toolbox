## 方案与边界（L2）

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、IDEM-01、CTRL-01，无架构契约变更。沿用 quiet-luxury-ui：消息中只加细边框的预览对象，44px 操作、独立滚动与全屏恢复，不复制页面或重排聊天布局。

1. 主对象仍为原逻辑会话与回复，预览引用继承完整 href 中的路由、设备、资源 ID 和源码标记。Markdown 只提取受控入口，浏览器模块通过公共组件拥有预览创建、画面和生命周期；原鉴权、账号隔离、资源绑定、环境/角色限制及生产确认继续由现有服务和工作台执行。
2. 不新增导航或浏览器代理。消息原链接保持可复制；首个预览引用后插入一个预览块，重复引用去重，其余手机/桌面选项归入同块。完整本地文件预览继续共存。现有完整预览路由及手动弹框保留，普通外链与不完整入口不自动读取。
3. 预览块进入视口后才挂载工作台并自动启动；离开视口、页面隐藏或全屏接管显示时停止对应内嵌状态/画面轮询，取消截图请求并释放 Blob URL。初始占位和正文区域保留高度，内容仅内部滚动，不调用聊天跳转/焦点/会话操作。创建、登录、失败、过期及生产环境确认使用真实服务状态；失败不自动重建浏览器，手动恢复保留错误与输入。
4. 点击原链接或全屏按钮展开相同预览 ID，不新建第二个浏览器。关闭恢复原链接/按钮焦点，内嵌画面继续；全屏内显式重新预览或设备切换产生的新上下文由内嵌宿主接回所有权。切换预览选项、消息卸载或会话变化时，只关闭该块创建的上下文；借用已有 ID 不取得关闭所有权。迟到的创建响应沿用工作台 active 检查后关闭，不更新已卸载消息。
5. 一个已挂载引用块拥有独立 requestKey，防止与其他窗口关闭所有权冲突；流式追加保留同一 React 位置、requestKey 和浏览器 ID。失败后的显式重试复用本次 requestKey，设备切换/重新预览才有新身份。关闭弹框不取消任务；视口暂停也不等于关闭服务端预览，过期按既有 TTL 如实显示。

## 访问与嵌套保护

- 复用 `pagePreviewEntryFromHref` 的当前源/路径/凭据参数检查，并为自动内嵌增加完整性检查。实际 href 决定预览，清理原始 HTML 的伪造 page-preview 数据属性；代码块、普通网址和内嵌文档不触发加载。禁止将任意目标 URL 放入 iframe。
- 有 resourceId 的入口只使用该资源；资源尚未核对、缺失或 PROD 时不自动启动。PROD 继续需要原显式确认，不能退回其他账号。未指定资源只使用当前 Forge 身份。截图沿用受保护接口，认证 Token 不进入 URL、Markdown 或图片地址；内嵌画面默认只读，接管仍在全屏工作台明确启用。
- 当前 Forge 的自动内嵌目标增加保留查询标记 `__forge_inline_preview=1`。浏览器前端在路由规范化前捕获到 sessionStorage，标记仅表示该标签页是预览渲染，禁用再次自动内嵌，防止“预览中的聊天”递归创建浏览器；不是鉴权或沙箱。展示和业务原地址隐藏该内部参数。外部资源路由不擅自追加参数，直接指向预览器本身的目标不自动启动。
- 不完整旧链接不猜测其真实目标，继续保留手动打开；新交付入口必须携带完整 route/device/scene/sourceRevision 等参数。入口已准备、画面已取得、业务功能验收通过仍是不同事实。

## 验证

复用真实消息/文件/站点预览与页面预览工作台测试，补视口生命周期、一个块/一个上下文、原链接展开复用、流式节点保留、迟到结果/借用所有权、资源和生产确认、错误重试以及递归抑制。最终源码构建、运行版本/资源与至少 60 秒稳定观察单列；真实手机/桌面视觉、焦点、矮屏与滚动仍须实际浏览器验收，沿用既有访问拒绝，不另换通道绕过。

2026-11-03 核对 [MDN Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API) 的可见区异步观察，用于只在阅读时启动和刷新；[MDN iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe) 的嵌套上下文与权限边界仅作比较，本次继续使用已有隔离浏览器的受保护画面，不通过原始 iframe 绕过登录、同源或页面嵌入策略。
