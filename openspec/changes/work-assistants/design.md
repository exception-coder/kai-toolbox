# 工作助理首期设计

## 产品与边界

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、EVID-01、CTRL-01、IDEM-01。对象为当前用户的助理会话与任务，使用持久 ID。首页呈现两个可操作机器人对象；Shell 仅挂一个轻量助理坞，面板按需加载。开关面板保留目标和草稿，关闭恢复焦点，窄屏使用同一工作区。任务后台执行不因关闭取消，取消必须明确操作。

助理坞为独立的展示控件，默认以窄把手贴右边，展开后可自由拖动，靠近左右边缘松手即收起，辅助按钮可手动贴边。按 DENS-01 采用 28px 宽的把手和紧凑收起按钮，减少对页面操作区的遮挡；把手高度 44px，保留机器人标识、可读标签及键盘恢复。鼠标与触控共用 Pointer Events，超过 6px 才拖动，捕获指针并过滤其他触点，取消恢复原位；拖动后的点击不得唤醒面板。方向键移动、Escape 收起、Home 复位，原快捷键保持可用。只在当前用户浏览器保存归一化位置与收起状态，不保存任务或秘密，不改后台配置；可视区域变化时钳制边界并尊重设备安全区。工作区打开时隐藏入口，原任务、会话与焦点恢复契约保持不变，无整体架构影响。

## 会话与 Skill

助理会话与编码会话分别保存；不抢占 ChatRuntime 的当前会话。每个新会话绑定平台随包发布的 SKILL.md 全文与 SHA-256，执行时显式加载该快照；缺失或损坏拒绝启动，不声称引擎自动发现代表已加载。首期采用平台逻辑会话：每轮通过 AgentOneShotRunner 调用已接入的官方 Claude/Codex，携带有界近期历史；不冒充原生 thread 连续运行。默认工具关闭，模型没有终端或资源写权限。

重复打开复用同一用户的最近助理会话；显式新任务才创建新会话。请求 ID 与会话共同唯一，重复提交返回同一任务；单会话最多一项运行。切换会话不串响应。失败、取消、重启中断保留输入和错误状态，重试明确创建新任务请求。旧 Skill 快照不随部署静默替换。

## 周报闭环

项目来自 ProjectCatalog 并在执行时重新检查 ProjectAccess；按完整 Git 根去重。日期按 Asia/Shanghai，结束日包含；作者须明确填写，不把全团队算作个人。受控 Git 只读取已有本地与远端引用，不 fetch/pull，不修改工作区。收集提交 SHA、作者邮箱、提交时间、标题与正文，有项目数、时间、条数、输出和进程超时上限，溢出明确要求缩小范围。模型按绑定 Skill 归并，结果保留证据与覆盖范围，不据提交推断已上线。初次生成后修改沿用原证据，重新采集需要新任务。支持正文复制与 Markdown 下载。

## 资源闭环

覆盖原资源中心的中间件实例、应用站点账号和密码认证 SSH 主机。资源元数据只向有管理权限的用户展示；账号密码使用专用安全输入，不混入普通聊天。登记预览不持久化秘密、不发给模型，用户确认后调用 ops 自有登记用例；稳定请求 ID 防止重复创建，重复资源拒绝并给出原记录入口，不静默覆盖。系统分组必须是已存在对象，环境为受控枚举，登记 PROD 不授予查询或执行权。主机登记通过 common 的 HostEnrollmentGateway 交给 hosts 自有用例，与登记回执共用同一事务，不跨模块查询或写 host 表；环境/系统仅为原主机 tag，不伪造系统绑定。密码/passphrase 仓储经 ResourceCredentialCipher 调用既有 AES-GCM 实现，不新建密钥或账号台账；历史明文读取和下次保存兼容，不批量改写，SSH/SFTP 仍从仓储获得解密后的配置。

## 自然语言入口（2026-10-20）

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、EVID-01、CTRL-01、IDEM-01，无产品原则例外。页面由助理切换、项目选择、自然输入/语音、主要操作组成；移动端项目列表限高，输入不再被引擎、模型、作者、日期表单推到屏外。默认 Codex，高级设置可换引擎/模型。原手动资源表单折叠为恢复入口，不新增菜单或对话弹层。普通需求草稿只放当前用户内存，资源原文只在当前安全组件内存中；关闭清除秘密，切换前沿用既有脏数据保护，确认保存期间不切换。

周报先调用 WeeklyRequestPlanner：禁用模型工具并使用独立虚拟线程和并发上限，提取 JSON 形式的明确作者及 THIS_WEEK/PREVIOUS_WEEK/TODAY/YESTERDAY/LAST_N_DAYS/CUSTOM/UNKNOWN 周期。作者必须出现在用户输入，不把“我”映射到猜测的 Git 姓名；相对日期由代码按上海日历计算，最长 32 天。项目只能来自所选 ProjectCatalog ID，执行采集时仍复核 ProjectAccess。规划不创建会话或运行 Git；失败/缺项保留输入并提示补充。90 秒等待超时取消规划，真实 worker 结束才释放并发槽。取得有效范围后复用现有 create/message 接口，首轮直接发送，响应未知使用相同请求 ID 重试，不重复创建或清除较新的草稿。后续换作者/周期仍显式新任务。

资源自然输入不交给模型：仅解析有限环境和类型词表、明确键值、常见连接 URI；不是任意自然语义解析承诺。每次登记一项，明确缺失、冲突及不支持格式，不静默选择环境。默认端口来自已实现类型；URI userinfo 进入隐藏凭据字段，不进入公开地址，URI 中密码或路径不能作为环境依据。确认摘要显示实际目标和凭据存在位，成功/关闭清除原文，失败保留同一次登记并给回原管理入口。SSH 私钥、Token 和批量自由文本不在此安全解析器范围，可到原管理入口配置。语音仍通过用户主动触发的原 STT，只用于描述资源，界面提示不口述密码。

当前项目来源需要区分：周报使用 ProjectCatalog；资源输入显式选择 ops 原系统分组。两者不通过名称猜配，不将资源登记等同绑定到 Project Registry。主机共享凭据端口由当前宿主的 OpsCredentialCipher 实现；独立 hosts 装配须提供实现，宿主类路径和仓储兼容回归为必要验收。键盘表单、原语音回填、返回焦点与脏数据提示沿用；浏览器与手机真实显示仍须运行验证。

新写入密码在原仓储用 AES-GCM 加密，服务端读取时解密，历史未加密值兼容读取并在下一次保存时转换。密钥保存在数据库外的服务账号私有文件，备份必须同时保留密钥，缺失或损坏不生成替代密钥解密旧值。明文不得进入 API 元数据、模型、会话、异常或审计；审计只记身份、记录 ID、动作和结果。普通聊天对明显凭据输入在落库前拒绝，不能声称规则能识别所有未标注秘密；界面明确引导专用入口。

## 验收与后续

首期验收：独立会话与重连、幂等与并发、跨用户拒绝、Skill 缺失、Git 边界与作者时间口径、取消与中断恢复、凭据加密兼容和确认登记、语音回填不误发、手机焦点与返回。语音复用已有转写，只有用户点击才录音；首期不新增实时通话、常听唤醒、定时任务或企微入口。文本附件允许明确支持的格式与大小，不将不支持的 Office 文件伪装成已解析。
