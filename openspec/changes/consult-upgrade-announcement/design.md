# 数字纸签与更新详情

适用原则：OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01。CTX-01覆盖层的焦点进入/关闭恢复仍保留；详情明确采用非模态，因此不锁定背景焦点，允许继续操作图谱。

主对象仍为原咨询；更新记录使用既有登记文件中的稳定ID。桌面右上角为232px、暖白纸面#FFFEF9、浅边框#E9E5DB、10px圆角及极浅阴影的小纸签，顶部14–16px低饱和图钉，不旋转。默认仅“近期升级”、最新一条标题及“查看更新详情”，无日期、列表、长段正文。位置在工具栏下方24px，不参与图谱缩放、拖动和布局。

点击纸签或历史咨询旁“更新”入口，打开352px非模态详情抽屉，无背景遮罩，无进场动画。完整记录按日期倒序、同日保持登记顺序，独立滚动、关闭与Escape可用；打开后焦点进入，关闭返回实际入口。点击背景不关闭详情，不停止咨询、清空草稿或移动图谱；全屏复用既有Portal容器。窄屏隐藏纸签，仅保留工具栏图钉“更新”入口；详情限制宽高，末项键盘滚动可达。

纸签关闭按钮在Hover/Focus时显示，按账号ID保存当前批次到本机localStorage。当前批次身份为最新日期全部记录ID的组合，新增日期或同日新增重大记录重新显示，更正同一ID文字不重新打扰。仅影响浏览器展示偏好，不跨设备同步，不发请求。存储失败仍在本页收起，刷新后可再显示。工具栏入口始终存在，打开详情会恢复纸签；重复打开复用原列表，不重复创建记录。无数据时不渲染纸签和详情。

更新数据和登记规则保留，说明仅压缩措辞而不扩大能力承诺。未部署或未验收和资源依赖写入摘要；公告不代表验收。无新后端、数据库或公告管理系统，不改变交付/发布/重启授权。
