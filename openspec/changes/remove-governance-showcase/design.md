# 设计

按前端 manifest 单一事实源删除模块，侧栏、首页和路由随注册表退出，不增加隐藏开关或新的导航入口。功能权限目录排除展示型模块，重新核对生成目录保持一致。

适用产品原则：NAV-01（删除不再使用的导航目的地）、DENS-01（减少菜单负担）、CTX-01（其他工具与会话上下文保持不变）。不增加弹窗、对象操作或新的键盘与移动端交互，没有原则例外。

移除独占的 Reveal.js 依赖、专用静态资源及文档，历史实现仍可从 Git 查询；通用 ShowcaseLayout 和其他展示型能力保留。

验收采用现有菜单注册表测试、目录一致性检查、类型检查和生产打包。依赖移除影响构建，因此执行前端打包；不新增仅镜像删除动作的测试，不重启服务。
