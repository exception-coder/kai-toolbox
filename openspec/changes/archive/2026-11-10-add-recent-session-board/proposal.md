# 最近会话看板

## Why

最近会话导航只提供切换入口，待发送队列依附当前会话。用户需要集中了解最近工作、正在运行的会话，以及已经挂上队列但尚未发送的任务。

## What Changes

- 在 Vibe Coding 现有工作区增加“会话看板”页签，按最后活动时间倒序展示最近 20 个有效开发会话。
- 展示会话标题、项目、引擎、运行状态、活动时间和服务端待发送任务摘要，支持进行中、待发送筛选及进入对应会话。
- 复用现有会话与队列只读接口，按账号和会话隔离缓存，渐进显示队列结果，错误不显示为零。

## Impact

- 仅影响 claude-chat 前端、相关说明与定向测试；不改变队列派发、会话恢复、权限、数据库或 Sidecar 协议。
- 不需要后端、Sidecar 重启或 SDK 发布；保持其他任务的改动及暂存内容。
