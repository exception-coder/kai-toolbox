# 避免大上下文每轮耗尽 WebSocket 重试

## 问题与目标

Forge 为每轮创建独立 Codex App Server 进程。长会话保留的图片使完整请求超过上游 WebSocket 消息限制；原生回退状态随进程退出丢失，下一轮再次重试五次后切换 HTTPS。目标是在开始主轮次及续问预测前按当前上下文体积选择传输，保留历史和正常小会话的 WebSocket。

## 范围

- Sidecar 官方 Codex 通道的传输预检与针对性回归。
- 不修改账号凭据、用户 Codex 配置、原生历史、代理、前端 WebSocket 或普通网络重试次数。
- 不重放已接受的轮次，不在本变更中重构进程池或自行实现 Responses 协议。

## 证据

见 [设计](design.md)：本机合成请求对照、原生 0.162.1 源码、实际会话字节构成和验证边界。
