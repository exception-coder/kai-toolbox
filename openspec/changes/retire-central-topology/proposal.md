# 退役公共知识图谱接入

## Why

公共知识图谱增加重复维护与运行依赖。用户要求 Forge 沿用新的团队套件规则，业务知识随所属项目维护。

## What Changes

- 移除 Forge 注入、查询和恢复公共拓扑 MCP 的路径。
- 团队更新仅同步现用套件，清理旧具名 MCP 注册。
- 咨询和需求分析按授权项目读取 Markdown 原文并定向核查源码，Graphify 按需使用。
- 项目工作台直接调用初始化 skill。旧状态与分析接口明确退役，保留历史记录可读。

## Impact

影响 Sidecar、团队更新、咨询、需求证据与项目工作台。接口退役使用 410，旧知识查询来源使用 RETIRED。源码交付与运行验收分开记录。
