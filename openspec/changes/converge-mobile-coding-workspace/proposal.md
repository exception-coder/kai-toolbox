# 移动端 Vibe Coding 信息层级收敛

## Why

当前聊天区域同时显示工具活动、文件变更、运行条与指标，监督和记录状态继续挤占输入区。用户要求对话优先、执行信息按需查看，保留全部功能。

## What Changes

- 普通助手消息扁平化、缩小头像与间距，次要操作收进更多。
- 日常执行活动集中至单一 Agent Dock；运行指标和队列按需展开，异常保留。
- 已结束轮次以弱色摘要显示，指标进入该轮详情；与当前执行分开标明。
- 手机聊天不常驻监督和记录大小横栏；相关能力仍在推进页及 Dock。
- 压缩固定操作区，输入自适应并限高，维持至少 44px 触摸入口。

## Impact

仅调整会话前端呈现，不合并/删除执行事件，不改后端记录、执行、队列、监督或 AI 编程架构契约。桌面完整视图、专注模式和原有个人偏好保持兼容。
