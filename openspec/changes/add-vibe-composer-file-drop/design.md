# 设计

## 对象与入口

适用 OBJ-01、CTX-01、FEED-01、CTRL-01、IDEM-01。主对象为当前会话，身份沿用 `sessionId`；文件通过既有上传 API 与附件草稿归属该会话。直接扩展全屏与悬浮窗完整输入区，无新增导航、选择会话步骤或弹框。精简语音模式不新增落点。

## 行为与恢复

文件进入输入区后出现轻量主题边界与「松开即可添加附件」，离开、放下、失焦或换会话即清除。放下只上传文件并追加附件，不发送消息、不替换输入草稿。上传状态与完成附件继续显示在原附件列表。

共用 `useComposerFileUpload` 负责选择、粘贴及拖放上传。每批同步预留剩余名额，计入原会话上传状态；成功追加后释放一个名额，失败也释放，防止连续拖放或两视图并发超过原 10 个限制。异步结果使用发起会话的 setter；换会话不串入新会话，迟到错误不出现在新会话。

超额文件不上传，成功部分保留，失败明确显示文件名和服务端原因，可重新拖入、粘贴或选择。锁定会话、演示模式、无有效会话仍不可上传；后端大小与权限校验保持原样。文件夹不递归读取，明确提示拖入具体文件。落点外仅阻止文件导航，不上传；普通文本和 URL 拖动不拦截。

一次原生 drop 只交接一次；同一文件再次主动拖放视作用户再次添加，沿用已有附件创建语义，不声称具备服务端幂等或断网自动重试能力。请求结果未知时不自动重发，用户核对附件后再重试。

## 结构与边界

主会话“更多功能”内显示照片和文件两个可见的原生 file input；照片使用 image/* 筛选，文件保留全部类型，两者共用原上传 Hook 和附件名额。不再将透明控件叠在图标上，也不以隐藏 input、标签转发或脚本点击作为唤起路径。浏览器绘制原生选择按钮；外围标签仅提供名称。取消或空选择不上传、不关闭菜单或清空草稿；选中文件后复制 File 数组、清空选择值并关闭菜单，允许再次主动选择同一文件。上限与会话锁定保持原禁用条件。此兼容调整沿用 OBJ-01、CTX-01、FEED-01，无新导航、配置或权限边界；自动化 DOM 验证不能证明某款手机实际弹出了系统选择器。

`ComposerFileDropZone` 处理拖放及临时反馈，`useComposerFileUpload` 复用原 API 与 `attachmentDraftPref`。两处大页面仅做组合，不复制上传循环。无整体架构影响，沿用既有附件与会话契约；不改变上下文分层、工具权限或交付生命周期，无需改写整体 AI 编程架构说明。

## 验证

组件与 Hook 测试覆盖嵌套落点、失焦、外部落点、文本原生行为、文件夹、并发名额、部分成功与会话切换。现有 ChatPage 用例验证真实输入区上传、草稿保留和不自动发送；沿用附件、输入框回归。TypeScript 与功能边界检查验证两处接线。

选择器与粘贴继续提供键盘及触屏替代；拖放提示不抢焦点、关闭错误入口可聚焦。无新增覆盖层焦点协议。真实桌面系统拖放、主题与窄屏视觉尚待浏览器验收；当前浏览器访问被已保存权限策略阻止，不绕过。自动化 DOM 测试不等同于浏览器验收。
