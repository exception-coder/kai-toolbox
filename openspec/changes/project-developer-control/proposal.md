# 项目编码门禁由开发者控制

## Why

写入执行、范围、分支和规格绑定的缺陷可能相互阻塞，开发者需要独立于执行锁的正式恢复入口。仅修复单个错误码无法保障编码可继续。

## What Changes

- 自动监督面板提供项目级编码门禁开关，同项目会话共享，默认启用。
- 关闭时编码准入与监督治理前置检查返回明确跳过结果；保留原记录和真实测试状态。
- 原子保存操作者、原因、版本和历史；过期面板不能覆盖最新状态。
- 重新开启恢复现有检查。服务重启、资源访问和生产授权仍独立执行。

## Impact

影响 Sidecar execution/MCP 准入、Java 自动监督、会话面板和整体架构契约。没有提供模型切换门禁的 MCP 工具，没有删除写入记录或修改业务会话文件。
