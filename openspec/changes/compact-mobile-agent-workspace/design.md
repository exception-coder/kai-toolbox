# 移动端 Agent 工作台设计

## 对象与原则

主对象是当前 sessionId，复用 Chat Runtime、原队列操作、监督查询与语音传输。适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、CTRL-01、IDEM-01，无授权边界例外。

页面顺序：现有会话标题 → 信息视图导航 → 可伸缩消息主区 → Agent Dock → 两行输入区。消息主区是唯一常驻阅读滚动区，详情抽屉独立滚动，使用 Shell 分配的剩余高度，不猜测顶栏高度。普通 375×812 目标消息区域占可用空间至少 60%；键盘、多行草稿、附件、待确认及真实语音恢复是必要空间例外。

## 渐进展示

Dock 复用 MobileSessionStatus 的全链路事实，不使用历史完成结果冒充空闲。默认 40px，显示状态与队列数量；暂停有明确文字。抽屉显示当前命令、运行建议、用量入口、队列操作和 OpenSpec 绑定/监督操作。无队列显示空状态。监督及队列写操作仍调用原能力，展开/关闭本身不触发发送。

移动端运行中发送按钮打开发送方式，默认动作是加入队列；支持补充的官方 Codex 无附件会话才显示当前轮补充。手机回车仍换行，桌面回车运行中仍排队。停止保持单独可发现入口。不新增自动发送开关，避免引入未经约定的队列生命周期变更：正常收口继续、异常暂停。

空闲语音按钮通过 Dock 触发已挂载的 NativeVoiceControl，关闭抽屉不卸载通话。连接/恢复/错误显示原控制与反馈。仅确实连接过的会话记录恢复提示，切换不能把旧通话状态记到新 sessionId。

全局 AI 胶囊通过公开的 launcher CSS part 在移动端对话页上移 128px，避开默认 Dock 和输入控件，保留拖动与原面板入口；长草稿或活动语音仍允许手动调整位置。

## 恢复与验证

复用 Radix Sheet 的焦点约束、Escape 和关闭入口；Dock/发送抽屉关闭后恢复触发器。草稿与附件归原会话所有，展开/返回不清除；改会话重新挂载 Dock。发送前复用现有禁用与能力条件；失败、断线、等待确认不被省略。

核对移动窄屏、矮屏、桌面、队列长内容与异常暂停；测量主区高度和横向溢出，验证发送方式、取消、停止可达及焦点。语音用模拟传输回归；真实麦克风与目标版本服务部署未执行则明确标记。

覆盖层交互基线参考 [WAI-ARIA Dialog Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)（2026-10-02 查阅）。本次复用已有组件，无新增库或第二套状态源。
