# 工作助理

入口 `/tools/work-assistants`。机器人首页提供周报助理与资源管家；跨页面右侧助理坞或 `Alt+Shift+A` 唤醒，避开底部聊天发送区。入口按需加载，不切走 Vibe Coding 正在使用的会话。侧栏与首页菜单仍由 FeatureManifest 注册，后端启动同步菜单权限后才可给普通用户授权；资源管家首期仅管理员可使用。

助理坞默认收成右侧小把手，点击展开后点击机器人打开工作区，也可直接从把手拖出。拖动机器人可自由移动，拖到左右边缘松手会收起；展开时的箭头按钮可手动收到最近边缘。拖动不会打开面板，取消拖动恢复原位。键盘方向键移动，Escape 收起，Home 恢复默认位置，原唤醒快捷键保持可用。位置与收起状态按当前用户保存在本浏览器，不是全局配置；浏览器禁用存储时仍可在当前页面使用。旋转屏幕、缩放或软键盘改变可视区域时重新限制位置，安全区不放置按钮；打开工作区期间隐藏浮动入口，避免重复遮挡。

## 使用

- 周报：选择 1–5 个项目、作者姓名或邮箱、起止日期及 Claude/Codex 引擎，创建任务会话，再输入整理要求。日期按 Asia/Shanghai，包含结束日，最长 32 天；作者精确匹配姓名或邮箱。读取已有本地与远端引用，不 fetch/pull，不证明远端最新或已上线。最多每仓 500 条候选提交，超过采集规模明确拒绝，缩小范围后重试。
- 多轮修改：继续当前任务使用相同证据和 Skill 快照。换周期、作者、项目或重新采集时开始新任务。每个任务最多 20 轮、有界上下文；结果可复制或下载 Markdown，不提供自动代发、Word/PPT/Excel 生成或定时执行。
- 资源：安全登记支持原资源中心的中间件实例及应用站点账号。可将逐行 `host/port/database/username/password` 键值文本粘到专用安全框，本地解析后清除原文，核对已有系统分组、环境、地址和账号后确认保存。其他账号类别尚未接入。重复资源不覆盖，回原资源中心修改；登记不测试连接、不改咨询绑定、不授予生产执行权。
- 输入：语音复用现有转写服务，点击录音、停止后回填草稿，核对后手动发送；未授权或服务不可用有原入口提示。支持单个不超过 256 KiB 的 TXT/Markdown/CSV/JSON 拖入并附加到草稿，合计最多 12000 字符，Office 文件未接入此助理。不要在普通消息或文字附件里放密码、Token、私钥，明显凭据会在服务端保存前拒绝；规则不能保证识别所有未标注秘密。
- 关闭面板保留当前用户在本标签页的会话选择和普通草稿，后台任务继续。刷新后从任务历史恢复已保存输入和结果；未发送草稿仅内存，不承诺跨刷新保存。安全登记表单关闭会清除未保存密码。失败输入保留，可回填草稿核对后重试；取消是明确操作，不由关闭窗口替代。

## 实现边界

后端位于 tool-claude-chat 的 `workassistants`，平台逻辑会话、Skill 全文与 SHA-256 在独立表保存，不创建第二套引擎。每轮通过 AgentOneShotRunner 显式交接 Skill、有界历史及证据，工具策略固定 `disabled`，不声称延续原生 thread 或引擎自动加载 Skill。两个可信 Skill 随后端制品发布，首期没有任意 Skill 上传或动态编辑入口。

资源保存位于 tool-ops，通过公开 HTTP 入口登记；前端不导入其他 feature 私有 API，后端没有 tool-to-tool 依赖。新写入凭据使用原仓储的 AES-GCM 封装；历史明文兼容读取，在下次保存转换，不批量改历史数据。密钥默认 `${user.home}/.kai-toolbox/secrets/ops.key`，可通过 `toolbox.ops.credential-key-file` 指定，文件限制服务账号访问。备份或迁移数据库必须同时安全保留该密钥；丢失时恢复原密钥，不能用新文件解密旧密文。旧密文、损坏密钥与错误密钥均拒绝解密。不要将数据库、密钥或运行产物提交 Git。

平台会在后端启动后将运行中的助理任务标为中断失败，不自动重发。会话、请求与当前用户绑定，单会话最多一项运行，主机最多四项助理任务；请求标识幂等，取消后迟到结果不覆盖取消状态。列表最多显示最近 100 个会话；详情最多 20 轮。API 权限在服务端检查，模型提示词不是授权边界。

代码、测试与部署状态见 [OpenSpec 任务](../../../../openspec/changes/work-assistants/tasks.md)。目标版本尚未重启、真实账号与语音及窄屏浏览器验收未完成，不把构建或测试替身当作生产可用证明。
