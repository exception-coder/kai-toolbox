# 设计与边界

适用OBJ-01、CTX-01、FEED-01、AI-01、EVID-01、CTRL-01。用户明确要求评测不阻止开发迭代发布；没有对资源授权和只读边界的例外。

ConsultAgentManagementService按稳定agentId选择发布策略：business-consult不要求评测，其余Agent保持原策略。列表快照与release执行使用同一领域校验，避免界面允许而接口拒绝。AgentReleaseGate保留已登记/可用/只读能力及MCP提供方绑定检查，咨询返回最低分0表示无分数门槛；评测运行、分数、通过标记保持原值，不补造运行或将false改true。

沿用CANDIDATE到PRODUCTION的原事务、发布历史、重复发布当前版本幂等及回滚。教学Agent禁止通用发布的原保护不变。前端发布候选按钮仍要求已保存、无未保存草稿且安全校验通过；数据库变更清除旧评测，可直接发布，显式提示评测仅供参考。失败沿用草稿保留和刷新核对原版本。ADMIN与原Agent管理权限不放宽。

流程资源选择发布仅对新咨询生效，旧咨询保留冻结快照；实际查询逐次校验系统绑定、启用状态、允许环境与只读策略。评测属于产品候选参考，不改变仓库开发验证、服务重启授权或部署规则。本次只实现该行为，不发布真实候选、不执行数据库、不重启服务。
