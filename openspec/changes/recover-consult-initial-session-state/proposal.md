# 修复业务咨询初始会话恢复失败

## Why

业务咨询出现“会话状态加载失败”并锁定入口。代码回归证实：新开发会话没有 SDK ID、历史咨询没有创建人时，不可变集合的空值查询会使两个会话列表接口返回 500；前端还将辅助运行列表错误提升为整个咨询入口的阻断条件。

## What Changes

- 列表投影兼容尚未建立的 SDK 身份及未知创建人，保留原记录与访问过滤。
- 咨询历史决定恢复哪个咨询；开发会话列表仅提供运行提示，不再阻断初始恢复。
- 咨询历史失败时仍锁定新建入口，重试成功后恢复原咨询，不重发问题。

## Impact

涉及 claude-chat、fore-consult 的列表投影与咨询页面初始化；不修改数据库结构、资源选择、引擎权限或会话发送协议。代码修复、部署和真实会话验收分别记录。
