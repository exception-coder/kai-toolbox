# Vibe Coding 输入区拖入附件

## Why

全屏聊天与悬浮窗输入区只能通过文件选择器或粘贴添加附件。用户希望直接把本机文件拖到当前对话，减少选文件步骤。

## What Changes

- 两处完整输入区接受系统文件拖放，显示落点提示；保留原选择、粘贴和手动发送。
- 共用既有上传 API、会话附件草稿和上传计数，整批先预留名额。
- 显示数量超限、上传失败、锁定会话和文件夹不支持的恢复提示。
- 输入区以外的文件落点不上传，并阻止浏览器跳转打开文件；文本拖动保留浏览器原行为。

## Impact

仅影响 `frontend/src/features/claude-chat`。不修改后端、文件权限、大小限制、发送与排队规则；不发布、不重启服务。
