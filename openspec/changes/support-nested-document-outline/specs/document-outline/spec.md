## ADDED Requirements

### Requirement: 文档章节大纲支持全部章节深度

文档浏览器 SHALL 在现有大纲中按正文顺序展示 h2 至 h6，以实际标题层级缩进，并允许用户定位到对应正文标题。

#### Scenario: 含三级编号的深层标题

- **WHEN** Markdown 的“3.3.1 普通对象与集合响应”被渲染为 h4
- **THEN** 大纲显示该章节，位于其 h3 父章节后并进一步缩进，点击后定位到该 h4 正文

#### Scenario: 更深标题与非章节内容

- **WHEN** 文档包含 h5、h6、h1 文档标题及代码块中的标题文本
- **THEN** 大纲显示 h5、h6 章节，不将 h1 文档标题或代码文本加入章节列表

### Requirement: 深层标题更新兼容既有章节身份

文档大纲 SHALL 自动反映异步加入和移除的 h2 至 h6 标题，保留显式锚点及既有 h2、h3 自动锚点的生成结果，使新增深度不改变原章节备注关联。

#### Scenario: 深层章节不改变旧锚点

- **WHEN** 文档的 h2、h3 之间存在 h4 至 h6 标题
- **THEN** h2、h3 的自动锚点与仅提取 h2、h3 时一致，深层章节使用独立锚点

#### Scenario: 深层标题异步加载与移除

- **WHEN** 预览节点异步加入带显式 ID 的 h4 标题，随后移除该标题
- **THEN** 大纲先展示并复用该 ID，移除后清理对应入口，没有章节时显示既有空状态
