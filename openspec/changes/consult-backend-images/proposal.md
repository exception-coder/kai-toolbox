# IT 客服后端原图与回复候选

## 目标

沿用业务咨询应用凭据与异步任务，接收原图并交给多模态模型，按需直接生成三条可独立选择的通俗回复。各接入方使用自己本机的 Forge、管理员配置和凭据；Forge 不发送飞书、不修改业务数据。

## 范围

- 应用身份上传 PNG/JPEG 原始字节、不透明附件 ID、元数据恢复、隔离、有效期和清理。
- 分析请求增加可选 attachmentIds、replyMode；原图实际传递至已有受管执行器。
- FORGE 模式返回三条候选，保留结构化分析及真实证据；缺失/非法结果不得模板补齐。
- SDK、OpenAPI、调用示例和交接说明同次更新。

## 验证边界

L3：涉及上传数据、应用/企业边界、持久化及跨系统兼容。代码和受控测试不代表真实模型已读图。重启须另行取得目标实例授权，真实图文验收单列。
