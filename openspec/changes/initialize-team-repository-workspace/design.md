# 团队仓库初始化设计

适用产品原则 OBJ-01、NAV-01、CTX-01、FEED-01、CTRL-01、EVID-01，无例外。初始化在依赖仓库标题区，与推送和检查并列；按缺失数量显示操作名称，手机可换行。进入页面仍只查询状态，用户执行拉取时自动准备缺失目录。

复用 PluginUpdateService 的固定仓库白名单、路径检查、clone / pull --ff-only 和 SSE 进度。独立 `/repositories/sync/stream` 不调用安装、构建、提交或推送链路。已有 origin 不自动切换，未提交修改与非 Git 占位报错并保留，其余仓库继续执行。整体失败/部分失败沿用现有结果显示与重试入口。

不改变 AI 编程架构或项目身份、治理契约；没有数据库变更。后端目标版本与端点运行验收需用户另行授权重启，本次不触发。
