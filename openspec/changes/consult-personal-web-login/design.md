# 设计

咨询面板内按需展开“本次咨询使用个人账号”，填写应用地址、明确环境、账号密码和可选同源登录页。保持原咨询上下文，适用OBJ-01、CTX-01、AI-01、EVID-01、CTRL-01、FEED-01，无例外；复用现有Input/Button和主题Token，键盘原生details展开，移动端44px控件及有界滚动。不把密码发送给模型，不读取聊天已有密码自动登录。

fore-consult拥有本人鉴权与内存授权：RequireAuth加owner精确匹配，管理员不豁免。每咨询最多一个随机personal引用，最多32个内存授权；15分钟固定有效期，不延期、不写数据库。重启后失效。模型调用既有consult_web DISCOVER/READ，签名会话限定引用；跨咨询、过期、归档或系统切换不可复用。退出和定时过期通过common的closePersonal/closeContext清理浏览器上下文。替换账号先释放旧状态；同一失败授权沿用现有不重试规则，用户修改表单重新提交是新授权。

ops复用既有targetPath及环境策略验证个人目标，必须唯一关联当前系统，不依赖公共账号绑定。允许LOCAL/DEV/TEST/UAT；已登记生产/未知站点禁止以测试环境覆盖。对未登记站点，环境是本人明确声明，平台未独立核验；网页证据携带该环境来源边界，不宣称测试数据代表生产。个人URL来自本人表单，不开放模型任意目标或密码参数。未登记站点仅允许可解析的公网HTTP(S)标准端口，回环/私网/链路本地/共享地址拒绝；内网及非标准端口需先将站点地址绑定到当前系统，可使用本人密码而非公共账号。登录失败不向调用者返回页面正文。

browser-request继续复用隔离Playwright、Cookie登录态和页面/只读GET接口读取，仅允许已识别登录请求写方法；对于未配置登录API的个人账号，仅在登录阶段识别同源POST、末段为login/signin/authenticate/token/session等常见登录端点且请求体包含本次两个精确凭据的JSON/表单请求，不开放任意POST。跨域SSO、验证码、任意脚本与业务写操作不支持。GET副作用仍需目标接口源码/文档核实。页面与接口内容视为不可信证据。密码字段只写反序列化，DTO字符串隐藏内容，错误消息不回显引擎异常；客户端结束提交或关闭表单清空密码。

新增公共端口方法必须通过宿主编译，专项覆盖所有者和跨咨询、撤销过期、系统切换、生产限制、密码序列化、实际Chromium Cookie释放及前端失败恢复。沿用[Playwright隔离上下文](https://playwright.dev/java/docs/browser-contexts)，不新增浏览器执行引擎。未获本次重启授权，不重启；真实个人账号登录待目标版本加载和用户本人填写，不以夹具通过代替真实站点验收。
