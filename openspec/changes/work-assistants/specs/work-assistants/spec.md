## ADDED Requirements

### Requirement: 独立助理会话
系统 SHALL 为当前用户保存助理会话和绑定的 Skill 快照，复用平台引擎且不切换编码会话。

#### Scenario: 重复唤醒
- **WHEN** 用户连续点击同一机器人或重新进入
- **THEN** 复用最近会话，恢复草稿与任务状态，不重复执行；显式新任务创建独立会话

#### Scenario: 跨用户与并发
- **WHEN** 请求其他用户会话，或在同一会话运行时提交不同任务
- **THEN** 服务端拒绝；相同请求 ID 返回已有任务

### Requirement: 记住助理项目选择
系统 SHALL 在当前浏览器按账号、助理类型分别记住上次项目选择，仅保存项目 ID，恢复时只采用当前可用目录中的项目。

#### Scenario: 重开、刷新和目录异步加载
- **WHEN** 用户选择项目后重开面板、新建任务或刷新，目录尚在加载后完成
- **THEN** 恢复仍可用的原选择，不被初始空目录清除；周报最多 5 个，资源所属系统最多 1 个
- **AND** 手动清空会保存空选择，原文、密码和需求正文不进入该偏好

#### Scenario: 账号隔离与存储不可用
- **WHEN** 切换账号、原项目已不可用或本地存储损坏/被禁用
- **THEN** 不显示其他账号的选择，不采用无效项目；存储异常不影响当前表单操作，不承诺跨设备同步

### Requirement: 周报事实受控
系统 SHALL 仅从获准的目录与明确时间、作者收集 Git 事实，关闭模型工具执行。

#### Scenario: 越界或超量
- **WHEN** 项目被排除、范围超限或 Git 输出截断
- **THEN** 明确失败并要求修正范围，不生成貌似完整的周报

### Requirement: 安全资源登记
系统 SHALL 通过专用安全输入预览并确认登记原资源，不把密码交给对话模型或会话存储。

#### Scenario: 确认与重复
- **WHEN** 管理员核对目标后确认保存并重试同一请求
- **THEN** 只创建一次记录，返回资源 ID 与原管理入口；新写入凭据加密保存

#### Scenario: 自然描述和主机登记
- **WHEN** 管理员选择 DEV/SIT/PROD 环境，可选所属系统，并粘贴地址、已标注账号密码或连接串
- **THEN** 在本地识别已支持的词表/连接语法并显示不含密码的摘要；缺失或环境冲突时只提示补充
- **AND** 确认后复用原资源/主机仓储，重复请求复用回执，不测试连接、不执行命令、不改变咨询绑定；不支持的私钥或 Token 指向原管理入口

#### Scenario: 环境独立于系统和粘贴内容
- **WHEN** 管理员不绑定系统，粘贴内容没有重复声明环境
- **THEN** 使用界面明确选择的环境，允许登记；未绑定连接在原资源中心可见并可沿原 ID 编辑，不创建占位系统
- **AND** 内容环境与选择冲突时提示核对并阻止预览，不静默覆盖；明确填写的系统仍须存在，目录加载失败不阻断无系统登记

### Requirement: 自然需求直接开始周报
系统 SHALL 在用户选择项目后允许以一段文字或语音描述作者与周期，校验后直接采集并发送首轮，不要求作者/日期/引擎表单作为默认前置步骤。

#### Scenario: 已选项目与周报模板
- **WHEN** 用户勾选项目或点击“本周 / 上周”
- **THEN** 已选项目稳定排在前面，未选项目保持目录顺序；周期切换保留原作者与其余要求
- **AND** 初始输入为可编辑模板，作者占位符未替换时不得提交，不猜测登录账号对应的 Git 作者

#### Scenario: 上周个人提交
- **WHEN** 用户选择获准项目并输入“看看我上周张凯的提交”
- **THEN** 提取明确作者张凯，按上海日历计算上一周的周一至周日，仅从所选项目采集并基于事实生成
- **AND** 模型不获得工具或资源写权限，执行引擎和模型设置默认折叠

#### Scenario: 缺项与响应未知
- **WHEN** 无法确定作者或周期，或首轮提交响应丢失
- **THEN** 缺项时追问且不采集、不创建会话；响应未知时保留原输入并使用相同消息请求重试，不创建第二份任务或覆盖后续草稿

### Requirement: 常驻与可恢复交互
系统 SHALL 提供机器人首页、跨页入口及按需语音转写，关闭面板不取消任务。

#### Scenario: 语音或失败
- **WHEN** 用户转写语音或任务失败
- **THEN** 转写先回填草稿，任务失败保留输入与明确恢复入口，不自动发送或重复写入

#### Scenario: 移动与收起入口
- **WHEN** 用户拖动浮动入口、将其拖到左右边缘或点击收起
- **THEN** 入口可移动并贴边收起，拖动不会打开助理；收起后可点击展开或拖出，取消拖动回原位，不修改会话和任务

#### Scenario: 移动端与本地偏好恢复
- **WHEN** 同一用户再次进入，或软键盘、缩放和屏幕尺寸改变可视区域
- **THEN** 在本浏览器恢复该用户的位置与收起状态，入口保持在可见安全区域内；存储损坏或不可用不阻断操作，键盘可移动、收起及恢复默认位置
