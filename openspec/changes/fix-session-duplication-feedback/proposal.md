# 修复会话复制及操作反馈

## Why

普通复制被 Auth 链路复用逻辑收敛回原会话，点击后可能没有副本；菜单关闭后缺少持续进度，最近会话没有同一动作。

## What Changes

- 普通复制显式创建独立配置副本，继承源会话目录、引擎、服务商、Auth 和分组；Auth 切换继续复用原链路。
- 点击后立即显示复制进度，真实 Ready 后展示结果；错误或超时保留恢复说明，不生成虚假成功。
- 最近会话和项目会话使用相同复制入口，移动端及悬浮窗保持一致。

## Impact

会话列表、Socket 复制状态及后端复制语义。无数据库迁移、原生历史复制、服务重启或自动模型调用。
