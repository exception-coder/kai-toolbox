## ADDED Requirements

### Requirement: 项目验证节奏
系统 SHALL 在现有项目控制中提供功能检查点和逐任务验证，默认功能检查点；改变节奏不得改变门禁开关或验收要求。

#### Scenario: 兼容及并发
- **WHEN** 旧项目无节奏字段，或旧客户端仅更新门禁
- **THEN** 缺省使用功能检查点，更新门禁时保留已有节奏；跨会话修改须验证当前 revision 并审计

#### Scenario: 逐任务验证
- **WHEN** 项目选择逐任务且下一任务属于关联验证组
- **THEN** 新生成的续跑交接仅授权当前一个任务，包含其验收描述

### Requirement: 有界任务收口
Runtime SHALL 将匹配的当前任务或授权批次验收描述交给 Agent，并提示引用有效证据、失败定向重验与功能节点收口。

#### Scenario: 门禁关闭后重复派发
- **WHEN** 同一 task 多次派发且完成数未变化
- **THEN** 交接提示核对已有成果和剩余验收，不新增自动暂停，不自动勾选，不授权无关任务

#### Scenario: 设置结果未知
- **WHEN** 保存失败或前端连接旧版服务
- **THEN** 界面显示可恢复错误或禁用不支持的设置，不显示未经确认的新状态
