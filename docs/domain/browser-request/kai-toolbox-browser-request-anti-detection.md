## 业务定义

部分目标网站（如带有商用反爬虫防护的招聘类网站）会检测浏览器自动化工具在底层调试协议上的特征动作；标准的自动化浏览器控制方式一旦被识别为自动化工具，页面会被目标网站直接崩溃处理为空白页，导致后续操作全部失效。

为规避这种检测，"站点录制编排"提供了一条"反检测"的浏览器引擎通道：这条通道下的浏览器进程与控制方式经过特殊处理，避免触发前述被检测的底层动作特征，从而能够正常操作目标页面而不被识别。

一旦某个浏览器会话选择走这条反检测通道，后续所有对该会话的操作（打开页面、执行动作、截图、点击、抓取录制等）都必须统一经由这条通道完成，不能再混用标准的自动化控制方式去操作同一个会话——否则同样会触发检测。

## 适用范围 / 边界

该反检测能力只在用户/系统为某个会话选择了"反检测引擎"时生效；使用标准引擎的会话不涉及这条规则，也不具备规避能力。这是关于目标站点反自动化检测机制与相应技术规避思路的既定事实与工程约束，不随具体某一种反检测实现方案的更替而改变结论本身（即"标准自动化控制方式会被检测、需要专门通道规避"这一事实）。
