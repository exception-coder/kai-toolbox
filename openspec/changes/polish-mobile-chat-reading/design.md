# 设计与边界

本次为 L2 有界前端改造，复用 MessageList、WorkspacePreferences、MobileSessionStatus、SessionBoardDock 与 AssistantHost。

## 产品原则

- DENS-01：去除手机 AI 正文外壳，正文默认 16px / 1.55，消息间距 20px。舒适与紧凑分别采用 24px / 1.6 和 16px / 1.5，不做页面缩放。
- CTX-01：切换阅读偏好前捕获可见消息 ID 与偏移，布局更新后恢复；会话改变后丢弃旧恢复。列表不因偏好重建。沿用既有草稿、虚拟分页、只在贴底时跟随的机制。
- OBJ-01、AI-01：悬浮面板继续使用真实会话看板及其队列数据，不读取推进规划或复制任务状态。原来的 28×44px 窄边缘入口、拖动吸附、位置记忆与键盘避让保持。
- CTRL-01：AssistantHost 通过公开接口委托入口，只在已授权且手机聊天看板挂载时隐藏助理独立入口；退出聊天或卸载时恢复。工作助理仍由原宿主管理权限、草稿、表单关闭确认及懒加载。
- FEED-01、EVID-01：运行摘要继续展开既有详情，错误仍有结构化容器。预览入口不是浏览器验收。

无原则例外。不改变上下文分层、权限判断、引擎协议、证据或开发交付生命周期，因此无需修改整体 AI 编程架构说明。

## 实现

阅读密度与字号使用两个独立浏览器存储项，经 useSyncExternalStore 同步，存储拒绝时原位提示且不假报保存。只对手机 Coding 消息流应用 CSS 变量；桌面、公开评审、工具结果与代码字体不受影响。主题仍管理色彩与语法高亮，阅读设置不写主题或动效配置。

输入区最低高度由 88px 减至 80px，保留 44px 操作触控目标和 16px 输入字号。复用原来的 VisualViewport、安全区域、输入框高度与运行详情抽屉，避免另建布局系统。

会话看板入口从全局聊天浮层移动到 AppShell 的 AssistantHost 内，避免兄弟挂载节点无法消费授权 Context。该快捷入口仅在工具外壳出现，公开展示页不挂载；全局聊天运行时、跨布局悬浮聊天和后台权限问题浮层不移动。

## 验收边界

组件回归覆盖消息操作、错误可见性、阅读位置、偏好独立持久化与存储失败、会话切换、悬浮入口委托和工作助理权限。构建与接口门禁不能证明真机键盘及视觉效果；Android Chrome、iOS Safari、飞书 WebView 和桌面真实浏览器验收仍需明确执行记录。
