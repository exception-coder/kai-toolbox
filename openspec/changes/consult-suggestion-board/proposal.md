# 业务咨询需求反馈与建议清单

## Why
业务人员需要在咨询平台反馈使用建议，避免零散口语化反馈难以转成清楚的需求描述。清单应统一可见，并保留原始表达和整理结果。

## What Changes
- 增加普通登录用户可见的需求反馈入口，以及桌面画布右下角轻量建议卡片；手机从更多功能进入同一抽屉。
- 通过既有AgentOneShotRunner禁用工具的纯文本能力，将建议整理成标题、问题、期望和可选完成标准；支持编辑确认与手动提交。
- 咨询模块自己持久化待评审建议，分页读取并保留原文。需求池现有端口直接创建待执行任务，不适合未经评审的建议，因此不自动复制。
- 登录身份由服务端获取；相同用户与提交标识幂等重试，草稿按用户保存在浏览器会话存储。

## Impact
fore-consult新增独立suggestion功能包和幂等启动schema，无人工执行迁移，不登记待执行SQL。不新增模块依赖或菜单权限目录项，不触发发布、外部通知或服务重启。
