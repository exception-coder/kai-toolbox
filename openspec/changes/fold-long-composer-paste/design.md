# 长文本粘贴折叠

## 范围与交互

Forge 主会话输入区粘贴至少 2000 字符，或至少 500 字符且 20 行的纯文本时，将本次粘贴片段显示为文本卡片。适用于 Markdown 和普通文本，不做不可靠的格式猜测。文件、图片与短文本沿用原有粘贴路径。

卡片显示首个非空行、字符数、展开编辑和删除操作。卡片之外继续输入补充说明；移动端卡片占独立一行，下方保持原有单行输入操作。连续长粘贴只折叠最新片段，之前片段恢复普通文本，避免引入附件列表管理。

## 数据与恢复

`useDraft` 中仍保存完整原文，发送、排队、持久化不改变。卡片不是上传文件，不占用附件名额，不注入占位符。显示层记录当前文本快照与折叠区间；可见文本编辑与引用插入映射回原始位置，不隐式删除折叠内容。删除卡片只删除该片段。

展开、切换会话、刷新或外部草稿改动恢复完整文本；折叠状态不持久化。已有草稿、附件与 Agent 状态继续由原有所有者管理。

## 原则与边界

适用 [产品交互原则](../../../docs/product-philosophy.md)：CTX-01 保留输入上下文，DENS-01 按需展示长文本，FEED-01 显示标题与数量及恢复动作，NAV-03 就地编辑、不新增菜单。无原则例外。L2 局部兼容交互变更，不改变 AI 上下文分层、执行或交付生命周期，整体架构说明无需修改。

实际运行和手机/桌面视觉验收与源码检查分别记录于 [任务](tasks.md)。不为验证自行重启服务。
