# 设计

## 对象、入口与权限
适用OBJ-01、NAV-01、CTX-01、FEED-01、CTRL-01、IDEM-01、AI-01、EVID-01，无例外。对象为ProjectCatalog项目ID；咨询候选与排序仍由现有已保存配置投影，不建立新列表事实源。入口位于原管理抽屉，普通用户看不到且服务端要求ADMIN。

GET `/api/fore-consult/source-sync`只发现当前前8个候选；前端顺序POST `/api/fore-consult/source-sync/{project}`，服务端每项执行前按当前候选重新解析真实目录并核对ProjectAccess，fetch后快进前再次核对。未保存的编辑不生效，界面明确说明。批量读取后被隐藏或排除的项目不能继续拉取。

## 复用边界
ConsultSourceSyncService通过目录共享检查状态及GitPullOperations。不再把内部同步逻辑绑定到runtimeId，而是注入本次授权根解析器；会话路径规则不变。管理员入口跳过五分钟时间缓存但不能跳过running互斥。相同目录正在同步时返回SYNCING，不再fetch。只对当前分支配置的上游安全快进，无stash、reset、rebase、切分支或索引重建，不改资源权限。自动与手动结果都只代表检查时源码，不证明部署版本。

## 交互与恢复
使用现有主题token与44px触控按钮，结果按项目逐项出现。加载时禁用重复按钮，并阻止抽屉关闭以保留结果入口；关闭后恢复配置触发器既有焦点管理，咨询草稿不变。检查无变化、已快进、跳过、同步中和结果未知分别展示。一项失败继续其他项目；断连不能推断未执行，显示结果未知并允许整批重新检查。再次点击重新读取已保存候选并刷新证据，不创建后台任务或新对象；稳定身份为规范目录，依靠共享检查状态与现有Git仓库锁避免并发变更。结果保留到抽屉关闭，不承诺跨刷新持久化；刷新后可安全重新检查。

## 验证
定向验证ADMIN拦截、隐藏/排除/未知项目拒绝、缓存绕过与复用、fetch后撤权不快进，以及UI逐项顺序、部分失败和重复点击。复用既有真实临时Git仓库安全快进测试，不在开发验证时拉取真实业务项目。桌面/手机预览入口只证明入口生成，不代表目标版本已启动、登录或运行验收；服务重启仍需当次明确授权。
