## ADDED Requirements

### Requirement: 图片预览具有可发现的关闭操作

咨询图片预览 SHALL 独立于咨询面板的层叠上下文，始终展示带「关闭」文字的按钮，不被移动顶部栏或图片盖住。按钮触控区域不小于 44px，并避让安全区域。

#### Scenario: 手机查看长截图

- **WHEN** 用户打开咨询或历史中的图片
- **THEN** 顶部展示图片预览及关闭按钮，图片等比占用剩余可用空间
- **AND** 点击关闭或黑色背景可退出，点击图片不退出

#### Scenario: 键盘与原生全屏

- **WHEN** 用户在桌面或原生全屏查看图片
- **THEN** 关闭入口与图片一起保持可见，Escape 可以退出
- **AND** 退出后恢复原触发位置的焦点（若仍可聚焦）
