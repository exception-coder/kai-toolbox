# 实现与验收边界

L2，有界的内部执行及 SDK 回放增强。职责沿用 fore-consult 应用服务、模型适配器、AgentTelemetry 和 SDK，不增加业务表或替换队列。外部应用仍经既有凭据认证、项目授权和异步任务准入。

## 执行观测

执行摘要使用 clientId、requestId、taskId 关联。记录队列等待、证据与图片准备、模型、结果校验、保存和取消请求耗时，以及模型策略版本、实际提示词摘要、调用方规则摘要和模型输入输出字符数。运行实现使用分析相关 class 的摘要标识，不能以工作区 Git HEAD 冒充已加载构建版本。Token 和人工认可率仅在真实来源提供时统计。

沿用 OTel 异步导出和开关，阶段 span 与既有模型 span 建立父子关系。默认关闭时摘要日志仍可用于分组统计，日志仅含受控标识、配置、摘要、计数、耗时和错误码。异常正文、业务原文、图片和账号目录不进入新增观测。执行器完成、业务结果校验、最终任务状态分别记录，取消保持执行器终态确认后释放名额。

## 内部载荷

完整请求仍用于准入、持久快照和幂等。模型 question 保留身份、授权项目、回复模式与业务规则，描述、近期上下文、分类、报错、附件文字和业务资料通过已有 evidence 传递。保持证据 ID、来源及顺序；原图元数据与真实字节保持一一对应。压缩前后验证内容完整、体积和合同；真实回复差异待业务样例回放。

模型内部将描述和业务资料以结构化 content 承载，保留 recentContext 列表、分类及业务 JSON 的条目边界。对外响应仍由原 Packet 生成 text，ITCS 继续读取原 evidence 合同。

## 真实回放

在 SDK 示例目录提供可恢复的回放适配，调用现有上传、submit、find 和 get。应用凭据来自现有环境变量，目标地址由操作者指定并沿用 SDK TLS 限制。案例文件提供完整分析输入、可选本地原图和人工参考。输入及上传检查点在网络副作用前保存，未知响应使用原键恢复，结果查询有截止时间，截止后保留任务以便再次查询。已终态的回放只读恢复，另建对比轮次须显式使用新 requestId 和输出目录。

该入口复用真实生产合同，避免从内部直接绕过应用授权。模型及策略使用目标实例当前配置，记录响应 policyVersion；人工参考属于待核对资料，不自动生成通过结论。原始报告保存在操作者指定的私有目录，控制台只输出摘要。

## 产品原则

适用 AI-01、EVID-01、CTRL-01、IDEM-01。对象为应用及其 requestId/taskId，回放沿用现有公共接口。失败和未知状态明确保留，无新增页面、键盘或移动交互。输入变化与重复执行分别按新键和原键处理，无例外。

## 验证

定向覆盖载荷完整、同步和异步合同、观测脱敏及失败阶段、图片字节映射、回放未知响应恢复和已完成结果复用。依赖装配变化验证宿主编译。真实案例、目标版本加载、观测导出和模型配置比较分别保持待验收，服务重启遵循当次授权。
