# 会话提交记录推送

## Why

Vibe Coding 的提交记录只能查看，用户需离开会话才能推送。项目库已具备绑定快照的安全推送，可以复用。

## What Changes

- 在全屏和浮窗提交记录中提供分支推送预览、确认、结果与恢复入口。
- 会话接口从服务端工作目录与所选子仓库解析目标，通过共享 GitPushOperations 端口复用项目库实现。
- 保持固定 SHA、上游目标、非强制、有界执行和仓库级互斥规则。

## Impact

影响 shared Git port、项目库推送服务适配、会话 Git controller 和通用提交记录面板；无 DDL、SDK 或引擎路由变化。不改变 AI 编程上下文、自动提交或授权生命周期。实现与上线验收分别记录。
