# 规格任务的有界推进与并行交付

## Why

执行范围已支持并行，但结束检查仍读取整个暂存区，其他任务的暂存可阻断已提交任务。正式规格使用全局版本，缺少已审阅依赖的局部失效方式。续跑虽带验收描述，却没有携带上轮持久的剩余工作和证据，恢复建议也未形成统一字段。

## What Changes

- 增加按执行范围提交入口，保留其他任务暂存、真实 Git hooks 和提交后核对；结束检查与普通提交检查分开。
- 支持显式完整规格依赖，旧记录仍保守检查并通过正式重评估迁移。
- 将原持久报告投影为有界任务检查点，复用现有上报和监督状态。
- MCP 和生命周期错误统一返回恢复类别与下一工具，不原样自动重试。

## Impact

影响 Sidecar 执行/规格工具与 Runtime 交接；不直接更新业务任务、不代替人工确认、不推送、不重启、不自动释放他人 writer。
