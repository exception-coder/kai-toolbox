# 公开链接与已登录菜单的读取

公开网页复用 Vibe Coding 的临时 Chromium。平台根据当前咨询、用户的实际消息和本轮工具装配绑定网址与链接文字。恢复会话时，账号说明、模型回答、网页和附件都不能指定操作。用户明确要求再试刚才的点击时，可以引用同一咨询紧邻的用户请求。浏览器返回实际打开的地址、标题或失败原因。

已登录菜单走原有 `consult_web READ`。每次按当前咨询、账号绑定、环境和来源核验读取权。工具只接受菜单的可见名称，在隔离页面中展开能确认为导航的折叠控件，读取实际可见条目。名称歧义、需要联网加载或无法确认结果时，保留证据缺口。已有只读接口可在用户允许时继续作为独立证据。

连续点击从最近可用的同一咨询浏览器成功回执恢复落地页，再应用本轮用户选定的操作。用户只是想试一下菜单是否可点时，独立浏览器可以选择导航区内一个可见的同源链接，回报实际选中项与落地地址。具名操作按用户指定的文字匹配。

已登录页面中的传统列表菜单也可展开。工具先在内存中为同一账号保留点击前的登录状态，再将当前页断网，点击指向本页空片段、紧邻唯一子列表的分类标题，核对实际可见的条目。操作后关闭接收点击的上下文。后续读取沿用先前的登录状态，重新校验目标页。工具区分新展开、原已展开、未找到控件与点击后未取得可见条目。

要求检查业务站点登录状态或展开账号菜单时，咨询先发现与站点、环境及账号匹配的绑定，再通过同一绑定读取页面。账号检查失败时，原咨询提示在「我的系统账号」检查登录。恢复旧咨询也在当轮接收这条规则。

沿用 OBJ-01、CTX-01、AI-01、EVID-01 和 FEED-01。操作在原咨询发起，用户沿用当前会话和账号。无须新增入口，桌面和手机均使用原消息输入与回执。用户可补充准确名称再试。公开浏览器只接收本轮的公开网址与操作范围，业务系统登录态留在原账号工具。
