## ADDED Requirements

### Requirement: 会话视图按使用频率收纳

平台 SHALL 在桌面主栏显示对话、推进、用量、会话看板，以及适用的文档和评审；轨迹和站点 SHALL 通过更多进入。手机 SHALL 保留对话、推进、会话看板和更多，并保持文档、用量及适用评审的可达性。

#### Scenario: 从更多查看当前会话
- **WHEN** 用户选择更多中的轨迹或站点
- **THEN** 平台在当前会话打开原有视图，更多标示当前视图，草稿和后台执行保持不变

#### Scenario: 菜单恢复与断点切换
- **WHEN** 用户关闭菜单、选择视图或窗口跨越手机/桌面断点
- **THEN** 菜单关闭并保留可用触发器与键盘恢复路径；窗口变化不修改当前会话或视图

### Requirement: Vibe Coding 移除数据库前端能力

平台 SHALL NOT 在 Vibe Coding 提供数据库页签、SQL 管理或登记覆盖层、对应导览入口及自动查询轮询；平台 SHALL 保留已有台账数据、Agent 登记契约和独立数据库工具。

#### Scenario: 历史会话仍有待执行 SQL
- **WHEN** 用户打开曾关联 SQL 台账的会话
- **THEN** 聊天页不查询或呈现 SQL 功能，也不删除、取消或修改原台账
