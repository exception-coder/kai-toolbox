# 会话复制反馈设计

适用 OBJ-01、NAV-01、CTX-01、FEED-01、CTRL-01、EVID-01、IDEM-01；无例外。

主对象是用户点击的源 Forge 会话 ID，不增加对象列表。普通复制拥有独立 Auth 链路；切换 Auth 的显式交接仍通过原 WebSocket 链路查找并复用。模型凭据只在后端复制。普通复制改用登录态 HTTP 命令，不依赖 Sidecar、引擎检测或能力清单初始化。

列表行复制一步启动，沿用源会话的 Auth；选择其他 Auth 仍使用当前会话配置里的切换入口。副本复制工作目录、模型运行配置、分组和附加目录，不复制原生历史、待发送队列或隐藏模型状态。

用现有模态框承载短时复制状态，点击立即显示进行中并阻止重复操作。浏览器先保存 requestId，再发送 `POST /api/claude-chat/sessions/{sourceId}/copy`。服务端复核登录用户与 ProjectAccess，源配置、副本 Auth 链路、附加目录、回执同事务写入；回执以用户加请求编号唯一，返回 requestId、sourceSessionId、targetSessionId，不返回凭据。单机服务在事务提交前串行处理复制，数据库唯一约束保留跨重启身份。重复编号绑定其他源返回冲突，副本已删除返回 410，不按旧请求重建。

HTTP 回执确认配置已保存后，前端才调用原 switchTo；引擎连接错误不能改写复制结果。每次请求等待最多十秒，网络失败或服务端异常以同一编号自动核对最多三次；未知结果保留编号供刷新或手动再次复制时继续核对，不搜索标题或会话列表猜测。明确 4xx 拒绝不自动重试；旧版后端 404 提示加载新版，禁止回退到非幂等 WS 写操作。离开源会话后迟到回执不抢回当前视图；成功切换依然保留源会话运行、草稿与队列隔离。Auth 切换的 Ready/交接语义不变，本次不宣称已修复其全部断线恢复。

复制中不以关闭暗示撤销；结果状态可关闭并恢复到当前工作区。Radix Dialog 管理模态焦点与键盘，适配全屏 Portal；窄屏宽度受视口约束、内容可滚动。验证同 Auth 的独立副本、Auth 复用、最近会话入口、延迟反馈、错误和断线边界；不将旧运行服务的响应记作新版验收。

复制的生命周期边界与正文流程同步到 AI 编程架构说明；不改变模型上下文分层、Agent 写入权或治理门禁。DDL 知识库核验为 PARTIAL：新回执表和 Auth 链路表未命中基线；本次按仓库实际 schema 定义与 SQLite 事务验证实现，不把基线缺失说成已核验的运行库事实。
