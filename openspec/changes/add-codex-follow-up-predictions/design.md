# Codex 续问预测设计

## 对象与入口

适用产品原则：OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、EVID-01、CTRL-01、IDEM-01；没有新增例外。主对象仍是当前 Forge 会话，关联选定 Codex 授权目录、原生 threadId 和已完成 sourceTurnId。建议依附现有输入框，不增加页面、页签或对象列表。

## 协议及进程

以固定 0.162.1 CLI 导出的实验 TypeScript schema 为代码契约：请求参数为 `{ threadId, sourceTurnId }`，请求响应仅表示接受；随后通知携带同一身份以及 `completed`（text 可为 null）或 `failed`。公开文档暂未解释账号开放范围，不能把 schema 存在当作真实账号已验收。

主轮次完成、原进程关闭后启动可取消的预测进程，恢复同一原生 thread，仅调用预测请求，不调用 turn/start 或工具。复用当前模型/配置，但禁用 MCP 并使用只读沙箱。最多等待 15 秒，失败仅记录有限诊断，不修改主任务终态和队列。

预测进程按授权目录与原生 thread 去重；新轮次先取消它并确认进程释放，避免新增 writer 冲突。无自动重试，重复回调和取消后通知不投递。回传仅包含 Forge sessionId、sdkSessionId、sourceTurnId 与验证过的纯文本，不保存到消息历史、模型上下文或持久缓存。

预测清理超时后保留原进程的退出观察器；下一次发送只重新等待同一进程的 `close`，不再次强杀、不重跑预测。确认关闭后删除失败任务并允许后续发送，仍未关闭则继续明确拒绝，未知异常原样传播。并发核验共享同一次等待；PID、退出码和关闭状态写入有限诊断，不记录命令参数或凭据。此恢复路径保持原有单 writer 契约。

主对话、预测及一次性能力查询共用从 spawn 即开始的关闭观察器。`exit` 只证明包装进程退出，不能替代包含输出管道关闭的 `close`；协议读取结束时移除消息处理器，继续排空 stdout 和 stderr，避免尾部输出反压阻塞退出。等待超时只结束当前观察，原进程观察器仍有效；多个等待不反复给子进程添加 close 监听器。包装进程先退出时，给剩余协议输出一个有界读取窗口，再判定异常，不能丢掉缓冲中的最终响应。

主轮次关闭失败同样按授权目录、Forge 会话和原生线程保留屏障，后续手动发送也必须重新核验，不能仅禁止 SDK 自动重试。原进程 close 后移除相应屏障；已经接受的 turn 不自动重放。预测取消会继续检查取消期间替换进来的任务，全部释放后才返回。一次性查询先自然关闭 stdin、排空输出并确认 close，超时才使用既有兜底；释放失败保留查询错误和清理错误，不能返回伪成功。上述为进程适配器内部修复，不引入常驻 App Server 池或另一套会话系统。

依据为安装版本的 [Node.js 子进程事件](https://nodejs.org/download/release/v24.16.0/docs/api/child_process.html) 与 [readline 关闭语义](https://nodejs.org/download/release/v24.16.0/docs/api/readline.html)。[官方 App Server](https://learn.chatgpt.com/docs/app-server) 提供交互客户端的线程、轮次及审批协议；本修复保持现有集成方式，不用替换 SDK 掩盖本地管道和释放状态错误。

Java 在当前引擎为 Codex、会话空闲、原生句柄及最后完成锚点相符时投影事件。浏览器再次核对当前会话、原生句柄及锚点；切换会话、开始新轮次、切换引擎或账号时清除建议。已有草稿、附件、输入法组合态、运行中、评审/咨询/一次性任务均不受建议影响。

## 交互与降级

浅灰建议与实际草稿分开，Tab 或采纳按钮只写入输入框并恢复焦点，绝不自动发送或加入队列。斜杠和项目引用菜单优先处理键盘；Shift+Tab、修饰键和输入法不采纳。Escape 可关闭建议，输入自己的文字后建议失效。失败或无内容恢复普通输入提示，不弹错误覆盖层。

没有建议时保持既有输入框布局；有建议时仅增加安静的键盘/触屏采纳提示。窄屏不横向溢出，手机可点击采纳。草稿、附件、停止与原有 Enter 逻辑不变。

## 验证边界

验证原生请求/通知身份和取消、超时、空结果；用输入框回归确认 Tab 不发送、IME/菜单优先与切会话隔离。定向编译、升级 schema 检查及质量门禁后提交。浏览器可以验收前端展示；新 Sidecar/后端运行及真实账号预测验收须在本次用户确认重启后完成，不自动重启。
