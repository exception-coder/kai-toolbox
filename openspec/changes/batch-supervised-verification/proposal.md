# Why

关联小任务逐项交接和重复调用相同测试降低自动监督编码效率。已有 Runtime 按 change 收口执行最终门禁，但缺少明确的同轮任务批次和工具级成功证据复用。

# What Changes

- 用显式 VERIFY_GROUP 标记关联任务，Runtime 基于当前快照下发有界批次。
- 连续实现后统一验证，保留逐任务验收及人工后置边界。
- 相同执行及完整输入下复用本地成功命令，提供强制重验与实际执行/复用标识。

# Impact

涉及 session-autopilot、Sidecar 执行验证、宿主交接、Skill 和规格生成规则。没有数据库迁移、生产操作或自动重启。暂不实现自动依赖图、跨执行缓存和自然语言任务相似度推断。
