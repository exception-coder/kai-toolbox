## ADDED Requirements

### Requirement: 本人个人账号持久绑定
系统 SHALL 允许本人在进行中的咨询保存与用户及系统关联的加密个人站点账号，同一用户后续同系统咨询可复用；只接受明确非生产环境，不把用户声明当作独立环境核验。

#### Scenario: 本人保存账号
- **WHEN** 本人填写合法站点、环境、账号密码
- **THEN** 经所有权与目标范围校验保存加密绑定，每用户每系统一个当前账号；替换后旧引用失效
- **AND** 密码不写聊天、公共凭据库、工具参数或响应，保存与登录结果分别展示

#### Scenario: 跨咨询与账号隔离
- **WHEN** 同一用户在后续进行中的同系统咨询发现账号
- **THEN** 可复用本人绑定，无需15分钟后重新填写；重启不删除绑定
- **AND** 其他用户含管理员不能操作本人咨询或引用绑定，不同系统和已归档咨询不能复用

#### Scenario: 过期检查与恢复
- **WHEN** 读取发现此前成功的登录态失效，返回401或可见登录页
- **THEN** 重新登录最多一次，失败后暂停自动尝试，由本人检查登录或更新账号恢复
- **AND** 浏览器context释放不删除持久账号；状态查询仅显示历史检查，超过60秒标为待检查，不把绑定当作在线证明

#### Scenario: 解除绑定
- **WHEN** 本人解除绑定并退出
- **THEN** 关闭context并删除该用户该系统密文绑定，后续咨询不能再复用；失败不得提示成功

#### Scenario: 长时间等待
- **WHEN** 登录、状态查询、检查或解除绑定60秒未返回
- **THEN** 页面结束等待并提供恢复入口，不宣称服务端已取消；登录未知结果先查状态不重复提交，迟到响应不覆盖超时结果
- **AND** 后端状态查询不等待浏览器操作锁，重复账号操作快速拒绝

#### Scenario: 页面与接口排查
- **WHEN** 用户要求以个人账号排查
- **THEN** 优先用本人绑定读取限定站点页面或只读GET接口，不用公共账号冒充本人结果
- **AND** 生产/未知环境、跨源目标、业务写请求仍受限
