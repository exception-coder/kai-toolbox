## Design

NAV-01、CTX-01、FEED-01、DENS-01，无原则例外。主对象是现有 FeatureManifest 的功能路由；复用同一 Sidebar 和公共导航，不建立新目录。移动 Sheet 向 Sidebar 注入关闭回调，普通主键点击在 React Router 原有导航之前关闭；点击当前功能同样关闭，慢加载不会阻挡反馈。Ctrl/Cmd/Shift/Alt 及已阻止的点击不抢占浏览器原行为，桌面不注入关闭回调。

搜索先关闭模态 Sheet 再触发原命令面板事件，避免抽屉的焦点/指针限制留在另一层界面之上。Sheet 继续使用原遮罩、Portal 和键盘约束，增加44px关闭按钮；记录实际触发元素，关闭后恢复可连接触发器焦点。路由变化关闭的原有兜底保留。

不修改页面草稿、会话、权限和执行状态；所有点击只导航或打开已有搜索能力，不创建业务对象。验证当前路由、延迟模块、搜索、显式关闭、焦点与修饰键，浏览器窄屏核对实际命中与关闭。当前路由无变化的复现不依赖网络或后端。
