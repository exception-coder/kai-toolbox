## ADDED Requirements

### Requirement: 项目绑定的只读代码审阅
系统 SHALL 从已登记项目或当前会话关联仓库打开统一 Project Explorer，继承项目上下文、现有权限与排除政策，不接受客户端指定任意根路径；窗口 SHALL 提供目录、提交与工作区独立视图，关闭和 Esc 恢复原上下文。

#### Scenario: 查看目录与历史
- **WHEN** 用户浏览目录或翻页提交历史
- **THEN** 系统按目录/页有界加载，以不可变提交快照关联后续查询；选择提交显示其文件列表和新增/修改/删除/重命名语义。

#### Scenario: 审阅单文件
- **WHEN** 用户选择变更文件
- **THEN** 仅加载该文件前后版本，默认 Unified 且允许 Split；删除展示删除前内容，重命名展示原路径，不提供修改或 Git 写操作。

#### Scenario: 查看尚未提交变化
- **WHEN** 用户进入工作区
- **THEN** 系统分清 HEAD、暂存区、工作树及未跟踪文件，允许选择比较层，不将其作为已提交历史。

#### Scenario: 无法安全完整展示
- **WHEN** 文件为二进制、编码不支持、超过上限、路径越界或请求失败
- **THEN** 系统明确提示原因并提供适用的返回/重试；不显示截断 Diff 为完整结果，不读取项目外文件，不修改项目文件或 Git 状态。
