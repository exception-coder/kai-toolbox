# 项目代码审阅窗口

在当前项目或会话中直接打开 Project Explorer，统一查看已跟踪目录、分页提交历史、提交文件清单与只读源码差异。工作区变更独立展示，支持区分暂存区和工作树。项目列表与会话继承原对象身份，不增加全局模块或重新选择文件系统路径。

新增有界的 Git 只读查询与统一三栏覆盖层。默认 Unified，可切换 Split，按文件读取源码，删除显示原文，重命名显示原路径；不提供编辑、终端或 Git 写操作。现有 Git 操作入口继续承载 Push/Pull 等不同目的动作。此次新增源文件读取面，按 L3 核验项目绑定、路径越界、输出上限及读取不修改仓库。分支间比较沿用现有 Git 能力，审阅窗口内任意两版本比较后续按实际需要接入。
