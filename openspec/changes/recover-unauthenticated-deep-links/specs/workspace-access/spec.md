## ADDED Requirements

### Requirement: 未登录模块深链返回可操作首页

系统 MUST 将未登录的工具模块访问替换为工作台首页，MUST NOT 渲染受保护内容或发起需求专属授权请求。公开展示页维持原有行为。

#### Scenario: 从分享链接访问工具模块
- **WHEN** 未登录用户打开带查询参数的模块链接
- **THEN** 当前历史项替换为首页，首页展示直接登录入口
- **AND** 浏览器返回不会再次进入刚被替换的模块链接

### Requirement: 登录和权限拒绝均具备恢复操作

首页 MUST 复用现有登录能力，失败可重试、取消可继续停留首页，成功后显示当前账号可用功能。已登录用户的权限校验 MUST 保持有效。

#### Scenario: 账号无模块权限
- **WHEN** 已登录用户访问未授权模块
- **THEN** 不展示该模块内容，并提供返回工作台首页的链接

#### Scenario: 账号已授权
- **WHEN** 已授权用户访问模块链接
- **THEN** 保留原有路径、查询参数和锚点
- **AND** 需求专属授权与控制模式校验继续按原规则执行
