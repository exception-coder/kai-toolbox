## 业务定义

LLM 监控回答的核心问题是"这段时间 LLM 被怎么用了、花了多少、稳不稳"，具体的统计口径约定如下：

**统计维度（三选一）**：汇总数据只能按下面三种维度之一分组呈现，不支持任意组合：
- 按**模型**：看每个具体模型各自的调用量/花费/表现。
- 按**档位(tier)**：看每个档位整体的情况（同档位下可能有多个模型互为备份，档位维度看的是这一层整体用量）。
- 按**调用来源(工具)**：看是哪个业务功能/工具触发的这些调用。

**错误率的定义**：错误率 = 异常失败的调用次数 / 总调用次数。这里的"异常失败"专指调用记录状态里的"异常失败"，不包含"配额拦截"（配额拦截根本没有真正发起调用，不计入错误率的分子）。

**默认统计区间**：不额外指定时间范围时，默认看的是"今天从 0 点到现在这一刻"，而不是最近 24 小时或全部历史。

**趋势图（时间序列）的粒度**：支持按"小时"或按"天"两种颗粒度分桶展示变化趋势，可选看的指标是 token 消耗量、调用次数、花费金额、错误次数这四种之一。

## 适用范围 / 边界

- 成立范围：LLM 监控页面/接口对外呈现的所有汇总类统计（总览、趋势图）。
- 不适用：单条调用明细的查询/筛选不受"三选一维度"限制，可以按状态、模型、来源工具等多个条件组合筛选，这条口径只约束"聚合汇总"这一层的分组方式。
- 特例：如果指定了自定义的起止时间，默认"今天"这条口径不生效，以用户指定的区间为准。
