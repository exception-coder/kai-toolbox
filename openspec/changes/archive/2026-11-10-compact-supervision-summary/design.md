# 监督面板布局

## 阅读路径与范围

Health → Progress → Risk/Blocker → Context。状态头合并 Runtime / Skill；正在监督只显示停止，暂停或待处理显示恢复，现有预算耗尽恢复入口保留。项目编码门禁使用局部 compact 变体，其他页面维持原展示。

主体为单列，不给每项套 Card。桌面指标四列，手机两列；状态、待办与批次纵向流动，由原页面承担滚动，面板不创建嵌套滚动或猜测可用高度。触控与折叠摘要至少 44px；长规格名、路径与错误可换行。

## 指标与证据

完成度 = completedTasks / totalTasks，高完成度仍为正常主色。轮次 = turnCount / maxTurns，使用达到 90% 预警；监督窗口条表示剩余时间占原开始到截止窗口比例，剩余不足 30 分钟预警。已结束运行不继续显示消耗中的窗口。无有效上限或时间显示未知，不设置虚假的 aria-valuenow。

上下文占用尚未由监督接口提供，显示“未提供”，不拿累计 Token 或缓存命中率代替。批次复用调用方已有任务查询，有真实 tasks 才投影完成度和人工标记；仅有当前 run 时只展示当前项已知计数，其他项明确未提供。未来接口补全不改变展示语义。

需要处理仅展示明确 deferred、未完成人工标记、运行异常或预算到限；普通进行中说明放折叠上下文。完成的人工项不再计入；数量按待处理规格与运行问题计算。失败展示实际来源及重试，正常提示不反复强调。

## 产品原则

DENS-01：稀疏上下文折叠，异常前置；OBJ-01/CTX-01：保留当前会话、项目与恢复入口；FEED-01/EVID-01：保存与读取失败诚实呈现，未知指标不伪装为 0%；CTRL-01：既有停止/恢复与项目开关继续由原接口负责。无原则例外，无后端行为修改。

## 验收

验证桌面高屏、短屏、手机，检查横向溢出、末项可达、折叠键盘操作、单主操作及读取失败恢复。隔离使用真实组件和构建 CSS，以模拟状态验证视觉；不代表新版后台已经加载或线上控制接口验收通过。
