# 设计

适用 OBJ-01、CTX-01、DENS-01、FEED-01、CTRL-01、EVID-01、IDEM-01，无例外。

1. 主对象为现有 sessionId 与当前草稿，复用 canSteerRunningMessage、steer 和 enqueue。仅官方 Codex 无第三方地址、纯文本支持插入；提交时再次检查，带附件或其他引擎进入队列。
2. 原输入区及发送菜单承载操作，不新增导航或弹框。桌面主按钮显示“插入”，不再隐藏主要动作；菜单提供排队，分屏和浮窗保持同一回车规则。
3. Enter 默认提交并优先插入，Ctrl/Cmd+Enter 排队，Shift+Enter 换行；触屏 Enter、输入法确认不提交。空输入、上传中和计划锁沿用保护。按钮说明指明插入会影响当前作业。请求结果和失败沿用原 Socket 提示及队列，不将前端调用称为模型已接受。
4. 原菜单关闭与发送后恢复输入焦点，保留手机可触达的明确选择；用已有页面回归覆盖键盘、插入与队列、输入法和不可插入场景，组件回归覆盖菜单关闭恢复；浏览器隔离样例检查真实组件的桌面/窄屏布局，不向真实运行任务注入测试文本。
5. 发送沿用现有 messageId，未增加并发协议或重试路径，不改变既有队列项及调度身份。本次不将已排队记录自动转成插入，避免改写用户已选择的任务去向。项目架构职责和上下文契约不变。
