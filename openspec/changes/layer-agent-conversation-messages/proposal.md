# Agent 消息层次与视觉锚点

## Why

手机消息与背景同色、边界全无，连续技术文字难以辨认信息单位。逐条常驻操作又分散注意力。

## What Changes

- 主 Coding 工作区每条助手回复用薄面板承载：主题内容底色、弱边界、10px 圆角、无阴影。
- 使用原文已有小节组织变化、验证与产物，不生成事实或成功状态；流式输出保持完整。
- 手机只在消息头常显更多，复制、分叉、转卡片按需打开；桌面悬停与键盘聚焦揭示操作。
- 保留主题、暗色、完整原文、链接、代码、图片、历史导航与工具详情。

## Impact

仅 claude-chat 消息展示与交互；不新增 Agent 输出协议、模型请求、后台状态或全站主题，不改变 AI 编程架构契约。
