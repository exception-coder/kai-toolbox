## ADDED Requirements

### Requirement: 管理员浏览与下载主机文件
系统 SHALL 通过已登记主机的 SFTP 连接返回实际目录，严格验证 SSH 主机密钥，限制文件与列表大小，并在结束或失败后释放连接。

#### Scenario: 未信任的主机
- **WHEN** SSH 主机密钥不在服务账号 known_hosts 中或已改变
- **THEN** 拒绝连接且不上传文件，提示检查信任配置

#### Scenario: 不支持的文件
- **WHEN** 请求下载链接、目录或超过 20 MiB 的文件
- **THEN** 拒绝请求，不读取其内容

### Requirement: 有证据的备份替换
系统 SHALL 要求替换目标的原摘要，先验证暂存上传，再保留备份后改名；失败 SHALL 尝试恢复并保留诊断编号。

#### Scenario: 未确认或目标已变化
- **WHEN** 已存在目标但没有匹配原摘要
- **THEN** 拒绝上传，不静默覆盖

#### Scenario: 最后改名失败
- **WHEN** 原文件已备份但暂存文件改名失败
- **THEN** 尝试恢复原文件；无法确认结果时提示核对目标和备份

#### Scenario: 切换目录
- **WHEN** 用户准备替换后打开另一个目录
- **THEN** 清除替换目标及摘要，恢复新增文件模式
