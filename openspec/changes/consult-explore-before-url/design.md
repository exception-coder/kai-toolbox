# 无 URL 时先自主定位

`source_context` 已支持不带 URL，通过问题与模块查询 Graphify；无需增加工具或放宽目录边界。修正工具描述中的 URL 优先歧义，在共用 `ConsultOrchestrationContext.renderPrompt` 末尾加入统一定位与追问规则，覆盖 V1–V4、已发布流程及冻结流程的后续追问，不改写存量流程快照或数据库。

截图与业务文案先用于收敛知识、模块与候选，菜单知识未命中后继续图谱查询、候选源码读取；只有范围已明确且仍缺实现证据时才限定子目录搜索。已有有效证据复用，证据充分即停止，无新线索不重复查询。仍无法区分页面、存在关键歧义，或定位工具不可用且线索不足时，说明已核对内容和剩余问题，再索取 URL 等最少信息。静态实现不能证明具体单据的运行根因。

适用产品原则：AI-01 使用已有业务能力，EVID-01 区分实现与运行事实，FEED-01 明确缺口与恢复动作；无例外。属于现有咨询定位规则修正，不改变 AI 编程架构的组件职责、上下文分层或权限契约。提示词测试只能证明规则已装配，不能证明模型一定执行；需在目标版本启动后用无 URL 截图问题实际回归。
