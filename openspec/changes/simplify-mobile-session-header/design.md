# 设计

Page Anatomy：手机默认 48px 顶部（导航 / 会话名称与视图展开 / 状态点 / 更多）→ 消息流 → 原 Execution Dock 和 Composer。原 44px 页签行不再常驻。会话导航展开显示完整会话名、引擎与连接状态、对话 / 推进 / 看板分段选择、其他已有视图和对话方式入口；以既有中性主题为主。

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01，无例外。主对象仍是当前 session ID，视图仍由原 SessionView 路由维护，手机与桌面共用视图定义。选择视图不创建会话、不发送消息或修改模型参数；重复选择复用现有视图。当前会话及未发送草稿保留，选择后关闭浮层并恢复触发器焦点。展开会话导航时收起更多；选择视图时隐藏新建表单但保留表单草稿。进入桌面断点收起手机浮层，原桌面页签可见。

选择覆盖层是为了让低频导航按需出现，而非另建页面、平行工作状态或全局项目列表。工作目录菜单复用现有提交记录弹窗，并把返回焦点设为仍可见的更多按钮。重命名仍从会话工具进入，编辑状态使用原输入框。分屏标题保持中性，不暗指某个会话；专注阅读保持原独立标题。未选择会话时只提供全局会话看板及对话方式，不暴露不可用的会话视图。

浮层使用现有 Radix Popover：可通过按钮、Enter / Space 展开，通过 Esc、外部点击或选择关闭；保留展开语义和焦点恢复。参照 [WAI Disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)，查阅于 2026-10-14。选项至少 44px，窗口限高且可滚动，长标题折行，不增加请求、加载状态或新失败恢复协议。数据异常继续由对应原视图处理。

验证使用既有 SessionViewTabs 和 ChatPage 用例，覆盖所有视图、细节视图归属、无会话、断点关闭、切换后的草稿及目录入口。浏览器验证 390×844、360×640、长标题和桌面布局，查看菜单可达性、Esc、焦点及横向溢出；真实会话仅打开关闭导航与只读入口，组合场景在隔离的生产组件中验收。浏览器模拟不等于真实华为设备验收。本次无 AI 编程架构契约影响。
