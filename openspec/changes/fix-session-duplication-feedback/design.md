# 会话复制反馈设计

适用 OBJ-01、NAV-01、CTX-01、FEED-01、CTRL-01、EVID-01、IDEM-01；无例外。

主对象是用户点击的源 Forge 会话 ID。复用现有列表、`duplicateSession` 和服务端配置复制，不增加对象列表。普通复制是用户明确要求的新副本，拥有独立 Auth 链路；切换 Auth 的显式交接仍通过原链路查找并复用。新增 `reuseAuthSession` 标明这两种意图，旧消息缺省保留原行为，新客户端普通复制明确传 false。模型凭据只在后端复制。

列表行复制一步启动，沿用源会话的 Auth；选择其他 Auth 仍使用当前会话配置里的切换入口。副本复制工作目录、模型运行配置、分组和附加目录，不复制原生历史、待发送队列或隐藏模型状态。

用模态框承载短时复制状态，点击立即显示进行中并阻止重复操作。成功以目标 Ready 为准，刷新原有列表并展示目标；失败显示原因，超时或断连标为结果未知，要求先检查会话列表，不建议直接重启或盲目重复创建。已发送的复制不在重连时自动重发，避免产生多个副本；尚未发送的请求可以在首次连接后发出。

复制中不以关闭暗示撤销；结果状态可关闭并恢复到当前工作区。Radix Dialog 管理模态焦点与键盘，适配全屏 Portal；窄屏宽度受视口约束、内容可滚动。验证同 Auth 的独立副本、Auth 复用、最近会话入口、延迟反馈、错误和断线边界；不将旧运行服务的响应记作新版验收。

这是普通会话操作修复，不改变 AI 上下文分层或治理/交付契约。
