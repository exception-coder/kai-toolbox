# 设计

## 控制点

`reconcileActiveRuns` 在派发前取得 SendDecision，只对 SIDECAR_UNREACHABLE、STALE 计入故障窗口。以 run ID + generation 隔离，正常忙碌/可派发状态清零；至少三次且跨度至少一分钟才通过版本 CAS 持久化 PAUSED、清理内部续跑队列并发布原有状态事件。CAS 失败不覆盖新状态，由下次巡检复核。用户消息、进度和正在运行的引擎不被取消。窗口为有界内存，后端重启后重新统计；已持久化暂停状态仍保留。

`jsonLineWriter` 为 stdin 安装局部 error 监听，同时处理 write callback、同步异常、已关闭流。一次故障只通知一次所属请求生命周期，清理 pending 请求；正常收轮后晚到错误仅消费。原有已接收轮次不得重放策略保持。
