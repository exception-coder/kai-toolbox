# Forge Android 与鸿蒙手机客户端

用户要求同时实现 Android APK 和鸿蒙原生客户端，当前设备为 Mate 60／鸿蒙 7。复用线上 Forge 工作台，增加系统文件／相册选择、复制文字与卡片图片、系统分享及按需麦克风权限。主机继续执行 Agent；不把手机壳当作手机端编码运行时。

当前只有 PWA，缺少原生工程；接口 `/api`、聊天 WebSocket 均依赖同源。两端分别使用官方 WebView／ArkWeb，既有工作台提供同一受限桥协议并保留浏览器路径。新增 `mobile/` 工程、构建与签名入口，不增加第二套会话、权限或项目配置。

本机未找到 Android／HarmonyOS SDK 或鸿蒙设备签名。源码开发、编译签名、安装与真机能力验证必须分别记录，不能把源码文件或网页单元测试记为可安装包交付。
