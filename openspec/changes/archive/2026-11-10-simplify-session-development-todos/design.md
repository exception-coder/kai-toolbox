# 设计

会话导航 → 更多 → 开发待办 → 内容卡片 → 需要时原位展开。新增仍是单层紧凑编辑框，仅有内容与图片；底部保存/取消，关闭保留草稿，放弃草稿可显式清空。标准密度，桌面有空间时两列，手机单列；卡片区域负责滚动，编辑框正文独立滚动而保存栏固定，首屏直接看到待办内容。

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、CTRL-01、IDEM-01，无例外。保留稳定会话/记录身份、用户隔离、未知写入结果与冲突恢复；不增加导航和状态模型。卡片不等于执行任务，不自动向模型发送或进入待发送队列。

新记录标题由内容首行截取最多 160 字，纯图片自动标记“图片待办”。时间在创建草稿时自动采集并保持稳定，保存重试不改变内容与创建身份；空卡片不能保存。旧记录已有标题、时间和元数据原样传回，来源、参与人与备注按需折叠查看。图片上传后采用临时 blob 缩略图，退出编辑时释放；关闭和刷新后的已上传附件 ID 继续保留。

列表沿用摘要分页，不批量逐条请求全文。展开某卡片时才读取全文和图片，不另建侧栏；旧回看链接不在当前页时仍能原位读取指定记录。引用保持当前会话草稿与来源追溯，单次最多 5 条。搜索保留，默认最新在前，取消排序和备注状态筛选。

前端变更不需要后端重启。验证复用现有用例，重点检查无主题的新建/纯图片、自动时间、空内容、保存重试、旧元数据和会话切换；真实浏览器在移动/桌面检查布局与保存失败恢复。隔离 UI 样例不视为真实服务器持久化验收。
