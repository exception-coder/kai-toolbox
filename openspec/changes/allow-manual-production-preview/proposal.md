# 管理员人工预览生产站点

## Why

Yoooni One 的 PROD 运行账号已登记，但预览列表只接受非生产环境，用户无法从会话打开该站点。账号没有丢失，缺口是人工预览和 Agent 测试访问共用环境过滤。

## What Changes

- 管理员的现有站点预览选择器展示已配置的 PROD 应用，打开前显式确认环境。
- 生产交付链接只打开设置；确认不从 URL 读取，切换账号清除确认。
- 拆分人工预览与非生产 Agent 账号端口，不复制资源或放开 AI 生产访问。

## Impact

影响 common 账号端口、ops 资源适配器及 browser-request 前后端；无数据库变更。复用既有账号、认证、上下文隔离及 TTL。运行生效需后端加载新版，本次不自行重启。
