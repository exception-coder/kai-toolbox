## ADDED Requirements

### Requirement: 可跳过并重看的功能导览
系统 SHALL 在Vibe Coding提供首次轻提示和会话工具顶部的功能导览入口，按开始开发、管理会话、查看执行、项目协作、交付结果、调整工作区六类说明真实能力、使用时机和入口，并提供可搜索完整指南。

#### Scenario: 首次与再次阅读
- **WHEN** 用户首次进入或主动打开功能导览
- **THEN** 首次提示可以跳过，导览支持上一步、下一步、关闭和完成
- **AND** 跳过或完成后当前浏览器不再重复首次提示，仍可从会话工具重看

#### Scenario: 查找与定位功能
- **WHEN** 用户开始简短导览或点击上一步/下一步
- **THEN** 系统自动展开当前步骤的真实区域，以遮罩、高亮框及旁侧说明浮层逐步讲解，无需点击独立定位按钮
- **AND** 关闭、跳过、完成或切换完整指南恢复原工作区视图与面板，保留消息和草稿
- **WHEN** 用户搜索完整指南
- **THEN** 系统显示匹配用途及路径，空结果可通过修改或清空搜索恢复
- **AND** 定位只展开已有视图或菜单并高亮，不能自动执行任务、重启、提交或其他写操作

#### Scenario: 前置条件与存储异常
- **WHEN** 当前没有会话或浏览器拒绝本地存储
- **THEN** 导览保持可读并说明前置条件，目标不可见仍可继续，不伪造执行内容
- **AND** 存储写入失败仍允许本次关闭并说明刷新可能再次提示

#### Scenario: 适应桌面和手机
- **WHEN** 用户通过键盘或触屏阅读与关闭导览
- **THEN** 内容与操作在窄屏可达，键盘焦点留在对话框并在关闭时恢复
- **AND** 专注模式归视图，工作区个性化归系统设置，不重复增加顶层操作
