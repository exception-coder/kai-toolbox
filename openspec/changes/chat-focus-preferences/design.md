# 专注模式与个人偏好

## 控制点

ChatPage 保留原 MessageList、Composer 和 runtime 实例，专注状态只切换展示；导航、监督条、运行状态和用量条由局部 data-focus-chrome 隐藏，停止生成及权限/问答对话框仍可操作。当前分屏/视图/附属面板在进入时记录，退出时恢复；草稿与附件不重置。顶栏 portal 在专注时归还页面内部，避免逃逸全屏；浏览器原生全屏使用现有 fullscreen portal 容器。

优先 requestFullscreen，不支持或拒绝时使用现有 fixed 视口布局。退出按钮、Esc 和原生 fullscreenchange 收敛为同一退出逻辑，退出后焦点返回会话工具。其他弹窗与输入菜单先消费 Esc；不将专注状态持久化。窗口降级时背景兄弟节点 inert，退出恢复原值，避免键盘进入不可见导航。

## 个性化

工作区个性化位于会话工具的“系统 · 设置”。最近会话默认状态存于当前浏览器 localStorage；缺失或不可读时默认展开，保存失败明确告知且不伪装成功。useSyncExternalStore 订阅同页事件和跨页 storage，已挂载侧栏立即应用；点击最近会话标题只做临时展开/收起，刷新或重新挂载回到偏好。无需另建服务器配置或项目数据。

## 交互与边界

应用 CTX-01（恢复视图/焦点/草稿）、DENS-01（对话优先）、CTRL-01（显式退出及浏览器降级）、FEED-01（保存失败可恢复）、OBJ-01（保留会话身份）。无原则例外。手机保留至少 44px 退出/设置操作区及安全区；MessageList 保持原滚动归属。不重启服务，不启动任务、不更改监督或生产授权。

## 验证

## 专注阅读布局

应用 CTX-01、DENS-01、CTRL-01、OBJ-01，无原则例外。专注视图保留消息列表与输入组件实例，以局部 CSS 和语义类切换布局，不改变普通聊天、草稿、附件、停止生成或权限弹窗。正文和输入 surface 使用同一中轴：860px 内容宽度加两侧 12px 留白；用户可显式扩展为 960px，手机按可用宽度收缩。宽度按钮仅改变展示，不触发模型请求。

顶部显示会话标题，复用按 sessionId 缓存的监督查询，展示真实 changeId/currentTaskId；未绑定、加载和失败显式显示，不根据消息文本推断。标题栏不包含启动监督或其他写操作。助手正文取消背景卡片、边框、阴影和头像框，保留角色时间；轮次统计改为灰色可操作文本，失败标记保持醒目。原列表运行 Footer 在专注时保留，避免隐藏状态栏后无法确认正在运行。长代码和表格在列内滚动。

个性化入口已经归入“系统 · 设置”，专注模式位于“视图”。本次无后端、数据库或 AI 架构契约影响，不重启或发布；前端仅用独立 Vite 构建验证，避免 assistant:release。

单元覆盖草稿 DOM 保留、背景不可聚焦及恢复、Esc、全屏拒绝降级、偏好跨挂载持久化和存储拒绝。浏览器核对桌面/手机、全屏/窗口降级、设置与刷新。在线服务不可用时保留明确限制，隔离验证不宣称生产会话验收。
