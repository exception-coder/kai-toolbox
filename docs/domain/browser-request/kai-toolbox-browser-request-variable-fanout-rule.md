## 业务定义

任务回放时，步骤间通过命名变量传递数据，变量解析与自动展开（fan-out）遵循以下规则：

- **取值优先级**：同名变量若同时存在"上游步骤提取出的结果"与"用户填写的运行参数"，优先取上游步骤提取出的结果；只有上游没有提取到时才使用用户填写的参数。两处都没有提供该变量值时，视为参数缺失，本次执行报错。
- **隐式数组迭代（fan-out）**：如果一个步骤引用的某个变量，其当前取值是一个数组（例如上一步用通配路径提取出一组值），系统会自动把该步骤按数组长度重复执行多次，每次迭代取数组中的一个元素替换该变量，其余变量沿用整体上下文。
- **单一迭代变量约束**：一个步骤内只允许出现一个"当前取值为数组"的变量触发自动迭代；如果同一步骤同时引用了两个及以上取值为数组的变量，视为不支持的用法，直接判为该步骤执行失败（无法确定按哪个数组迭代）。
- **迭代与提取的交互**：一个步骤在多次迭代执行中各自提取到的同名变量，以最后一次迭代的提取结果为准，覆盖之前迭代提取到的值，供后续步骤使用。

## 适用范围 / 边界

该规则只适用于任务"回放"阶段的变量绑定与执行展开逻辑，不涉及录制阶段。数组类型的变量本身只能整体用于触发迭代，不能被当作单一字符串直接嵌入 URL/请求体/请求头做替换（会被判定为非法用法而报错）。
