## ADDED Requirements

### Requirement: 业务咨询评测作为可选发布参考

系统 SHALL 允许管理员对已保存的业务咨询候选直接发布，不以评测运行、通过标记或95分为前提。

#### Scenario: 未评测或不通过仍可发布

- **WHEN** 管理员保存合法候选，其评测缺失、未通过或分数不足95
- **THEN** 候选发布资格和发布接口均不因评测阻断，界面显示评测可选及实际评测状态
- **AND** 不伪造评测运行、分数或通过结果，发布仍由用户显式触发

#### Scenario: 保存和发布边界

- **WHEN** 数据库选择尚有未保存草稿，或没有候选，或候选含不合法能力绑定
- **THEN** 不允许发布，仍保留保存草稿、能力校验、权限、发布历史和回滚边界
- **AND** 发布后仅新咨询使用已发布流程，旧咨询资源快照与每次查询的只读和系统绑定限制不变

#### Scenario: 其他Agent保持既有策略

- **WHEN** 发布其他Agent候选或调用教学Agent通用发布接口
- **THEN** 保留原评测策略和教学保护，不随业务咨询策略改变
