# 本地生产前端与提交后自动构建

## Why

公网当前提供 Vite 开发源码，首页需沿多个模块请求才能接管。用户要求本地运行生产资源，同时在修改完成后自动更新。

## What Changes

- Forge 的前端运行模式增加 static，默认仍为 dev；复用现有 Node/PM2、HTTPS、后端与控制器代理。
- 从已提交 frontend 树构建不可变候选，在独立依赖缓存和输出目录校验后原子发布。
- 检测本地提交及已有 Git 更新流程落地的变化，不新增 fetch/pull 或后端重启任务。
- 保留旧资源；构建失败保留旧版。业务页提示刷新，已知无编辑、无活动的首页空闲后刷新。

## Impact

新增运行能力，需同步启动说明、架构边界、OpenSpec 与专项测试。首次模式切换仍须用户明确授权，未执行的部署与公网真机性能不得标为已验收。
