## ADDED Requirements

### Requirement: 数字纸签按需展示重大升级

系统 SHALL 在业务咨询画布右上角提供轻量数字纸签，默认展示最近五项业务咨询板块重大能力升级的短标题，少于五项按实际数量展示；点击才查看完整业务咨询更新记录。纸签与详情 SHALL 仅展示实际业务人员直接受益的咨询重大变化，以业务用法和价值表述；SHALL 排除管理员账号配置、流程候选/评测/发布、源码与 Git 排障等咨询内部开发运维内容，以及全平台导航、通用开发交付、主机运维等其他模块更新及普通修复；历史误收内容仅留档，不参与展示。

#### Scenario: 默认纸签与窄屏入口

- **WHEN** 桌面打开业务咨询页面且存在更新记录
- **THEN** 固定宽度折角纸签显示近期升级、日期倒序最近五项短标题和详情入口，同日保持登记顺序，无长说明，不跟随图谱缩放拖动
- **AND** 纸签具有偏心金属图钉、近直角纸面、右下折角和轻微倾斜；悬停或焦点进入恢复水平，减少动态偏好下取消倾斜与过渡
- **AND** 窄屏隐藏纸签，通过现有更新入口查看详情（手机位于更多功能菜单）

#### Scenario: 查看完整详情及恢复

- **WHEN** 用户激活纸签或更新入口
- **THEN** 打开无背景遮罩的非模态右侧详情，日期倒序展示全部记录，同日保留登记顺序
- **AND** 记录区域独立滚动、关闭与Escape可用，关闭后恢复实际入口焦点
- **AND** 底层咨询、草稿及图谱状态保持，背景仍可操作，不因点击背景关闭详情

#### Scenario: 按用户收起与新批次提示

- **WHEN** 用户收起纸签
- **THEN** 当前账号在本机浏览器记住当前批次，重复打开仍收起，更新入口可恢复纸签及详情
- **AND** 其他用户不继承此状态，最新日期或该日期记录ID集合变化时重新提示
- **AND** 存储不可用仍允许本页收起，不阻断咨询

#### Scenario: 历史与能力范围

- **WHEN** 新重大变化同次登记
- **THEN** 保留全部历史和稳定ID，说明变化与用法，必要资源依赖、未部署或未验收在摘要明确
- **AND** 公告本身不替代上线或验收证据
