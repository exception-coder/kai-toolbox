## ADDED Requirements

### Requirement: 本人个人账号持久绑定
系统 SHALL 允许本人在进行中的咨询保存与用户及系统关联的加密个人站点账号，同一用户后续同系统咨询可复用；只接受明确非生产环境，不把用户声明当作独立环境核验。

#### Scenario: 用户授权后使用原生能力直接登录
- **WHEN** 用户明确指定站点、账号并要求登录查看，当前Codex宿主具有可用原生浏览器或只读HTTP能力
- **THEN** 咨询配置不主动禁用这些原生能力，Agent按该站点授权直接登录排查，无需先填写个人账号表单或重复确认相同授权
- **AND** 不自动保存凭据或Cookie；保存表单仅供可选复用；继承宿主能力及站点权限，工具不可用或权限拒绝如实说明，不绕过限制
- **AND** 仅登录与只读排查被授权，文件、数据库、业务数据写入及从网页取得授权仍禁止

#### Scenario: 本人保存账号
- **WHEN** 本人填写合法站点、环境、账号密码
- **THEN** 经所有权与目标范围校验保存加密绑定，每用户每系统一个当前账号；替换后旧引用失效
- **AND** 密码不写聊天、公共凭据库、工具参数或响应，保存与登录结果分别展示

#### Scenario: 直接使用个人测试站点
- **WHEN** 本人填写内网或公网HTTP(S)测试站点及合法端口和个人账号
- **THEN** 不要求资源中心登记、项目库唯一关联或已完成服务端源码定位，即可保存、检查登录及通过personal-引用读取
- **AND** 公共账号和数据库仍保持原有绑定及定位要求，个人账号仍验证本人所有权、非生产环境、同源路径及只读请求；已登记生产/未知环境不可伪装测试，本机/链路本地/组播等保留地址不因该简化直接开放

#### Scenario: 跨咨询与账号隔离
- **WHEN** 同一用户在后续进行中的同系统咨询发现账号
- **THEN** 可复用本人绑定，无需15分钟后重新填写；重启不删除绑定
- **AND** 其他用户含管理员不能操作本人咨询或引用绑定，不同系统和已归档咨询不能复用

#### Scenario: 过期检查与恢复
- **WHEN** 读取发现此前成功的登录态失效，返回401或可见登录页
- **THEN** 重新登录最多一次，失败后暂停自动尝试，由本人检查登录或更新账号恢复
- **AND** 浏览器context释放不删除持久账号；状态查询仅显示历史检查，超过60秒标为待检查，不把绑定当作在线证明

#### Scenario: 解除绑定
- **WHEN** 本人解除绑定并退出
- **THEN** 关闭context并删除该用户该系统密文绑定，后续咨询不能再复用；失败不得提示成功

#### Scenario: 长时间等待
- **WHEN** 登录、状态查询、检查或解除绑定60秒未返回
- **THEN** 页面结束等待并提供恢复入口，不宣称服务端已取消；登录未知结果先查状态不重复提交，迟到响应不覆盖超时结果
- **AND** 后端状态查询不等待浏览器操作锁，重复账号操作快速拒绝

#### Scenario: 页面与接口排查
- **WHEN** 用户要求以个人账号排查
- **THEN** 优先用本人绑定读取限定站点页面或只读GET接口，不用公共账号冒充本人结果
- **AND** 生产/未知环境、跨源目标、业务写请求仍受限

#### Scenario: 传统表单的绝对定位布局
- **WHEN** 可见的密码输入框属于一个自身没有布局高度的表单
- **THEN** 根据可见密码框识别所属表单及其实际提交地址，不因表单外框不可见而丢失登录请求许可
- **AND** 仍拒绝多个可见密码框所属表单的歧义及非登录业务写请求；未确认登录时不推断验证码或单点登录为原因

#### Scenario: 默认应用入口本身是登录页
- **WHEN** 请求路径与登录路径相同，且登录后已进入其他同源页面
- **THEN** 检查实际登录落点，不再次返回登录入口而误报失败
- **AND** 后续检查仍重新读取页面核验登录状态，显式其他业务路径仍按请求导航

### Requirement: 网页只读取数路径

业务咨询 SHALL 根据实际可用工具及用户要求选择已授权的网页查询路径。源码存在时定向核对当前版本的前端请求与后端参数语义。

#### Scenario: 接口等价性已核实
- **WHEN** 用户需要取数且未指定验证页面交互，接口和完整筛选条件与页面行为等价
- **THEN** 使用已授权登录态调用只读接口，并核对完整条件生效

#### Scenario: 需要实际操作页面
- **WHEN** 当前接口、参数或工具能力不足以完成查询，或用户明确要求验证页面交互
- **THEN** 尝试使用本轮可用且已授权的原生浏览器操作筛选并触发只读查询；无法执行时说明具体缺口

#### Scenario: 官方 Codex 咨询装配浏览器插件
- **WHEN** 官方 Codex 咨询创建或恢复 App Server 线程
- **THEN** 先读取合并配置，仅放行官方 browser、chrome、unified-computer-use 插件，关闭其他插件的默认及显式开启项
- **AND** 配置无法核验则停止启动，不自动回退 SDK，不复制桌面连接身份或放宽站点授权
- **AND** 工具可见不代表浏览器已连接；实际调用失败须保留准确原因，不报告点击完成
