# 设计

Page Anatomy：现有 48px 会话顶部 → 唯一消息滚动区（原文结果 / 关键变化 / 验证 / 详情）→ 44px 手机 Dock → 88px 左右 Composer（＋ / 输入 / 发送，执行中保留中断）。目标普通手机消息区至少 65%，输入区约 15% 以内，状态区不超过 10%；极短屏、键盘或附件展开状态须优先保留可达操作，不虚报比例达标。

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01，无例外。主对象仍为原 session ID；轮次由原 user / result 边界识别。MessageList 只有在调用端明确已挂载 Dock、手机断点且工具隐藏偏好开启时，才收起技术事件；专注、嵌入及用户主动显示工具的场景保留已有入口。原 events 不变，正式 error / warning 继续在正文可见。当前结果标记只在手机主工作区迁入 Dock；历史轮次保留时间与结果详情。后台作业、重连、不一致、等待确认和队列暂停沿用原权威状态判断，不从一条工具日志推断任务失败或完成。

回复投影为本地纯呈现适配，不增加要求模型生成 JSON 的协议。Markdown 标题与独立加粗标签识别原文分区；从开头、明确的变化/验证以及风险、阻塞、待确认中形成可扫读概览，文件与执行过程保留原始 Markdown 并展开。短回复、正在输出、无安全分区、关键内容超出概览容量时保持全文。只重新安排已有原文，不生成摘要事实、测试数或成功图标；复制与分叉始终使用完整原文。复用 AssistantReply 和 Markdown，不建立第二套消息数据源。

TurnResultDetails 共用当前与历史轮次的统计、结束原因、复制和变更入口，颜色使用中性文本。技术失败可在 Dock 一行标记「执行提示」，展开查看完整工具和活动；正常成功收口后，不把先前已处理的工具尝试当作当前告警。清理异常、新建等正式恢复操作保持可见，不改可恢复性。

Composer 配置保持挂载，只把手机入口通过 Portal 移到「＋」菜单。打开配置时关闭菜单，不丢失抽屉、自定义选择或权限参数；关闭后焦点回到仍可见的「＋」。模型滑动组合保留，自定义仍在同一抽屉。引用复用原 hook，手输 @ 继续可用；语音录制中原控制保留。没有自动发送、修改模型、创建会话或请求麦克风。菜单限高可滚动、触摸入口至少 44px、Esc 和外部点击关闭；重复打开仅复用配置。

不增加一次性全局 Agent Design System：当前复用边界是 feature 内的 reply / turn details / Dock / 配置组件。其他 Agent 的协议和权限不同，后续需要实际消费者后再提取公共设计系统。本次不改变 AI 编程架构契约。

验证复用现有 MessageList、MobileSessionStatus、SessionConfigSheet 和 ChatPage 用例；覆盖原文验证/风险保留、当前与历史结果归属、工具提示详情、复制本轮、入口卸载后配置继续可用、草稿和焦点。浏览器检查生产组件的 390×844、360×640 和桌面布局及恢复状态。当前真实路由显示要求登录，未绕过权限；真实会话联动复验与隔离组件证据分开记录，不把样例状态当作线上事实。
