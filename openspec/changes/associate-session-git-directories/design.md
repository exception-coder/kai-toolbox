## Context
现有 SessionProjectDirectoryService 持久化会话附加目录，WorkspaceScanService 投影 ProjectCatalog。CommitsPanel 已支持多个仓库，现仅查询主 cwd。

## Decisions
- 复用会话关系；不增加项目清单或平行存储。服务层解析仓库，控制器复用公共 Git 服务。
- 使用已关联目录对应的稳定标识，每次操作从服务端重新解析；移除关联、排除或不存在时拒绝。
- 提交弹窗顶部展示关联工作目录及管理入口，复用选择器。保存后重新加载仓库；主 cwd 不改变。
- OBJ-01/NAV-01：主对象是 sessionId，仓库由会话内选择；不新增顶级导航。
- CTX-01/FEED-01：关联编辑返回原提交弹窗；查询失败显示重试；切换时丢弃旧请求结果，推送时禁止切换。
- IDEM-01：关系继续使用现有去重原子替换；同一规范路径只显示一个仓库。
- DENS-01/CTRL-01：紧凑目录区，完整路径用于同名辨别；移动端换行，Dialog 处理焦点及 Escape。无例外。

## Verification
后端覆盖主仓兼容、外部关联、移除、排除、路径去重；前端覆盖关联管理返回和切换查询。构建及本地测试先执行，实际服务需授权后重启验收。
