# 文档浏览器

首页「直接打开文件」支持拖入文件，或点击选择文件后直接预览，无需挂载目录。支持 `.md`、`.markdown`、`.mdx`、`.html`、`.htm`、`.txt`、`.rst`、`.adoc`、`.drawio`、`.drawio.xml`；一次最多 10 份，单份最多 5 MiB、合计最多 20 MiB。UTF-8 与带 BOM 的 UTF-16 文本可读取。

Markdown 沿用 Mermaid 和 h2–h6 大纲，MDX 按静态 Markdown 阅读；RST/ADOC 显示原文。可切换同批文件和源码，大文件默认显示源码。HTML 为隔离的静态单文件预览，内嵌样式可显示，脚本、表单和外部资源不执行。

临时文件只在当前浏览器内存中读取，不上传、不登记文档源、不修改原文件，关闭窗口即清除。需要关联图片、链接、完整 HTML 交互或保存编辑时，使用既有「添加本地目录」入口。GitHub 文档源仍为只读。

实现与验收范围见 [直接打开文件](../../../../openspec/changes/add-browser-file-preview/tasks.md)。

## draw.io 图形预览

选择或拖入 `.drawio` / `.drawio.xml`，可查看压缩或未压缩图文件，切换页面、缩放、适应窗口和全屏查看；仍可切换源码。Vibe Coding 回复中的本地图文件链接可直接点击弹框查看，完整读取上限 5 MiB，沿用会话与已登记项目路径校验；关闭回原消息。工作目录的文本文件预览复用同一组件，读取被截断时明确提示改用原文件，不尝试渲染残缺内容。该能力不包含图形编辑、保存，也未扩展后端文档源的格式白名单。

渲染完全在浏览器执行，固定版本资源随 Forge 静态文件分发，不新增服务、不调用在线 draw.io。隔离 iframe 禁止网络读取、外部图片/字体、链接跳转及数学公式扩展；内嵌图片可显示。压缩页面先有界解压：总展开文本最多 20 MiB、最多 100 页和 20000 个单元；旧浏览器不支持解压时提示升级或另存为未压缩 XML。

公共组件通过 `doc-viewer/public-api/drawio` 按需导出，避免查看图形时加载文档编辑器。第三方版本与文件校验值见 [draw.io 资源说明](../../../public/vendor/drawio/README.md)。实现及验收状态见 [draw.io 前端渲染](../../../../openspec/changes/add-drawio-preview/tasks.md)。
