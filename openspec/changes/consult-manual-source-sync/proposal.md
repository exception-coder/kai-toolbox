# 管理配置一键同步咨询源码

## Why
管理员需要主动确认咨询候选项目的本地源码是否与远端一致，不能等模型恰好探索某项目，也不能把五分钟自动检查缓存当作本次最新证据。

## What Changes
- 在现有业务咨询配置增加一键 Pull，读取已保存的前8个可用候选，按顺序逐项检查并安全快进。
- 复用既有同步服务、GitPullOperations与仓库互斥；手动操作绕过时间缓存，完成结果供自动探索复用。
- 管理接口要求ADMIN，不接受目录、远端或任意命令；逐项显示结果、分支、检查时提交与时间。

## Impact
涉及fore-consult管理配置、源码同步编排与文档，无数据库迁移，不登记业务人员更新纸签，不自动发布或重启。
