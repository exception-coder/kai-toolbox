# 指定用户只读共享会话

普通用户的 Vibe Coding 会话默认归本人，ADMIN 保留原有访问能力。新增会话级具名查看授权，让拥有者或管理员把一个会话共享给已启用的平台用户，并可撤销。接收者通过登录后的只读页面查看已落盘的对话文字，不获得引擎、文件、附件、工具及配置操作权。

会话行「⋯」可直接打开授权面板，提供 1 小时、24 小时、7 天有效期，默认选择 24 小时。链接复用原会话只读路由，服务端按登录身份及有效期核验。

复用现有身份、会话目录和历史分页，不修改原有写操作的会话访问策略，不创建公开 token 或副本。指定示例会话为 `563792af-2a29-4311-b705-c3263496fad6`；真实授权须通过目标版本的登录态 API 完成，开发完成不代表已给严伟生效。
