# Codex 本机会话同步

## Why

Forge 的本机历史仅扫描 Claude，用户无法从 Codex 桌面共享的授权目录选择项目、导入历史并续接原生会话。

## What Changes

- 在会话工具的「会话」分类添加按需加载的 Codex 同步预览。
- 通过 App Server 分页读取真实项目和会话，选择授权目录，按项目筛选。
- 导入所选会话到已有会话列表，保留授权目录、原生句柄、工作目录和模型；重复导入复用原记录。
- 导入不启动 Agent、不修改 Codex 的项目、标题、收藏或归档。

## Impact

影响 Claude Chat 的 Sidecar 只读查询、会话元数据导入及前端覆盖层。复用现有会话存储、访问策略和续接链路；不改变上下文分层或工程治理职责。服务启动和页面验收须另获重启授权。
