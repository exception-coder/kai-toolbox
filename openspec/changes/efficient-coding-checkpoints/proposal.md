# 按功能检查点推进编码

## Why

监督会话持续提交细小实现，但当前 task 长期未收口。门禁关闭路径的交接只有任务编号，缺少验收描述；重复派发计数又被清零，无法提示优先核对已实现内容。已有验证缓存不能覆盖 Agent 直接执行的 Maven/npm 命令。

## What Changes

- 复用项目控制设置，增加功能检查点（默认）与逐任务验证节奏。
- 每轮交接权威快照中的任务验收描述，限定当前任务或已登记的关联批次。
- 反复派发同任务时提示核对成果、完成剩余验收，不新增暂停条件。
- 明确有效证据复用、失败定向重试及功能节点文档/提交要求。

## Impact

影响项目监督面板、项目控制 API/存储与 Runtime 交接。保留门禁、预算、手动暂停及生产授权现有语义，不改 Sidecar 缓存或业务项目 task 状态。
