# 轻量工作空间上下文切换器

## Why

移动端标题弹框混合会话身份、页面页签、低频工具和嵌套模式菜单，导致四层导航争夺空间。

## What Changes

- 标题只呈现当前上下文、直接模式选择和原会话列表入口。
- 页面视图进入右上角更多的折叠工作视图组，继续复用已有定义与状态。
- 列表式模式选项、弱阴影和限宽浮层；保留权限、草稿与焦点恢复。

## Impact

仅调整 claude-chat 前端交互，不修改引擎协议、后端、会话存储或 AI 编程架构契约。本变更替代 simplify-mobile-session-header 中“标题承担全部视图导航”的呈现决策，其单行 Header 与桌面布局约束继续成立。
