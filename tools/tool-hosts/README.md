# 主机管理与 SFTP

主机管理复用已登记的 SSH 账号，管理员点击主机行的「SFTP 文件」浏览目录、下载与上传。仅支持 SFTP SSH，不支持普通 FTP/FTPS。

1. 在主机管理登记 hostname（不含 http://）、SSH 端口、用户名与密码或私钥。
2. 通过管理员可信渠道核对服务器主机密钥，并登记到 **Forge 服务账号** ~/.ssh/known_hosts；非标准端口使用 [hostname]:port 格式。不要仅凭 ssh-keyscan 输出自动信任。
3. 点击「SFTP 文件」，打开远端目录。原「测试连接」执行SSH命令，仅SFTP账号不必通过它，应以目录读取结果验收。Windows 可尝试 C:/目录，最终以服务器返回的路径为准。
4. 上传新文件会拒绝同名目标。替换先点目标「准备替换」，选择本地文件，再点「备份并替换」。原摘要不匹配时须重新核对。
5. 成功结果显示远端路径与同目录 .forge-backup-编号 备份。备份不自动清理；需要恢复时下载备份，重新核对目标摘要后替换。

目录最多显示1000项，单文件20 MiB。不支持链接下载/替换与递归传输。不执行远程命令，不触发服务重启。避免和其他部署任务同时写同一文件；多次 SFTP 操作不是事务。Windows 文件占用或服务器不支持权限/改名时会失败，不降级为直接覆盖。替换只复制普通rwx权限，不复制所有者、ACL、特殊权限位或时间戳。

网络中断或恢复失败时，先核对原目标、备份和 .forge-upload-编号 临时文件。日志仅记录主机ID、操作编号和阶段，不输出账号密码或文件内容。服务端返回失败不证明远端完全未发生变化。
