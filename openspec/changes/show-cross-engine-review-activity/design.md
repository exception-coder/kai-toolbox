## 选择

复用原工具调用作为身份与时序锚点。App Server 的工具开始、输出和终态以同一 item ID 关联，终态通知包含最终项目。Forge 源码已将这些事实带入实时工具记录，并从原生历史恢复工具输入和结果。本期通过 Team Standards CLI 的版本化摘要识别独立审查，保留旧版 JSON 结果兼容。读取时使用当前消息序列和已有访问限制。[Codex App Server 事件协议](https://learn.chatgpt.com/docs/app-server#items)

Team Standards 决定是否调用、执行权限、调用范围及记录。Forge 只投影与工具调用关联的状态，不读个人历史目录、不传递凭据、不启动评审。CLI 的可选 stderr 摘要包含请求、派发和终态，stdout 原有 JSON 可继续供其他客户端使用。未知输出只展示结果待确认。

## 交互

适用 OBJ-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01。审查摘要在原位置更新，默认折叠。窄屏允许模型名称和状态换行，点击摘要展开耗时与原因。聊天只显示安全摘要字段，不从一句普通回复推断调用。共享会话既有执行信息隐藏设置仍适用。

本期在所用引擎能回传 Shell 工具记录时显示。失去实时输出时可用原生历史恢复终态；出现在聊天工具记录之外的调用仍能通过 CLI 历史查询。
