## ADDED Requirements

### Requirement: 本地代码查看与格式化
系统 SHALL 在既有格式化工具内提供 Java 原文和格式化结果，高亮和显示行号，仅在浏览器内解析，不执行或上传代码。

#### Scenario: 直接处理 default 方法片段
- **WHEN** 用户粘贴带泛型、lambda 和中文注释的单个 default 方法并格式化
- **THEN** 自动选择接口成员入口，输出可解析的 Java 片段，保留原文、标识符、字面值及注释内容，不附加包装类

#### Scenario: 语法不完整
- **WHEN** 代码缺少必要括号或分号
- **THEN** 提示原文中的错误位置，保留原文和上一份结果，阻止把旧结果当作当前结果复制

### Requirement: 计算与对象版本隔离
系统 SHALL 使用按需创建的 Worker、代码大小限制和超时；正在计算或完成结果只属于提交计算时的原文与选项。

#### Scenario: 计算中更换输入
- **WHEN** 用户在格式化完成前编辑原文、修改选项或取消
- **THEN** 旧计算结果不覆盖新版本，可再次格式化当前版本

#### Scenario: Worker 或剪贴板失败
- **WHEN** Worker 失败、超时或复制被浏览器拒绝
- **THEN** 保留输入，说明可重试或手动复制，不伪报格式化或复制成功

### Requirement: 阅读与导航恢复
系统 SHALL 保留格式视图本页输入，提供 Java 直达地址，桌面对照阅读、手机输入/结果切换和键盘操作。

#### Scenario: 切换格式后返回
- **WHEN** 用户在 Java、JSON 或其他格式间切换后返回
- **THEN** 已访问视图的本页输入和结果保留，不要求重新粘贴
