## 2026-10-26 空响应解析回归

手机截图显示预览已关闭，同时报 Unexpected end of JSON input。核对 PagePreviewController：close/input 的 void 返回是 200 空响应；通用 http 默认只识别 204，其他成功响应均调用 json。重新预览先关闭旧上下文，关闭已成功却在解析阶段拒绝 Promise，因而后续创建不会执行；接管输入也受同一问题影响。此前浏览器夹具错误地假定 DELETE 返回 204，未覆盖实际 200 空响应。

在 http 的成功分支增加显式 empty 响应模式，仅由关闭/输入命令选用，不吞掉 JSON 查询的空内容或非成功状态。无需修改或重启后端；不改认证、生产环境限制或服务配置。
