# 设计

复用现有 Radix Dialog 与 useFullscreenPortalContainer，将图片预览挂到 body 或原生全屏容器，避开咨询面板层叠上下文。顶部独立工具行展示标题和「× 关闭」文字按钮，触控区域至少 44px，保留顶部/底部 safe-area；图片在剩余空间内等比展示并支持浏览器双指缩放。黑色背景点击与 Escape 保留，点击图片不关闭，Dialog 管理焦点与背景滚动，退出后回到原触发元素（若仍可聚焦）。

适用 OBJ-01、CTX-01、FEED-01、EVID-01、IDEM-01，无例外。主对象仍是当前图片 src；沿用图片覆盖层，不新增导航或配置。加载仍由原图片元素负责，不在本次变更下载/重试机制。关闭只退出预览，不取消咨询、不删除附件；再次打开仍使用同一地址。桌面和移动共用组件，保留原图比例；验证 Portal、文字关闭、黑色区域、Escape、焦点恢复及原生全屏。浏览器核验窄屏与桌面；不可用时记录限制。无 AI 编程架构契约影响。
