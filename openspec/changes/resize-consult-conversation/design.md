# 设计

Page Anatomy：现有业务图谱 → 附属咨询窗口（标题、单一消息滚动区、固定输入区），历史归档沿用右侧只读窗口。默认保留 520px / 560px 宽度，桌面沿对应边缘调宽或一键展开到工作区，归档不引入另一套页面。手机按可用屏幕宽度收缩，消息区纵向滚动、宽表格内部横向滚动；头部和输入 / 归档页脚保持可达。

适用 OBJ-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01，无例外。主对象仍是既有 consultId / sessionId；公用 ConsultPanel 只持有瞬时宽度与展开状态，不新增对象、请求、持久配置或业务事实。关闭流程不变，展开 / 还原不会卸载内容，保留当前草稿、附件与消息上下文。尺寸不跨关闭或浏览器重启保存。

右侧边缘对应当前对话，左侧边缘对应历史归档；指针捕获保证拖出窗口仍可调节，取消和捕获丢失结束拖拽。宽度受父工作区 ResizeObserver 约束，最小 360px（不足时以实际空间为准），最大工作区减 24px。展开保留手动宽度，恢复时重新应用当前边界；不修改全局 body 样式，不依赖显示器宽度。

键盘分隔条具有 separator 语义、方向、控制目标与当前宽度：左右方向键移动边缘，Home / End 到最小 / 最大；双击边缘恢复默认宽度。展开按钮保留自身焦点与状态说明，手机隐藏这些冗余控件。参考 [WAI Window Splitter](https://www.w3.org/WAI/ARIA/apg/patterns/windowsplitter/)（2026-10-15），不引入依赖。

两个答案渲染器保留各自原 Markdown / 清理链路；ConsultAnswerContent 只约束宽度并为表格补充键盘聚焦与滚动说明，保留原生 table 语义、列、正文和链接。表格最小列宽 8rem，长内容换行，超宽部分局部滚动。局部 MutationObserver 覆盖异步 Markdown / 归档内容替换，仅观察子节点，卸载时断开；不修改数据或共享 Markdown 组件。

加载、失败、发送、附件、归档与会话恢复沿用原组件，尺寸操作没有异步失败或写入结果。浏览器验收使用真实组件与示例数据，分别核对当前 / 归档、拖拽、键盘、还原保留草稿、宽表格、空内容、手机与短屏。生产构建不等于真实业务会话或发布验收。无 AI 编程架构契约影响。
