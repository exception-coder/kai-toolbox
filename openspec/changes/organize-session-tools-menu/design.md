# 设计

Page Anatomy：原单行 Header → 对话 → Dock / Composer 不变。更多首页由两项手机快捷操作和五类入口组成；进入分类时替换首页内容，顶部返回固定在滚动区上方。低频能力不再与常用操作争夺首页注意力。

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01，无例外。主对象仍是现有 session ID / 当前工作目录；各分类只组织已有动作，不持有另一套业务状态、目录或权限。

| 分类 | 主次与边界 |
|---|---|
| 工作与进度 | 复用 SessionWorkViews 的对话、推进、看板、待办、文档、轨迹、评审；自动监督也在此类 |
| 文件与项目 | 目录、提交、待提交先显示，其次变化及附加项目，最后项目准备 |
| 会话与分享 | 命名、提问定位、导出、分享评审、规格关联；无会话时禁用并说明 |
| 阅读与显示 | 工作区偏好、通知、专注、显示方式、消息显示、手势开关 |
| 运行与维护 | 连接与能力 → 服务与依赖 → 诊断与恢复；引擎列表按需展开，自检与重启靠后 |

2026-11-03 按用户反馈进一步去重：手机「工作与进度」移除工作站点和 Token 用量，分别复用输入区「＋ → 站点预览」与「会话控制 → 会话用量」。桌面导航、原视图及业务回调保留。手机原“工作目录与提交记录”只是提交记录快捷入口，归入文件分类的提交记录；文件浏览仍用独立工作目录，不丢失能力。所有原账号检查、运行中切引擎限制、评审会话限制、确认及回调保留。重启入口只打开原确认流程，本任务不重启服务。

Menu 分组描述由局部 sessionToolGroups 持有，业务动作仍在原 ChatPage。共享 SessionToolsMenu / Section 新模式可选，未启用分类导航的嵌入调用保持原折叠方式。普通打开回首页，导览可直接定位原 workspace / session / system 分类；导览期间不抢自身焦点。

返回与 Escape 先回首页并聚焦来源分类，再次 Escape 关闭并回更多按钮；方向键、Home/End 和 Tab 可操作，禁用项跳过。打开菜单会收起新建表单，但保留原选择和草稿；切视图沿用原草稿、分页及滚动状态。菜单约 256px 宽、最大视口减 32px，最大 75dvh，弱阴影，返回区固定，分类内容独立滚动，操作至少 44px。

没有新增异步保存或事实推断；加载、失败与确认继续由原能力承担。真实登录页面只验证菜单导航，不触发会话写操作或维护命令；构建证据与真实页面验收分别记录。无 AI 编程架构契约影响。


本次收敛沿用 OBJ-01、NAV-01、CTX-01、DENS-01 与 EVID-01。对象仍为原 session ID，不新增页面、状态、接口或写入；菜单退出、焦点、草稿及原异步操作保持现有流程。仅移除两个手机重复按钮并更新指引，以现有视图导航和会话工具用例回归，实际手机验收另行标注。无 AI 编程架构契约影响。
