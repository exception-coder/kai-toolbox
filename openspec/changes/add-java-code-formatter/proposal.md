# Java 代码查看与格式化

## Why
现有内容工具已提供 JSON、XML、YAML、SQL 和 Nginx 格式化，但同事发来的 Java 方法片段无法直接高亮查看和格式化。复用已有格式化入口，补齐粘贴代码到核对、复制结果的闭环。

## What Changes
- 在「内容工具 → 格式化工具」增加 Java 代码视图，支持完整文件、单个方法/成员、语句和表达式。
- 原文与格式化副本分开显示，提供行号、高亮、折叠、缩进和行宽、复制与下载。
- 格式化在按需加载的浏览器 Worker 中进行；失败和输入变化保留原文，迟到结果不覆盖当前输入。
- 提供 Java 直达链接，保留各格式视图本页输入。

## Impact
仅前端 formatter feature、内容工具布局和菜单描述；无后端接口、数据库、代码执行或 AI 上下文契约变更。
