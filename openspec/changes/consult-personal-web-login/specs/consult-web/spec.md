## ADDED Requirements

### Requirement: 本人个人账号临时登录
系统 SHALL 允许已登录用户在本人进行中的咨询内提交个人站点账号，无需公共账号绑定；只接受明确非生产环境，不把用户声明当作独立环境核验。

#### Scenario: 本人填写个人账号
- **WHEN** 本人在咨询内提交合法站点、环境、账号密码
- **THEN** 服务端静默登录，仅在内存保留15分钟临时授权，模型发现本咨询personal引用
- **AND** 密码不写聊天、公共凭据库、工具参数或响应；实际页面非READY不得声称登录成功

#### Scenario: 非本人或已失效授权
- **WHEN** 其他用户（含管理员）试图授权，或模型跨咨询使用引用，或授权过期、咨询归档、系统已切换
- **THEN** 拒绝登录或读取；过期、退出及检测到范围失效时关闭对应浏览器context

#### Scenario: 用户退出个人账号
- **WHEN** 本人点击退出
- **THEN** 移除临时授权并释放Cookie，后续读取要求重新登录；退出失败不提示成功

#### Scenario: 登录请求长时间没有结果
- **WHEN** 登录、查询状态或退出请求60秒仍未返回
- **THEN** 页面结束等待并提供查询状态和退出恢复入口，不宣称服务端操作已取消
- **AND** 登录结果未知时清空密码并禁止重复提交，状态查询成功后解除未知状态；迟到响应不能覆盖超时提示，退出未确认不得显示已退出

#### Scenario: 页面与接口排查
- **WHEN** 用户要求用个人账号排查
- **THEN** 优先使用personal引用读取限定站点页面或只读GET接口，不用公共账号冒充个人权限结果
- **AND** 生产/未知环境、跨源目标、业务写请求保持受限，失败不自动反复尝试相同授权
