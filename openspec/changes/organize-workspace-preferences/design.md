# 个性化分类设计

适用 NAV-01、CTX-01、DENS-01、CTRL-01、FEED-01，无例外。保留现有会话工具分类及功能导览入口。专注模式位于视图；个性化使用 SlidersHorizontal 位于系统设置。弹窗以章节标题和分隔线组织，不套多层卡片，手机限高并可滚动。

布局与导航复用最近会话默认展开；阅读与外观复用 skinPref、toolColorPref、toolVisibilityPref，不新增存储；交互偏好接入 ChatPage 已有手势状态和 toggleGesture。用户点击手势选项后关闭偏好弹窗并进入原有摄像头授权流程；打开弹窗不启动摄像头。原视图中的快捷设置保留且实时同步。

无后端、数据库或 AI 编程架构契约变化。本次独立 Vite 构建，不执行助手 SDK 发布，不重启服务；目标页面未加载时如实保留运行验收待办。

工具调用可见性的默认值调整为隐藏：localStorage 无值、无法读取及服务端快照均返回隐藏；已有 `0`（用户选择显示）和 `1`（隐藏）沿用，不迁移覆盖用户选择。桌面、手机及悬浮窗复用同一 Hook，不新增设置或存储。本默认值调整只执行定向回归和类型/边界检查，不因常量修改重复整套前端构建或浏览器验收。
