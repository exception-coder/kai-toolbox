## ADDED Requirements

### Requirement: 明确授权后执行本次非生产 SQL 写入
普通开发 Agent SHALL 仅在用户明确授权相应对象与操作后调用 EXECUTE，附上授权原话、适用范围及稳定请求 ID；资源工具 SHALL 继承当前会话身份、资源绑定、环境和能力校验，缺少声明拒绝执行。

#### Scenario: 已授权写入
- **WHEN** 用户明确允许当前测试库变更，Agent 提交对应单条 DDL/DML 和授权声明
- **THEN** 系统通过原连接器执行并记录 SQL、声明和真实结果

#### Scenario: 默认和受限边界
- **WHEN** 缺少授权声明、目标为生产或未知环境、资源停用，或 QUERY 包含写入
- **THEN** 拒绝执行，不能通过附带授权绕过 QUERY 的只读校验

### Requirement: 写入不因重试重复执行
系统 SHALL 在外部执行前持久认领稳定请求 ID；相同请求重放读取已有状态，不再次执行；不一致请求拒绝复用，超时和未知状态须先核对事实。

#### Scenario: 完成或结果未知后的重复调用
- **WHEN** 已认领的请求再次到达
- **THEN** 返回原已知结果或明确的结果未知，且不重复连接目标数据库执行

### Requirement: 对话授权与人工交接分离
Agent SHALL 将授权理解与服务端机械校验分开，不把工具注解或授权字段称为独立人审证明；未执行且需人工执行的脚本保持待执行登记，已执行脚本不得重新登记为待执行。咨询及评审不获得写入能力。

#### Scenario: 用户仅要求生成脚本
- **WHEN** 用户没有授权实际执行
- **THEN** 继续生成与登记待人工执行 SQL，不调用 EXECUTE
