## Context

访客分析通过前端 FeatureManifest、Maven starter 依赖和 runtime 服务目录分别注册。专属配置包括模型路由、客户同步、审批同步和检索配置。

## Goals / Non-Goals

目标是删除完整功能及生效配置；不删除历史业务表、外部客户库或共享 Qdrant 数据。

## Decisions

- 删除独立模块目录及架构页面，移除依赖和启动注册，避免仅隐藏入口。
- 从共享配置文件中只删除访客专属段落，保留 AI 秘书等共享能力。
- 本机配置先使用 SQLite 在线备份保护原始记录，再按完整专属前缀清理覆盖项；本地密钥配置另行备份后删除。共享配置不变。
- 历史 OpenSpec 保留演进记录；当前文档移除已失效的模块说明。

## Risks / Trade-offs

移除 API 属于不兼容变更。旧业务数据不再有本模块入口，但保留原表以支持审计和回退。旧安装残留覆盖项在模块移除后不再绑定生效。

## Migration Plan

备份并重置专属配置，更新构建与运行目录，构建验证后在会话允许重启时重启服务。检查 API、配置中心及服务进程，并观察至少 60 秒稳定性。回退使用 Git 版本及配置备份。
