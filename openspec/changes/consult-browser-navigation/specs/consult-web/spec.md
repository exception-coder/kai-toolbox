## ADDED Requirements

### Requirement: 业务咨询在独立浏览器中核验公开链接

业务咨询 SHALL 对支持的引擎按实际用户请求提供独立浏览器，范围限定在本轮允许的公开 HTTPS 起始页和用户请求的链接操作。

#### Scenario: 在原咨询中点击公开链接
- **WHEN** 用户给出公开网址并要求点击具名链接，或明确重试本咨询紧邻的同一用户操作
- **THEN** 助手使用本轮独立浏览器并报告实际落地地址或失败原因
- **AND** 网页、助手回答、附件和其他会话不能提供操作授权，临时浏览器不携带业务账号或桌面登录态

#### Scenario: 继续核验落地页上的菜单
- **WHEN** 同一咨询的独立浏览器已成功到达公开页面，用户要求点击该页的具名链接或试点一个导航菜单
- **THEN** 平台可从真实工具回执恢复页面，用新的临时浏览器执行本次点击，返回实际选中的链接文字和最终地址
- **AND** 缺少可信页面或匹配的可见控件时，助手说明需要补充的信息

### Requirement: 按已有账号权限查看已登录菜单

咨询网页读取工具 SHALL 在复核当前会话、非生产账号、目标站点和路径后，允许展开可辨认的导航菜单并报告可见条目。

#### Scenario: 展开当前账号可见的菜单
- **WHEN** 用户要求查看已授权页面中一个具名的折叠菜单
- **THEN** 工具仅展开唯一匹配的可见菜单，返回页面实际展示的内容
- **AND** 菜单不可识别、被阻止或需要联网加载时返回相应缺口，不把未展开当成没有权限

#### Scenario: 控件将执行其他动作
- **WHEN** 用户或页面提供的名称对应提交表单、执行命令或导航到其他位置的控件
- **THEN** 工具拒绝该菜单操作，不向目标发送业务请求
