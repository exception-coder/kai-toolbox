# 移动会话视觉收敛

适用 OBJ-01、NAV-02、NAV-03、CTX-01、DENS-01、FEED-01、EVID-01；无新增业务对象或执行状态源。

会话以 sessionId 为身份。快捷工具只协调现有看板与当前页待办面板，页面继续拥有引用草稿和权限判断；不新增请求、列表副本或发送流程。默认一个 44px 可拖动入口，打开轻量工具选择，再进入原功能。桌面沿用同一入口，独立未挂载宿主的待办保留兼容入口。

位置按账号保存横纵比例，兼容旧左右边缘记录。拖动结束抑制合成点击，取消拖动不保存。键盘和窗口变化仅夹取可见位置，不改用户偏好；Alt+方向键提供键盘移动。避让可见输入框与安全区域；浮层关闭恢复统一触发器焦点。面板切换不改会话、草稿、消息滚动；原加载、失败、重试和只读行为继续有效。

手工纸静态 SVG 的墨色透明度由 .14 降至 .042，短曲线与细粒替代长划线；正文再减半。黄油纸也换成更淡的颗粒。消息、代码、工具继续使用独立表面 Token。减少叠边和投影，不引入持续滤镜或动效。阅读密度各档减少消息间留白，保留原消息身份和完成/错误节点，不跨任务合并。

状态栏保持 44px，移动端状态名优先，任务摘要和队列在其下的小字区域，显式会话控制和独立停止仍直接可达。输入胶囊及语音/发送互斥、排队、粘贴和自动增高逻辑不变。

验证重点：同一入口打开看板与待办、交接焦点、草稿保留、拖动释放/取消/刷新、键盘视口避让；现有输入、消息、主题对比度测试；桌面及 Android 真机视觉/触控须分别记录，不以 jsdom 代替。
