# 移动端对话工作台空间优化

## Why

移动端运行、队列、监督和语音控制同时展开，挤压核心消息阅读空间。以对话、输入、状态、导航、高级操作为顺序分配空间。

## What Changes

- 一条 40px Agent Dock 汇总运行状态和队列数量，展开底部抽屉查看执行、队列及 OpenSpec 操作。
- 移动端取消常驻监督栏及队列明细；空闲语音入口收进 Dock，通话、恢复和错误仍保留可见反馈。
- 运行中输入区仅保留停止与发送入口；发送方式抽屉明确选择排队或适用的当前轮补充。
- 保持会话执行、排队自动发送与异常暂停规则；修复语音切换时恢复提示错误归属新会话的边界问题。

## Impact

仅调整 Claude Chat 前端呈现和语音恢复提示归属，无后端协议、Agent 执行或 AI 编程生命周期架构变化。桌面继续显示完整控制区。
