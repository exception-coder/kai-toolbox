# 功能导览设计

对象为当前Vibe Coding工作区及已有会话，复用ChatPage和会话工具。适用OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、CTRL-01、EVID-01，无例外。帮助入口保留顶部，普通操作沿用视图/会话/工作区/系统分类。

首次显示可关闭的轻提示，不自动弹出长导览。用户开始后，六步导览直接在真实页面上自动展开新建表单、会话列表、执行导航或对应菜单分类，用暗色遮罩和高亮框突出区域，旁边小浮层介绍核心用途、使用时机和入口。上一步/下一步直接切换高亮，不需要再点击定位或关闭弹窗。完整指南独立支持搜索和空结果恢复，高级内容在指南查阅。导览不发送消息、不重启、不提交、不激活监督。

局部组件与内容落在components/guide，ChatPage只连接已有状态。v1首次偏好仅存当前浏览器localStorage；存储不可读时仍可阅读，不可写时本次关闭且明确提示刷新可能再显示。无会话时执行定位禁用，其余入口如实说明前置条件。功能能力以当前引擎/权限为准。

Radix Dialog管理焦点与Esc，浮层允许上一步、下一步、暂不查看、关闭和完整指南。退出或切换指南恢复导览前的面板、会话视图、分屏形态和菜单，不更改消息、草稿或任务。高亮框根据 DOM 可见矩形裁剪，滚动、窗口和内容变化后重新测量；目标暂不可见时显示入口路径并继续，不出现卡住的等待。桌面浮层靠近目标下方或右下方；手机改为底部窄浮层，限高、内部滚动、操作区至少44px。原始目录/插件权限不因帮助扩大。采用WAI-ARIA模态焦点与关闭规则：https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ 。

正文仅覆盖当前源码已存在能力；变更菜单能力时同步guideContent。此任务不改变AI编程架构上下文与治理契约。其他任务已暂存内容保留，本次提交采用具体路径。
