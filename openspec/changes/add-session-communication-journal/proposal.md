# 会话沟通流水

## Why

需求开发前的飞书聊天、截图和口头沟通散落在不同入口，单个开发会话需要回顾多条原始记录并保留自己的整理备注。

## What Changes

- 在当前会话的「更多 → 沟通流水」提供按沟通时间排列、搜索和阅读的工作区。
- 同一会话保存多条原文、来源、参与人、截图及整理备注，支持修改、移除和恢复。
- 用户选择记录后引用到当前会话草稿，保留原始来源与图片，核对后自行发送。

## Impact

仅扩展 tool-claude-chat 的会话资料与前端视图；复用原有会话权限、图片上传、输入草稿与附件发送。新增 SQLite 表由应用启动初始化，不执行人工数据库脚本；后端更新需要单独确认重启。
