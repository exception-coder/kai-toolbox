# Codex 同步设计

## 已核验证据

2026-10-10，本机 Codex CLI 0.159.3 生成的协议包含 `project/list`、`project/read`、`thread/list`、`thread/read`。本机只读调用前三类目录读取成功。会话列表包含 CLI、VS Code 和 App Server 来源；授权目录中的内容不能被误称为仅来自桌面。

官方线程读取协议见 [App Server 文档](https://developers.openai.com/codex/app-server/)。项目接口以当前安装版本的生成类型和本机调用为证据，旧版缺少接口时返回明确错误，不伪造项目。

## 对象与交互

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、EVID-01、CTRL-01、IDEM-01。

- 对象是选定授权目录内的原生项目和线程；身份分别为 `codexHome + projectId`、`codexHome + threadId`。不按项目显示名推断成员。
- 现有项目分组是名称投影，不新增平行项目存储。导入的分组名称带有授权目录和完整项目 ID 派生的稳定后缀；不直接截取时间型原生 ID 的相同前缀。
- 使用现有「会话工具 → 会话」下的覆盖层，查询按需加载，关闭返回原会话与触发器，不新增主导航。
- 项目列表保留真实名称和根目录，包括空项目。导入的会话投影到现有项目分组；空项目仅供浏览，不伪造聊天记录，也不自动注册业务系统。多根目录在预览中展示，附加项目仍需沿用既有关联能力显式配置。
- 本机旧会话的 `projectId` 多为空。项目筛选先读原生成员，再以真实根目录精确匹配未分配项目的旧会话；两种来源独立分页、每页最多 50 条，界面注明目录匹配，不能称为原生项目成员。每次只读当前页，不扫描所有历史凑满页面；空的原生第一页可直接转到目录流。
- 分页和账号切换分别维护缓存键，不用前一个账号的数据占位。请求中、无数据、失败、过期预览和无变化都有结果与重试入口。
- 复用 Radix 焦点管理和 Esc，窄屏纵向排版、内容独立滚动，固定操作区可达。导入中保护关闭与重复点击，超时提示先刷新核对。

## 服务边界

Sidecar 仅归一化原生协议，不读取凭据或触发 `thread/resume` / `turn/start`。Java 控制管理权限、授权目录白名单、项目排除策略、短期预览和元数据导入。仅管理员或关闭认证的本地单用户可访问本机账号。

授权目录必须是运行用户目录下的 `.codex*` 直接子目录，拒绝符号链接或真实路径越界。服务端预览令牌绑定当前用户与授权目录，十分钟过期，最多缓存 128 页；导入只接受预览中的原生 ID，每次最多 50 条。网络请求在事务之外完成；导入复用原生句柄匹配，或以规范化授权目录与线程 ID 派生稳定 Forge ID，不覆盖已有会话的运行状态、归属和用户设置。

已有会话匹配采用一次有界集合查询，每批最多 100 个绑定参数（当前句柄与引擎映射各 50 个）；插入只针对用户选中的最多 50 条，不为每条扫描全库。SQLite JSON 函数通过实际测试库验证。

读取状态仅代表查询 App Server 的视角，不能证明桌面已停止写入。导入不宣称获得跨客户端锁；续接由用户明确选择，提示先停止桌面生成，复用现有 Forge 授权与恢复链路。

## HTTP 契约

| 接口 | 输入与结果 |
| --- | --- |
| `GET /api/claude-chat/codex/desktop/projects` | `codexHome`、可选 `cursor`；返回原生项目、下一页游标、真实获取时间 |
| `GET /api/claude-chat/codex/desktop/threads` | `codexHome`、可选 `cursor` / `projectId`；返回本页线程、目录可用性、已导入会话 ID、预览令牌及 `projectMatch` 来源 |
| `POST /api/claude-chat/codex/desktop/import` | `previewToken` 与最多 50 个 `threadIds`；返回新增 / 复用数量与 Forge 逻辑会话 ID |

历史接口 `/api/claude-chat/history/{sdkSessionId}/messages` 增加可选 `sessionId`。同步会话传递逻辑身份，服务端验证所属用户和原生句柄后从该会话确定工作目录与授权目录；同一原生 ID 位于不同账号目录时不再从全局首个匹配项取历史。旧调用保持兼容。

## 首期边界

单向按需同步未归档的持久会话；不回写桌面，不自动监听桌面，也不导入临时、子 Agent、归档或无效目录会话。不复制聊天正文，查看历史继续使用授权目录中的原生 rollout。桌面专属图标、收藏、布局及多根目录的自动执行授权不在首期范围。
