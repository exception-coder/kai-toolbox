# 会话视图导航设计

## 对象和交互

适用原则 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、IDEM-01，无例外。主对象仍是当前 Forge 会话 ID；主栏和更多切换现有会话视图，不创建路由、复制会话或执行任务。

桌面保留对话、推进、用量、会话看板，以及关联存在时的文档和评审；轨迹、站点进入同一栏末尾的更多。手机保留对话、推进、看板和更多，文档、用量、评审沿用更多入口。当前次级视图显示在更多触发器中，菜单标记选中项；评审提示仅在该视图确实位于更多时出现。

复用既有 Radix Popover、主题和当前会话视图状态，导航提取为只负责展示的组件。切换不丢失草稿、附件或后台任务；视图加载、失败和重试沿用原工作区。窗口跨断点时关闭菜单并恢复触发器焦点，保留当前视图；按钮具备文字、触控高度及键盘焦点，Escape 关闭后返回入口。无会话时沿用全局会话看板入口。

## 删除边界

移除数据库工作区、SQL 管理覆盖层、展示解析与目标选项代码、对应前端 API/类型，以及 ChatPage 每 3 秒查询待执行 SQL 的轮询。功能指南与能力目录不再指向这些入口。此处删除的是 Vibe Coding 前端功能，不触碰已持久化台账、Agent prepare_sql_context/register_pending_sql 及其服务端契约，也不改变独立数据库控制台。

## 验证

复用更多菜单、功能指南和整页配置回归，集中验证桌面/手机可达性、当前状态、断点恢复及数据库入口移除。执行类型与依赖边界检查、独立 Vite 构建、OpenSpec 校验和项目门禁；不跑整个前端测试套件，不触发 assistant:release 或服务重启。浏览器以实际导航组件核对两个尺寸，生产后端与 Sidecar 不需要为此变更重启。
