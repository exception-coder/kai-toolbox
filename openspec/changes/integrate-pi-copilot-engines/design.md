## Context

现有 engineContract、builtinEngineAdapters、engineCatalog 定义引擎身份及能力；sessionManager 编排会话，Java 持久化引擎字符串，前端消费动态目录。采用相同边界扩展，不另建会话系统。

## Goals / Non-Goals

目标：Pi、Copilot 可选择、配置模型及服务商、输出文本和工具事件、恢复与中断。非目标：赠送模型额度、自动登录、覆盖用户全局配置、自动发布。

## Decisions

原生 SDK/API 仅存在于独立适配器；会话编排只委托调用。按安装版本公开类型实现，固定版本并补回归。Pi 使用原生 SDK 的 tool_call 扩展钩子，在执行前接入 Forge 权限，禁用隐式用户扩展加载；Copilot 使用官方 SDK 管理进程并拦截工具调用。两者第三方服务首期支持 OpenAI Chat Completions 兼容协议，不能把 Anthropic URL 当成兼容地址。

凭据由现有服务商档案解析，会话显式配置覆盖默认环境，不写用户设置。模型清单按引擎和服务商隔离。权限复用 Forge 授权，无法准确映射的操作拒绝，不默认全部批准。恢复失败不自动创建新会话；同一 Forge session 的原生句柄保持稳定。

第三方模型目录只有 Java ProviderModelService 一个写入来源；Sidecar 对 Pi/Copilot 网关会话不发送原生占位清单，避免异步覆盖完整目录。原生目录请求返回时核对会话、引擎、服务地址、模型和凭据是否仍一致，过期结果丢弃。目录失败保留当前模型，UI 支持手填恢复。

适用 OBJ-01、CTX-01、FEED-01、AI-01、IDEM-01。主对象是既有 session ID，新建/切换/配置均复用现有控件，不增导航。加载、错误及重试保留当前模型与草稿；切换引擎不携带旧引擎模型。重复恢复不重复注入交接包，活动轮次遵循既有并发限制。键盘、焦点、移动端继承现有组件并回归检查。

## Risks / Trade-offs

- SDK 版本变化：以固定依赖公开契约及测试为准，不按网页示例猜测。
- 空输出与错误误判：基于原生权威终态，错误不可被后续 idle 覆盖。
- 权限不等价：保守映射、显式拒绝不支持能力。
- 账号尚未配置：报告缺少认证，真实账号验收不伪造通过。

## Migration Plan

无数据库结构变更。先完成协议测试、前后端构建及 Forge 门禁；用户明确授权重启后才部署和执行 60 秒稳定观察。回滚恢复源码及依赖版本，保留会话记录，不把未知引擎自动当 Claude 执行。

## Open Questions

真实账号额度、供应商工具协议兼容性需在安装版本与目标账号下验证。Codex 自审：本方案沿用现有分层，不修改治理架构；适配已实现，尚未部署，真实账号及浏览器运行验收未执行。

## Verification

最终具名审阅：Codex 已对照变更核对独立适配器、目录所有权、权限上限及失败恢复边界。当前专项结果为 Sidecar 22 项、前端 18 项、Java 14 项通过；Forge 执行验证 regression/api/design/ui/spec 五类均 PASS。该结论不扩展到真实供应商或部署验收。

- Sidecar 使用临时编译目录，不替换运行中 dist。专项测试覆盖目录身份、BYOK 显式配置、工具权限、参数修改拒绝、工具次数上限、缺少凭据、预取消和敏感信息脱敏。
- 原生 SDK 对接本地 HTTP/SSE 模拟服务：Pi、Copilot 均验证精确模型/Key 路由、两轮流式回复及同句柄恢复，随后阻塞模型响应并验证实际中断。
- 前端测试覆盖动态引擎目录、会话配置反复打开、Pi/Copilot 第三方模型目录缺失时手填与同步入口。原生模型列表未覆盖真实登录账号。
- Java 21 验证会话引擎身份和既有服务商/模型目录回归；完整宿主打包成功。Maven 默认 Java 8 导致首次构建失败，命令进程指定 Java 21 后通过，未改系统设置。
- Forge Quality CLI 返回 PASSED；executedCheckers 为空，不能称已执行 Java 静态规则检查；9 项 API-RUNTIME-001 仅证明旧运行服务的已有接口可用，不代表两种新引擎已上线。
- 不自动导入用户 MCP/插件或声明未实现的图片/子代理能力。依赖审计包含存量 MCP 链的告警，本次未进行无关依赖升级。
