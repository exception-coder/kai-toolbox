# 设计与权限边界

## 共享失败反馈（2026-11-18）

沿用 FEED-01、OBJ-01、EVID-01：复制链接仅传递会话身份，不创建或延长授权。已共享列表未确认或没有有效接收账号时禁用复制，并引导先搜索账号授权；列表读取失败不能表现为无人共享。接收页失败展示当前账号，对 403/404 提示分享人核对有效授权，对网络/服务失败提示核验未完成，仍不挂载内容。不修改权限判断和后端协议，不自动授权真实账号。

- L3：新增对象级权限。分享关系归 tool-claude-chat；共用 AuthUserRepository 的最小用户目录投影，不复制用户身份。
- 仅拥有者或 ADMIN 且通过现有项目可见性校验者可搜索接收者、查看授权名单、添加与撤销。未启用认证时不开放具名共享；接收者须为有效账号。
- 独立只读 Controller 每次请求复核账号、会话、项目可见性与授权。原 canAccess、WebSocket 和所有写接口不变。共享链接只定位对象，不授予权限。撤销影响后续读取，无法收回对方已读文字。
- 新表 claude_chat_session_reader 以 (session_id, user_id) 唯一，外键级联清理会话；最多 50 个接收者。目录搜索最少两字、最多 20 个；共享列表最多 100 个，使用批量会话读取，不逐条查询历史。
- 只投影 title / engine / 用户与助手文字及时间，不返回目录、SDK 句柄、Key、工具日志和附件路径。共享内容可能本身含敏感文字，授权面板明确提示。复用当前原生会话的历史分页，不触发引擎、不读取任意客户端路径；未落盘内容和其他引擎段不宣称完整覆盖。
- 移动端复用 Sheet；入口放当前会话“更多→会话→共享给用户”，另有同模块“共享给我”列表；只读页面无输入框和执行按钮，手动刷新重新验证权限。失权或请求失败时清除已展示内容并提供返回入口。
- 适用原则 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01；无例外。弹层关闭由 Radix 恢复焦点，搜索/保存反馈独立。
- 依据：[OWASP 授权建议](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)：默认拒绝并在每次请求校验。无需引入外部 ACL 服务。
- prepare_sql_context 核验结果为 DDL_MISSING（evidenceId: 7629717e-b8af-4787-ae71-2895c8b855ce）：项目 SQL 扫描达到上限，三张目标表均未核验。资源发现中 Forge 系统没有绑定可查资源。DDL 以本仓 SQLite schema 为基线，仅交付幂等迁移，并用内存 SQLite 验证唯一性、上限和级联清理；未核验运行库，不直接写运行库、不重启服务。

## 会话行临时共享

遵循 OBJ-01、NAV-01、NAV-03、CTX-01、DENS-01、FEED-01、CTRL-01 和 IDEM-01。会话行的 UUID 是唯一对象身份。列表行的「⋯」和现有会话工具打开同一面板并显示会话名称。用户无需打开目标会话，关闭后焦点回到原按钮。复用原有只读页面和「共享给我」，没有新导航。

按用户名或姓名核对接收者，选择 1 小时、24 小时或 7 天，默认 24 小时。授权后提示并显示截止时间，可复制同一个登录态链接或撤销。加载、错误和写入中有独立状态，写入失败先重新读取授权核对结果。窄屏复用可滚动底部 Sheet，验证键盘入口、关闭与焦点返回。会话 ID 和账号 ID 是幂等键，重复授予有效记录不会延长期限；过期后可以重新授权。

以服务端时钟为准。共享列表、会话详情和历史分页都检查授权是否有效。已有无期限授权保留；旧 API 继续兼容，新界面使用专用临时授权路径，旧服务器拒绝未知路径。临时授权独立存于 `claude_chat_session_temporary_reader`，回退的后端读不到临时授权。新版合并检查有效名额，撤销同时回收两类授权。权限仍仅限原有文字投影和具名登录账号。

## 限时继续会话与撤回

沿用 OBJ-01、NAV-03、CTX-01、FEED-01、CTRL-01、IDEM-01。会话行和共享面板继承同一 UUID，复用现有账号搜索、期限、复制和撤回。收到链接后，按授权范围进入只读页或原开发对话。可再次发起授权以升级既有只读权限，重试重复协作授权不延长期限。

协作渠道使用登录账号和单一会话 ID，逐条校验命令、历史、附件、队列与实时事件。绑定复用原会话与正在运行的引擎。接收者可发送、补充、排队、响应确认、中断和调整本会话模型或引擎。会话归属、删除、再分享、会话复制、第三方凭据、系统管理保持各自既有权限。旧授权字段默认只读，既有授权不会自动获得交互权限。

撤回以会话 ID 与账号 ID 删授权，重复撤回可安全重试。提交后断开该账号的协作连接，其他观察者继续使用。已经接收的轮次和队列按原生命周期管理。输入、广播和读取均重新检查有效期，访问失效时客户端清除会话消息并提示退出。验证覆盖目标切换、双账号、撤后旧连接和手机布局。运行验证需加载目标版本。

共享落地页和带协作标识的工作台链接按 OBJ-01、NAV-03、CTX-01、FEED-01 校验当前登录账号和该会话 UUID。普通 Vibe Coding 菜单权限独立保留。工作台需要协作授权，只读授权仅开放落地页。核验前不挂载页面内容，失败可重新检查或返回主页。账号或对象变化会重新发起核验。
