# 工作助理

## Why

用户需要常驻、职责明确的轻量机器人，通过文本与语音处理周报和资源登记，复用 Vibe Coding 执行能力，避免切走编码会话。

## What Changes

- 新增工作助理首页与跨页面助理坞，首批提供周报助理、资源管家。
- 平台保存独立助理会话、绑定 Skill 快照和任务结果；复用现有 Claude/Codex 执行接口。
- 平台收集受控 Git 事实，模型只负责整理；资源登记在预览确认后写入原资源中心。
- 密码通过专用安全输入提交，不进入模型提示、助理会话或日志；资源仓储新写入加密并兼容历史读取。

## Impact

前端 work-assistants、Shell 常驻入口，claude-chat 内聚的 workassistants 能力，ops 登记与凭据保护，共享 Git 只读能力。无需人工执行 SQL；新增 SQLite 表由启动幂等初始化。目标版本待用户确认重启后运行验收。
