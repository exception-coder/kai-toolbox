# 文档浏览器直接打开文件

## Why

查看一份本机文档也必须先挂载目录，增加了临时阅读的步骤。用户需要在文档浏览器首页拖入文件直接渲染，手机也能选择文件。

## What Changes

- 首页增加「直接打开文件」，支持拖拽及文件选择，不依赖文档源接口。
- 在临时预览窗口复用 Markdown、Mermaid、大纲和原始文本能力；HTML 在隔离窗口静态预览。
- 明确支持格式、大小限制、读取状态和失败恢复；关闭即释放临时内容，不上传或写回文件。

## Impact

仅影响前端 doc-viewer feature。既有目录编辑、GitHub 文档源及后端接口保持原契约，无数据库迁移或服务重启。
