# 收口自动监督运行链路故障

## Why

Sidecar 查询超时或快照过期时，巡检只过滤不可派发的运行，缺少持续故障的可恢复终态。Codex stdin 异步写入失败未由请求生命周期接管，可能落入进程级兜底。

## What Changes

- 持续至少 60 秒且至少三次状态不可确认，暂停自动派发并显示原因及恢复路径。
- 正常执行和思考不计为故障；恢复代次重新统计。
- Codex 输入流故障关闭本轮失败请求；晚到错误不污染已完成结果，不重放已接收轮次。

## Impact

修改 Forge Runtime 巡检与 Codex App Server 传输适配器，不修改任务完成条件、写入范围或生产验收。
