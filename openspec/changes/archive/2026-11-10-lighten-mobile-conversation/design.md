# 设计

Page Anatomy：48px 会话头部 → 44px 对话/推进/看板/更多 → 消息列表 → 44px 状态摘要 → 88px Composer。对话为唯一常驻主要纵向滚动区域。手机普通正文 15px/1.5，头像 24px 与身份同一行，全文从左侧内容边界开始；不改桌面消息形态。中性背景沿用用户主题 tokens，取消手机引擎氛围层，选中及发送使用品牌色。

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01、IDEM-01，无例外。主对象仍为 session ID / message ID；不新增导航、独立列表、持久状态或模型调用。折叠按钮只改变当前消息可见范围，保留复制全部原文、分叉锚点及会话草稿；键盘 Enter/Space 切换，按钮提供 aria-expanded / aria-controls。虚拟列表沿用尺寸感知及跳到最新逻辑。

摘要为原文完整开头块，不自动生成、解析任务成功状态或强制 JSON。完成的回复超过 1000 字符且完整开头块不超过 600 字符时折叠其余内容，不截断代码、列表或链接；原文相邻且足够短的“当前状态”“关键变化”“主要修改”“验证结果”等明示段落一起展示，整体仍不超过 600 字符。当前轮流式全文可见；长列表/代码开头不适合摘要时保留全文。验证结果和问题仅在原文明示时呈现，不把 Agent 收轮认定为业务成功。未来只有明确的引擎结构化契约可用时再考虑语义摘要，不在本次扩展提示协议。

图片在净化后的 HTML 中提取为受控组件，保留既有安全属性；加载占位、失败说明和原地址重试，不放宽本地路径读取。Markdown 与附件使用同一恢复组件；旧源替换时重置状态。图片不存在时重试仍可能失败，不假称能够读取未发布的本地文件。

语音仅把空闲入口移至「＋」；持续挂载原组件，关闭菜单不取消录音。录音、识别和错误在 Composer 可见，不隐式申请麦克风。模型入口保留短名称及可展开配置。Dock 警告、运行、队列仍常驻，空闲只显示状态入口，完成及指标仍归属历史轮次详情。

验收覆盖原文展开/收起、当前输出、旧轮与新轮共存、图片加载/失败/重试/地址变化、录音入口移动后操作可达。390×844、360×640 与桌面核对消息宽高、无页面溢出、详情和输入可达；正常手机目标对话面积 ≥70%，短屏与键盘/附件情况报告实测，不承诺所有环境。

沿用 React 19 / Radix / Virtuoso。折叠语义依据 [WAI Disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)，图片状态依据 [MDN img](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img) 的加载及失败行为，查阅于 2026-10-14。不新增依赖或改变 AI 编程架构契约。
