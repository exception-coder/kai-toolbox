# 移动端会话快捷切换设计

主对象是现有会话 ID。运行面板仅投影现有会话列表，`RUNNING && live` 的会话列于“正在执行”，其余按 `lastSeenAt` 展示最近 8 个；当前会话保留“当前”标记。选择后调用既有 `switchTo`，运行会话传入运行提示。重复选择仍指向同一 ID，不创建会话。

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、IDEM-01：快捷入口留在当前对话的覆盖层中，不增加页面或第二份列表权威。面板打开时按现有列表接口刷新，加载、空数据和失败分别呈现状态，失败可重试。点选关闭面板并进入目标会话；关闭按钮恢复原触发器焦点，行按钮支持键盘焦点和移动端触控，面板自身限高滚动。切换失败沿用现有 `switchTo` 的恢复反馈。

仅调整前端视图和行为，不改变系统架构、后端接口或数据库。验证覆盖运行优先、最近列表、切换提示及既有运行面板回归；当前 Vite dev 服务无需重启，目标页面仍需浏览器验收。
