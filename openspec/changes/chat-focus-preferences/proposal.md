# 对话专注模式与工作区偏好

## Why

开发者需要临时隐藏工作区导航与运行控制，专注阅读消息及输入；最近会话默认展开也应由个人选择。

## What Changes

- 会话工具提供一键专注模式，桌面优先原生全屏；手机采用窗口内可见视口布局。
- 保留原对话、输入和授权弹窗，提供退出按钮与 Esc，退出恢复原视图和面板。
- 新增当前浏览器个性化设置，持久保存最近会话默认展开/折叠，支持临时切换。
- 移动端采用单行 48px 导航和无卡片阅读流，低频操作收进更多，运行提示集中在输入区上方；保持同一会话、草稿与阅读位置。
- 统一使用专注模式，移除重复的普通全屏切换和白云语音展示；保留普通语音输入、原生语音对话与悬浮窗。

## Impact

仅前端视图、无后端或执行生命周期变更。不修改项目、会话数据或其他用户偏好。
