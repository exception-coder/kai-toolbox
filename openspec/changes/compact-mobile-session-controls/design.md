# 设计

本次采用 L2 有界前端调整，基于 MobileAgentDock、MobileSessionStatus、QueuedList、CurrentSessionStorage 及既有 Sheet、ConfirmProvider。

## 原则与结构

- DENS-01：标题统一为“会话控制”，视觉上删除解释副标题，保留辅助阅读器说明。队列摘要优先，语音、轨迹、用量使用同级中性图标入口；记录摘要使用紧凑行。
- NAV-01、OBJ-01、DENS-01：快捷操作与最近会话分开；按 2026-11-03 用户反馈移除额外的 3 条截断，复用既有会话看板最近 20 条集合、过滤、排序和真实状态。常规手机展开后可浏览至少 5 条，更多条目使用现有面板内容区独立滚动；短屏、键盘或放大字体仍优先可用视口，不强制撑高或缩小文字。保留原 60%/90% 面板高度、展开能力和完整列表入口，不增加嵌套滚动或第二份查询。监督与推进保留原完整工作区入口，控制面板不新增监督数据查询或空分组。
- CTX-01：队列明细、运行详情和最近会话均为局部展开；关闭只清理展示状态，不发送、不清除、不取消任务。会话切换复用 chat.switchTo 的草稿保存；关闭恢复摘要触发器焦点且不滚动。
- CTRL-01、IDEM-01：复用已有删除、发送和回执处理，不自行重发未知派发。批量清除在“更多”中二次确认；确认期间消息集合或派发状态改变时拒绝清除，要求重新核对。面板关闭后的旧确认不影响原会话。
- FEED-01、EVID-01：待发送、发送中、已接收执行中、失败、待核对分别表达。FAILED 可能包含发送或执行失败，不能无证据归因为网络发送失败。不可用语音显示原因，异常记录与会话列表保留恢复入口。

没有原则例外；不改变整体 AI 编程上下文、权限、规格、任务或证据生命周期契约，因此不修改整体架构文档。

## 视口与滚动

移动 Sheet 高度由内容决定，默认上限为当前可见视口的 60%，显式展开至 90%。监听 VisualViewport 的 resize/scroll 以及窗口 resize，避开键盘与动态浏览器区域。安全区域沿用既有 Sheet padding。只由面板内容区纵向滚动，队列不另设限高滚动区。

拖动手柄下滑超过 64px 关闭、上滑超过 48px 展开；触控取消或自身失去捕获会复位。另有键盘可用的展开/收起按钮及既有关闭按钮。桌面沿用居中紧凑 Sheet，显示能力和数据接口不变。

## 验证边界

组件测试覆盖展开前不派发、清除确认与并发保护、回执状态、最近会话按需查询和切换、详情事件保留、键盘视口投影、下滑关闭与焦点恢复。DOM 模拟不是 Android Chrome、iOS Safari 或飞书 WebView 真机验收；预览准备也不代表已登录或验收通过。


## 2026-11-03：状态栏显式入口

依据 DENS-01、CTX-01、OBJ-01、CTRL-01、EVID-01、IDEM-01，底部摘要保留原 sessionId、runtime 查询与 MobileAgentDock.queue 数据，右侧明确显示“会话控制”及方向箭头。原生 button 覆盖整行，移动端保持 44px，状态摘要可省略，队列数量与入口不换行；执行提示保留在可访问名称及原详情中，不挤占移动行宽。空闲无历史时也保留入口，专注模式的空闲/完成隐藏规则仅保留桌面端，不增加悬浮按钮或第二份执行状态。

继续使用原 Bottom Sheet 和动态视口、安全区、内部滚动；不增加导航步骤或重新实现面板。打开不发消息、不切会话、不清队列，关闭恢复触发器焦点并使用 preventScroll；草稿与聊天滚动不受本次状态影响。运行查询失败仍可打开并从既有详情核对原因。

原生按钮保留 Enter/Space，aria-haspopup、aria-expanded、展开时的 aria-controls 与面板关联，名称明确“打开/关闭会话控制”。箭头跟随 open。首次手机使用显示不占布局、不获焦点的短提示，6 秒后或首次打开后记为已发现，当前浏览器保存；存储不可用时跳过引导，不阻断操作。这是浏览器级功能引导，不保存账号业务偏好。

重复点击只切换同一组件的 open，不创建任务、会话或第二个面板。验证覆盖空闲、运行/暂停队列、异常、关闭焦点恢复、首次引导及现有队列操作；真机键盘、视觉与滚动验收单独记录，不以 DOM 测试冒充通过。无架构契约变化、无原则例外。


## 2026-11-04：移动输入区横向空间

遵循 DENS-01、CTX-01、CTRL-01、NAV-03。默认胶囊容器左右各 12px，普通输入使用 flex，正文 flex: 1/min-width: 0；仅「+」与右侧一个 44px 操作位常驻。空草稿显示语音，文字、附件或上传期间显示发送（上传期间禁用）；录音时保持原语音组件挂载，复用停止转写及取消流程。折叠长文本和显式展开编辑仍使用原网格布局。

运行中停止按钮是状态栏的独立原生按钮，与会话控制按钮并列，不嵌套按钮、不展开会话控制、不清草稿。使用同一个 chat.running / interrupting / interrupt；手机发送直接进入既有 queue 分支，桌面的插入/排队选择保持原样。锁定会话与上传约束不变。

多行向上生长，最大 192px 且不超过现有 --app-vh 可视高度的 30%；复用 AppShell 对 VisualViewport 的监听、安全区及滚动策略，不新建键盘控制器。无架构契约变更，无原则例外。
