# 会话本地记录大小

## Why

用户需要在最近会话与项目会话中判断记录是否过大。各引擎的存储方式不同，不能将共享数据库大小或无法定位的记录显示成单个会话的大小。

## What Changes

- 在现有会话行、会话看板和当前会话显示实测记录大小。
- 按逻辑会话保存的原生引擎句柄汇总，区分完整、部分已知、尚未生成、缺失与暂无法获取。
- 采用独立、受限批量查询和短时文件定位缓存，不读取消息正文，不阻塞会话名单或消息加载。

## Impact

影响 Vibe Coding 前端会话元信息与 Java 只读文件统计。无数据库结构、Sidecar 协议、执行治理或上下文分层变更。
