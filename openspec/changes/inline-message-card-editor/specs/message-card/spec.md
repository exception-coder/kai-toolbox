## ADDED Requirements

### Requirement: 在对话中编辑回复卡片
系统 SHALL 在当前会话覆盖层复用卡片编辑器，不通过导航菜单或改变路由处理回复。

#### Scenario: 手机或桌面打开转卡片
- **WHEN** 用户从一条回复点击转卡片
- **THEN** 完整原文进入当前对话的卡片弹框，手机默认全屏预览，桌面默认弹框
- **AND** 手机更多菜单关闭，编辑器不随菜单或虚拟消息行卸载，关闭返回原操作或消息区

#### Scenario: 切换尺寸和会话
- **WHEN** 用户切换全屏或缩小
- **THEN** 同一编辑器保留正文与配置，路由不变
- **AND** 切换会话清除弹框，返回旧会话不自动恢复旧弹框

### Requirement: 复用受控卡片能力
系统 SHALL 沿用原工具权限、主题与导出实现，隔离独立工具草稿与对话原文。

#### Scenario: 编辑、导出和恢复
- **WHEN** 用户修改卡片或执行导出
- **THEN** 只修改本次卡片副本，不覆盖独立工具草稿或消息；全屏切换不重建编辑器
- **AND** 导出中保留节点并禁止关闭/切换大小，失败解锁且可重试，不重复导出

#### Scenario: 加载失败或未授权
- **WHEN** 模块加载失败或没有原内容工具权限
- **THEN** 加载失败可原位重试，未授权不挂载编辑器；两种状态都可关闭继续原对话

#### Scenario: 直接分享卡片图片
- **WHEN** 用户点击分享并等待图片生成后点击选择应用分享
- **THEN** 系统从该次点击直接将内存中的 PNG 文件交给原生分享面板，无需先下载或上传服务器；多页作为同一组交付
- **AND** 目标应用由设备提供，不承诺指定应用可用或已向收件人发送；取消、失败或能力不支持时保留原文与手动保存入口，不自动下载
- **AND** 修改正文、主题、分页或可见段落使旧图片失效；重复点击受理中不重复派发，修改后重新生成才可分享
