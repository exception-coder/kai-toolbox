# 设计

本机 `FORGE_CLOUDFLARE_ENABLED` 作为显式开关。控制器启动服务后启动命名隧道；完整重载使控制器重新装配，PM2 在隧道意外退出时有限次数恢复。重复 `start` 复用在线进程。全量 `stop` 删除受管进程。

启动等待先检查本机服务，再检查配置中域名的首页和 `/api/tools`；回源未就绪时继续等待并显示状态，配置或进程失败时给出日志入口。公网探测只用于启动验收，不将瞬时网络状态转为远端配置变更。Quick Tunnel 不参与自动管理。

适用产品原则：AI-01 保持当前工作区上下文；FEED-01 显示实际启动与公网状态；CTRL-01 在失败时提供 `logs cloudflare` 和 `tunnel check` 恢复入口。此变更只有 CLI 状态反馈，没有新增导航或对话框；不申请例外。
