## Context

五个工具各自通过 index.tsx 注册到内容分组。featureRegistry 自动注册路由并派生权限，shell 已有 replacesMenus 迁移机制。Graphify query 已定位页面与注册表，因工作区存在并行改动，以定向读取的当前源码补足新鲜度。此次属于 M 档导航变更。

## Goals / Non-Goals

统一入口并保留五种能力、旧权限、输入草稿及旧链接。退役 resume/workline 的前端注册，不删除存量业务数据，不改后端、不扩大清理范围。

## Decisions

- 新增 content-tools feature，页面只负责编排，工具通过各自 public-api 导出既有页面。旧 manifest 用 chrome 保留权限及兼容跳转；退役模块使用 hidden 完整退出注册。
- 使用 tool 查询参数标识当前工具，保留其他参数及 hash。复用 shell 权限上下文，合并入口权限或原工具权限允许进入对应能力，未授权页不挂载。
- 采用 CONSERVATIVE 组合，沿用 forge-enterprise 参考画像、现有 tokens 和项目开发页签模式。工具提供 embedded 模式以去除重复标题、外层卡片和边距，业务控件沿用原实现。
- 访问过的工具保持挂载，隐藏页签不接收二维码全局粘贴事件。按需加载仍复用外壳错误恢复能力。
- 原始工具 ID 是输入所属上下文（OBJ-01）；五个稳定能力视图使用页签（NAV-01），一处入口减少侧栏定位；CTX-01 保留切换输入；DENS-01 避免套卡；FEED-01 复用原有处理、导出、失败及重试；EVID-01 分开记录构建、浏览器和运行证据。
- 支持方向键、Home/End 和可见焦点；窄屏页签横向滚动，内容在 Shell 分配空间滚动。无权限提供回首页入口；异常参数明确提示并允许选择可用工具。无原则例外。

## Risks / Trade-offs

- 隐藏页面保留内存 → 仅挂载已访问工具，权限变化卸载对应页面，不添加持久化敏感输入。
- 旧权限与新入口可能漂移 → 测试旧授权单工具隔离、新入口授权和偏好迁移；从 manifest 重新生成权限目录。
- 并行任务正在修改公共目录及 shell → 复用其已提供接口，不修改无关暂存内容，提交仅限可拆分本次内容。

## Migration Plan

更新注册及生成目录，在现有 Vite 开发运行模式验收；不必为纯前端变更重启后端。验证包含工具切换与草稿、键盘、旧链接、权限、桌面/窄屏和 60 秒服务稳定观察。回滚仅撤回本次前端改动并重建目录；数据没有迁移。
