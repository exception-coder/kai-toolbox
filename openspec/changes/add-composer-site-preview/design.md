# 设计

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、IDEM-01、EVID-01，无例外。

主对象为当前会话及待预览应用资源 ID；应用列表与凭据沿用资源中心和浏览器预览公共 API。既有快捷站点/会话站点关联仍是链接管理，不据此推断账号，也不合并第二份账号配置。

现有输入框「＋」菜单增加一个动作，打开公共 PagePreviewDialog，无需跳菜单或路由。快捷入口不带 auto=1，因此先展示应用与环境、设备及目标路径，明确提交后才创建浏览器；AI 已准备且带 auto=1 的链接保留自动启动行为。切换应用用该应用登记地址初始化路径，避免请求新应用的旧路径。

菜单关闭后弹框独立挂载，关闭恢复「＋」焦点，草稿与原会话滚动不变。弹框状态按 sessionId 隔离，切会话卸载并沿用现有上下文释放逻辑。全屏/缩小、重复提交锁、新请求身份和迟到创建释放复用原实现。

列表加载、无可用应用、读取失败均保留关闭及配置/刷新恢复入口；不默认选择任意外部账号。键盘与手机使用既有弹框焦点约束和响应式布局。定向验收保护不自动创建、不发聊天消息、应用选择路径同步、明确提交、关闭恢复与切会话释放。实际浏览器检查桌面/手机/矮屏及空/失败恢复；真实目标登录与版本部署独立记录。
