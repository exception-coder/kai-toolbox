# 手机 Agent 结果优先

## Why

顶部、消息外观和执行 Dock 已经收敛，但结构化回复中的验证仍可能被文件清单挤到详情里；工具失败在消息流与执行链路重复呈现，当前轮完成又有消息标记和 Dock 两处入口。输入区的模型、引用等低频控件仍常驻。

## What Changes

- 从完成回复的原文提取开头、明确的变化与验证，保留风险、阻塞和待确认内容；文件与详细过程按需展开。
- 默认隐藏工具详情时，手机主会话将技术失败与过程保留在 Dock，正式会话错误和警告继续直接展示。
- 最近一轮结束状态由 Dock 承载，历史轮次仍有独立详情；共享复制本轮、变更和中性指标呈现。
- 手机模型组合、引用和空闲语音入口进入「＋」，保留发送、中断、草稿和配置权限边界；桌面不迁移。

## Impact

仅修改 claude-chat 前端呈现与定向测试，不改变模型输出协议、执行事件、后端或侧车。跨 Agent 的设计系统迁移保留为后续需求，不为本次增加平行基础设施。
