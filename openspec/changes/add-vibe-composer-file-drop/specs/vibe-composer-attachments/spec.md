## ADDED Requirements

### Requirement: 从当前输入区拖入文件

系统 SHALL 允许用户把一个或多个系统文件拖入全屏聊天及悬浮窗完整输入区，并通过既有上传接口添加到当前会话附件草稿，保留选择器与粘贴方式。

#### Scenario: 上传后保留草稿并等待手动发送

- **WHEN** 用户将文件拖入当前会话输入区并放下
- **THEN** 显示落点提示及上传状态，完成后显示附件，保留输入草稿，且不自动发送、补充或排队

#### Scenario: 连续批次与部分失败

- **WHEN** 附件和上传中的文件接近 10 个，用户连续拖入多批文件
- **THEN** 整批先预留名额，最多接收剩余数量，明确提示超出部分未上传；上传失败显示文件名与可恢复提示，已成功附件和草稿保留

#### Scenario: 上传期间切换会话

- **WHEN** 用户在附件上传完成前切到其他会话
- **THEN** 成功附件和上传计数仍属于原会话，原会话迟到错误不显示在新会话

#### Scenario: 受限输入与文件夹

- **WHEN** 会话锁定、处于演示模式、没有有效会话或拖入文件夹
- **THEN** 不上传，并说明当前限制及恢复方式，不绕过原文件大小或权限校验

#### Scenario: 非输入区及文本拖动

- **WHEN** 用户把系统文件放到输入区以外
- **THEN** 不上传并阻止浏览器打开文件，清除落点提示
- **AND** 普通文本与 URL 的原生拖动行为保持可用
