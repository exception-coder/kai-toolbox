# Git 分支按逻辑名称与来源浏览

## 范围
沿用共享 CommitsPanel 与现有 Git 工作树检查、切换预览及确认流程。分支选择采用逻辑名称列表和来源详情两层；新增只读比较接口，不改引擎、任务与 AI 上下文架构契约。

## 设计
适用产品原则：OBJ-01（精确引用）、NAV-01/02（单覆盖层）、CTX-01（仓库隔离与筛选恢复）、DENS-01（按需展开）、FEED-01/EVID-01（缓存与同步证据分离）、CTRL-01（切换确认）、IDEM-01（不重复写入）。无例外。

- 当前分支优先，严格区分大小写的逻辑名称分组；本地名含 remote 前缀不剥离。
- 每个来源保留原始 ref、SHA、上游；按已配置 remote 的最长前缀归一化，未知来源独立展示。兼容旧后端的普通 origin/gitee 名称，精确操作始终使用完整 ref。
- 全部/本地/远程与 remote 筛选；搜索完整名称与引用。默认行高至少 56px，长名称换行，复用移动 Bottom Sheet，搜索栏统一刷新。
- 来源详情放复制、查看提交和切换。远程来源已有同名本地分支时不提供覆盖式切换；无本地分支时明确创建跟踪分支。后端原有工作树、token 与目标 SHA 复核保持不变。
- 差异按需读取两个实际引用的固定 SHA，以 rev-list --left-right --count 计算；不 fetch、不 checkout、不遍历全部引用对。响应须匹配当前引用与 SHA，过期响应不用于同步结论。
- 刷新沿用现有接口，仅当前上游可能 fetch；其他 remote 保持本地记录，未提供的 fetch 时间标为未知。差异核对时间不能冒充 fetch 时间，更不能宣称实时远程同步。
- 新后端接口未加载时保留分组浏览，比较失败给出可恢复提示。新增后端能力运行验收待用户确认重启；不得自行重启。

## 验证边界
定向组件与临时真实 Git 仓库测试覆盖分组、来源筛选、精确动作、过期比较、不同 remote 分叉与相同提交，以及原有切换工作树安全。类型检查、前端构建、受影响宿主编译和项目门禁。真实手机浏览器未执行时明确标注，不以预览入口代替验收。
