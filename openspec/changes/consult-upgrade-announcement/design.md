# 公告交互与内容

适用原则：OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、CTRL-01，无例外。主对象仍是原咨询，公告依附当前页面标题，不增加导航或系统选择。

标题旁小标签对所有用户可见，点击使用现有Sheet展示日期和五项变化：截图直接问、关联系统探索、回答中准备草稿、附件拖入及源码/Git定位线索。正文仅描述已实现行为，注明证据取决于已接入资源、无法确认会说明缺口，不声称解除数据权限或完整运行验收。已有咨询按原范围兼容，跨系统新路由仍以实际部署及验收为准。

不自动弹出，不持久化已读状态或发请求；静态正文与复制文本来自同一内容对象。复制仅在用户点击后写剪贴板，成功反馈可转发；失败保留正文并允许重试/手动复制，不自动向同事发消息。

复用Sheet的焦点约束、Escape关闭和触发器焦点恢复，支持全屏Portal与窄屏滚动，底部复制按钮保持可达。打开、关闭、复制及重试不切换咨询或清空草稿；重复打开复用原静态公告，重复复制不创建对象。关闭公告不停止咨询。无需新后端、数据表或架构契约变更。
