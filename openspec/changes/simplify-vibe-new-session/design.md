## 实现与边界

适用 OBJ-01、NAV-01、NAV-02、CTX-01、DENS-01、FEED-01、AI-01、EVID-01、CTRL-01、IDEM-01，无新增权限或资源权威。对象为一次新会话意图，工作区完整路径及其目录候选仍由 ProjectCatalog 投影提供，不建立第二份目录配置。

采用用户指定的 A+B：标题及返回 → 最近有效配置 → 工作区及新建 → 可选项目 → 可用引擎 → 设置入口 → 底部创建。普通表单不套卡片，手机单列，工作区/项目支持固定候选搜索，最多三个可用引擎直接呈现，其余在选择器中。没有选择项目时执行工作区根目录并显示说明；目录消失、项目隐藏或跨工作区时不猜测其他目录。自动生成名称，沿用会话现有重命名能力。

新建工作区使用现有 Sheet：手填/浏览真实目录 → 既有目录浏览验证 → 项目库公开 registerWorkspaceRoot → 刷新原工作区投影 → 选中该根。此处“新建”指登记现有文件夹，不隐式创建磁盘目录。配置保存成功但刷新失败时提示部分成功，保留路径供重试。旧常用目录及移除、多目录聚合、Codex Auth、网关与模型均保留在设置；不删除旧偏好。已完成的克隆/聚合通过同一公开工作区登记能力返回新建面板，失败仍保留目录结果。

新建草稿和最近配置沿用同一浏览器用户范围 v1 偏好；仅扩展白名单 recent 字段，不存凭据、模型或会话标题。手动修改记忆草稿，显式发起有效创建时保留最近有效配置，未来复用必须重新核对目录、项目、引擎、服务商。旧偏好可作为待核验的最近候选，失效后不可直接创建。引擎列表以运行目录 ready+selectable 为准；旧引擎不可用时选用当前可用项并给出提示，不能把目录失败回退清单冒充已检测可用。已选择第三方服务商时显示其名称，失效不得静默改为官方。

新建面板使用主内容高度、单一内部滚动及底部操作栏；原消息区仅隐藏，保留原组件与会话运行。抽屉使用现有 Radix 焦点约束，关闭回触发器，目录保存中防重复提交且不把关闭当撤销。会话创建采用当前调用期间的同步锁，收到新会话 ready 或明确连接错误后释放；不自动重发未知结果。原创建协议未增加持久幂等键，本次不宣称跨刷新创建恰好一次。设置与选择不创建会话、不发送模型消息、不重启服务。

选择器搜索只过滤候选，不改变当前值；Escape 可退出，键盘可以进入候选后确认。参考现有组件及 [WAI-ARIA Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) / [Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)（2026-10-31 核对）。

## 风险与验证

复用并调整原新建/偏好/目录用例，重点核对跨根清理、无项目根目录、隐藏和删除项目、引擎空或不可用、失效网关、最近配置复用、重复点击与设置保存失败。检查桌面、手机及矮屏底部按钮、长名称搜索、焦点恢复；浏览器权限不允许时明确未执行范围，不用其他浏览器通道绕过。前端类型/构建及项目质量入口按实际执行报告；准备桌面和手机入口不等于已登录验收。本次调整呈现和原公共能力的消费，不改变 AI 编程架构的上下文、资源或执行生命周期职责，无需改写整体架构正文。
