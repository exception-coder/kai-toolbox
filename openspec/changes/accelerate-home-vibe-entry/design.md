# 设计

适用产品原则 NAV-01、DENS-01、CTX-01、FEED-01。主对象是现有 Vibe Coding 模块和其会话；入口仍指向 manifest 中的 `/tools/claude-chat`，不创建第二套会话或菜单目录。

React 挂载前，HTML 加载壳只根据同源已缓存的登录与权限快照显示快捷链接。无快照、快照损坏或无权限时隐藏；最终访问仍由现有路由守卫和服务端鉴权决定。加载壳保留状态说明，链接可用键盘聚焦，窄屏可直接点击。

React 首页先显示已授权且未被用户隐藏的 Vibe Coding 入口，其他入口在浏览器空闲时补齐；没有该入口权限时先显示第一个可见模块。命令面板及视频搜索依赖首次触发 Ctrl/⌘+K 或搜索按钮时加载。失败会输出诊断日志，后续触发可重试。重复点击快捷入口仅导航至同一现有路由，不产生写操作。用户切换页面后沿用路由及会话恢复规则。

验证需覆盖生产构建、OpenSpec 校验、权限快照分支、键盘入口和真实手机从 HTML 响应到可交互的时间。构建成功不代表真实手机秒开；当前较大的公共启动包仍需单独测量。
