# 修复会话复制及操作反馈

## Why

普通复制曾被 Auth 链路复用逻辑收敛回原会话。区分两种意图后，创建结果仍依赖引擎 Ready 和 15 秒浏览器计时，回执丢失或引擎变慢时只能提示结果未知，缺少自动核对。

## What Changes

- 普通复制显式创建独立配置副本，继承源会话目录、引擎、服务商、Auth 和分组；Auth 切换继续复用原链路。
- 普通配置副本与持久回执原子保存，数据库提交即确认创建；后续引擎连接独立展示。
- 请求编号跨刷新保留，网络故障最多三次幂等核对；明确拒绝不盲目重试，副本删除不自动重建。
- 最近会话和项目会话使用相同复制入口，移动端及悬浮窗保持一致。

## Impact

会话列表反馈、登录态配置复制接口与应用自动初始化的 SQLite 回执表；不改变 Auth 交接协议，不复制原生历史，不调用模型，不自动重启服务。无人工待执行 SQL。
