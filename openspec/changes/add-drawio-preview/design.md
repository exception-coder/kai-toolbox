# draw.io 文件预览设计

## 对象与交互

适用 OBJ-01、NAV-01、CTX-01、FEED-01、EVID-01、IDEM-01，无例外。对象沿用已选择的浏览器文件 ID 或会话工作目录文件路径，不新增菜单、列表或远端文件服务。选择/拖入后在原弹框查看；全屏为原对象的覆盖层，退出回预览，关闭回原入口。重复查看不创建持久对象。

沿用现有 Radix 弹框的焦点约束，图形全屏可 Escape 退出并恢复触发器焦点；手机工具栏换行，画布占剩余区域并负责平移/滚动。解析和渲染分别展示进行中状态；无效、空、超限、超时可重试或切源码，关闭后不接受迟到回调。只读操作无保存草稿。全屏不宣称修改文件。

## 实现边界

doc-viewer/drawio 负责读取与渲染，公共 API 供其他 feature 复用。`.drawio.xml` 专门识别，普通 XML 不自动当图。官方 v32.5.5 WAR 中的 Viewer 已内嵌 stencils，使用本地固定静态路径；仅打开图形时请求，不重复加载图形库，也不增加首页 JS 解析负担。

浏览器有界解压压缩页面，校验 mxfile/mxGraphModel，拒绝 DTD/实体，5 MiB 源文件、20 MiB 展开文本、100 页、20000 单元。只将校验后的单页 XML 通过 postMessage 传入隔离 iframe；回执核对 Window、opaque origin 和每次实例随机 token。内容不拼入 HTML/脚本。iframe 无同源权限，CSP 禁止连接/外部媒体和字体，不执行自定义 stencil 脚本或跳转链接。内置数学扩展不加载。该隔离避免第三方全局对象污染 Forge。

前端本地文件入口和可完整读取的工作目录文本文件复用渲染器；工作目录结果被截断时不给出残图，明确提示选择原文件。后端文档源白名单保持原状。本期不增加编辑、导出、原文件写入或协作服务。

## 消息链接入口（2026-10-24）

AI 回复的本地图文件链接在原消息上打开只读弹框，不跳转菜单、不启动系统程序。文件身份为 sessionId + 规范化路径；相同链接复用当前弹框。支持 Windows/Linux 绝对路径、file URI、裸相对路径和编辑器行号后缀，外部 HTTP 链接保持不变。按需加载弹框及已有渲染器，不在回复初次展示时读取文件。

`GET /api/claude-chat/sessions/{id}/diagram` 通过现有会话目录及 `SessionLocalPathAccessService` 解析路径，仅允许 draw.io 扩展名和完整 UTF-8 文本，5 MiB 上限在读取前与有界读取后分别检查。范围外文件遵循下述精确会话引用兼容规则，不扩大目录或文件树权限，也不执行文件或改写数据。后台只读取原文，图形解析仍在前端。

加载/读取失败保留弹框和路径，可手动重试或关闭；不自动重试和降级到通用终端/系统打开。请求带取消信号，关闭/卸载或切换会话后丢弃旧读取；关闭不留图原文缓存。关闭恢复原链接焦点并禁止滚动跳转；流式更新替换触发节点时焦点恢复到原消息。沿用 OBJ-01、NAV-01、CTX-01、FEED-01、EVID-01、IDEM-01，无例外。

## 验证

定向回归覆盖格式、分页与边界、预览入口和隔离协议。真实浏览器检查压缩/多页、缩放、全屏/恢复、手机与桌面尺寸以及损坏输入；记录 CSP 外部请求是否被阻止。类型检查、前端构建和项目质量门禁证明构建范围，正式服务运行版本另行标识，不自行重启。

## 跨目录会话证据修复（2026-10-29）

原图文件实际存在，且当前会话助手明确给出链接，但会话主目录为 application-starter，文件位于另一工程；目录归属校验提前拒绝，尚未进入 XML 渲染。这与此前本地图片的跨工程证据问题相同。

图片的精确引用登记扩展为 `SessionArtifactReferenceService`，由同一已鉴权历史分页入口登记，图片与普通 Draw.io 文件链接分类型保存。图文件请求要求登录与会话访问权限；优先检查既有项目范围，范围外只允许 standard 开发会话助手明确引用的绝对路径。用户消息、裸文本、其他会话、同目录未引用兄弟文件及 review-only/consult-readonly 不能授权。普通文件链接必须为 `.drawio` 或 `.drawio.xml`，保留 UTF-8、5 MiB、全局路径排除，并在引用兼容路径上复核真实路径的排除策略。不会自动登记整个项目、修改工作目录、开启通用文件访问或启动系统程序。

引用缓存沿用 128 会话、每会话 512 个有类型的路径。正常历史分页负责较早引用，直播/冷缓存仅从当前逻辑会话已保存的最多 8 个原生句柄读取最近 100 条，未命中时提示重新加载对应历史页；不扫描全量 GB 历史。重启后由历史页重建。文件身份为会话 ID、类型和规范化路径，重复点击只读，不产生新对象。

适用 OBJ-01、NAV-01、CTX-01、FEED-01、EVID-01、IDEM-01，无例外。主对象、消息触发器、原位弹框、全屏/关闭、焦点与窄屏行为不变，本次仅修正后台授权，复用已有加载、失败、重试和关闭恢复；无写入与草稿。回归验证覆盖已鉴权历史页登记和接口读取，不以单元测试或旧服务健康响应宣称正式版本已加载。
