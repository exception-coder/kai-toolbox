# 会话内 Markdown 文件预览

## 默认内嵌扩展（2026-11-01）

用户要求本地 SQL、Markdown、draw.io 文件无需点击即可阅读。将主会话正文中的已识别链接改为自动内嵌，接近阅读区再加载；保留复制、刷新、错误重试及可选展开阅读。复用既有受控读取和渲染器，不递归展开文件内部关联文档、不加载远程文件、不执行 SQL、不增加目录权限。下文点击弹框为原实施记录，默认入口以本节及设计的内嵌约定为准。

## 为什么

Vibe Coding 的 Draw.io 链接已能在当前会话预览，但相邻 Markdown 说明链接仍启动系统程序，移动端不能直接读文件，用户需要离开当前工作流。

## 改动

- 本地 `.md` / `.markdown` 链接按需打开只读弹框，提供正文、源码、全屏及恢复入口。
- 沿用会话文件接口和有类型的精确助手引用，完整读取有界 UTF-8 内容。
- 文档内相对图片和链接以文件所在目录为基准；Markdown 在同一弹框继续阅读并可返回。

## 范围

不增加菜单、文档副本、编辑器、MDX 执行或通用远程 URL 抓取；不扩大项目目录、工作台登记及咨询权限。服务重启与运行验收另行取得本次明确授权。

## SQL 原文预览扩展（2026-11-01）

用户要求 SQL 文件与 Draw.io、Markdown 一样可在会话点击查看。增加 `.sql` 本地链接的只读高亮、行号、原文复制与读取重试；完整读取及精确引用复用现有文件边界，不调用数据库、不执行脚本、不改变待执行 SQL 登记。受保护文件类型扩展按现有完整规格维护，新增设计与验收集中于本 change。
