# 会话工具分类与主次

## Why

手机更多菜单有四个常驻动作与六个平级分组，目录、用量、站点存在重复入口，连接和运行能力混入会话操作。展开多个内容后缺少清晰返回路径。

## What Changes

- 手机首页保留新建与会话列表两个并排快捷入口，五类工具依使用目的排序。
- 在同一浮层进入单一分类，提供固定返回入口与焦点恢复，普通打开回到首页。
- 常用文件与 Git 优先，项目准备在后；连接、同步、日志、自检和重启归入维护。
- 合并同目的用量 / 站点 / 提交记录入口，保留各自现有能力、权限与执行限制。
- 同步导览和文档路径，保持既有桌面快捷入口。

## Impact

仅 claude-chat 前端导航，不增加 API 或改变引擎、执行和数据契约。替代此前更多菜单分类的呈现决策；标题轻量切换器和消息分层增量保留。
