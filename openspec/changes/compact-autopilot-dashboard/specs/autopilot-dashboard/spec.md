## ADDED Requirements

### Requirement: 贴边入口提供最近规划的只读快捷看板
系统 SHALL 向有 Vibe Coding 权限的非演示用户提供贴边会话入口，点击展开侧边轻量看板，查看最近 8 项已有规划并进入原会话。关闭时不得查询或激活聊天引擎。

#### Scenario: 查看规划状态并筛选
- **WHEN** 用户展开会话快捷看板
- **THEN** 最近规划沿用服务端自动监督状态，提供进行中、已完成、异常筛选
- **AND** 暂停、待确认、停止与 Agent 自验保持可辨，不将空闲会话当成已完成规划
- **AND** 自动更新保留已有条目的相对顺序，只有手动刷新恢复最近排序

#### Scenario: 进入已有会话
- **WHEN** 用户点击规划条目
- **THEN** 进入该条目的原 sessionId 对话视图，至多由一个所有者执行会话切换
- **AND** 不创建或执行任务、不改变规划运行状态，保留原会话草稿

#### Scenario: 状态暂不可读或面板关闭
- **WHEN** 查询失败、快照过期、无匹配规划或用户关闭面板
- **THEN** 明确区分失败、旧快照与空集合，并保留重试、关闭和完整看板入口
- **AND** 关闭取消请求和轮询，切换账号不复用上一账号的数据
- **AND** Esc 关闭恢复入口焦点，手机窄屏和键盘视口变化时列表末项保持可达

### Requirement: 看板提供稳定的返回对话入口
自动推进看板 SHALL 在桌面和手机提供常驻的返回对话按钮，并沿用当前会话及原输入内容。

#### Scenario: 手机看板正文已滚动
- **WHEN** 用户查看看板并滚动任务或项目设置
- **THEN** 返回入口保持可达，点击后回到原会话输入并清理看板路由参数

### Requirement: 运行列表优先于低频配置
看板 SHALL 默认折叠项目设置和已绑定规格，保留原配置能力；手机使用可访问的范围下拉，正文单独滚动。

#### Scenario: 打开未绑定规格的会话看板
- **WHEN** 当前会话未绑定规格
- **THEN** 不展开长说明占据首屏，展开规格区后可返回对话配置

#### Scenario: 调整范围或展开设置
- **WHEN** 用户选择范围或打开项目设置
- **THEN** 复用原范围查询及配置接口，不修改运行状态、权限或任务结果
