# Vibe Coding 会话

## 首屏加载

菜单注册只读取元数据与轻量路由入口，不连带加载其他工具的页面组件。悬浮窗、语音界面和后台答题界面按实际状态下载；普通消息只在出现完整 Mermaid 图表块时加载图表库。聊天实例仍跨路由常驻，各界面保留独立错误恢复。

主样式只扫描 `frontend/src`，避免父目录遍历、本地缓存和构建文件拖慢样式生成。入口 HTML 的加载壳沿用手写样式，不需要 Tailwind 扫描。验证构建应输出到已忽略的 `frontend/dist` 子目录，防止开发服务监听临时产物引起重复刷新。

引擎品牌图标使用原 SVG 子集，避免开发服务下载整套图标集合。升级 react-icons 或增补品牌后运行 `node scripts/generate-engine-icons.mjs`，用 `--check` 核对生成资产与许可证。源码加载提速不代表外网真机已经验收；需结合实际启动阶段日志测量。

## 团队仓库初始化

会话工具 → 系统 · 设置 → 团队依赖，在依赖仓库区执行「初始化 / 拉取」。默认自动创建用户目录 `.kai-toolbox/team-tools` 并克隆缺失的五个团队仓库；配置过依赖目录时沿用配置。已有仓库沿用 origin，仅快进更新；未提交修改或非 Git 占位目录会保留并报告，不删除或重建。拉取独立于下方插件安装及提交推送；打开面板本身不执行写操作。

## 会话项目分组

工具会话的项目列表保留手动分组；未设置分组的会话按主工作目录自动归组，显示目录名和完整路径。Windows 路径大小写、斜杠及尾部斜杠统一识别，同名但路径不同的目录分别显示。只有未记录主目录的会话继续进入「未分组」，附加项目不改变归属。

进入项目、筛选和全局搜索标签沿用同一规则。会话行仍可设置自定义项目 / 需求分组；选择「恢复自动分组」会清除手动分组，并按主目录重新显示。手动项目可继续重命名；自动目录名称随实际主目录变化。分组展示不写入推断名称、不注册新项目，桌面与手机使用同一列表规则。

## Codex 项目与会话同步

在「会话工具 → 会话 → 同步 Codex 项目与会话」选择本机 `.codex*` 授权目录，分页浏览原生项目和未归档会话。项目筛选先读取原生成员，再按真实根目录精确匹配尚无项目 ID 的旧会话，并注明「目录匹配」。导入后保留项目名称，以授权目录和完整项目 ID 派生的身份后缀区分同名项目；“全部会话”按工作目录归组。此目录可能同时包含桌面、CLI 和 VS Code 记录。空项目可以查看根目录或进入既有新建会话流程，不自动注册业务系统。

导入只保存现有会话存储中的恢复元数据：授权目录、工作目录、原生线程 ID、模型和推理强度，不启动模型或复制聊天正文。成功后明确显示「导入成功」及新增 / 复用数量，清空选择；已导入记录保留「打开」入口，不可再次单选或批量选择，整页已导入时显示「本页已全部导入」。后台刷新失败不抹去已确认的导入结果，剩余记录可在刷新恢复后继续导入。服务端仍对重试复用已有会话，保留 Forge 内的标题、收藏、分组、配置及运行状态。打开后使用已有历史和原生恢复链路；继续对话前需由当前客户端释放同一线程的写入连接，目录读取不能证明另一个客户端已释放。

遇到「原生会话被占用」时，占用端可能是 VS Code、Codex 桌面或 Forge 语音连接，不能仅凭报错判定为上一轮或桌面。先在持有该会话的客户端停止任务，再离开或关闭该会话，释放后在 Forge 重试当前消息。仅停止生成或取消订阅可能不会立即卸载线程；不必先关闭整个 Codex 桌面，也不要删除锁文件。Forge 只对尚未发送的启动请求做有界重试，不抢占其他客户端、不自动更换原生会话；占用失败保持待发送队列暂停，语音也不提示用文字绕过同一锁。

通过同步创建的会话在完整列表和最近会话中显示「Codex 导入」。来源根据创建时的授权目录、原生线程 ID 与稳定逻辑身份核对，旧导入无需再次导入；切换引擎后仍可从保存的 Codex 句柄识别。原本就在 Forge 中、同步时被复用的会话保留原来源，不能仅凭当前使用 Codex 就判定为导入。

列表每行保留一个「更多」入口，收藏状态仍在标题旁显示；收藏、复制 ID / 配置、规划过期 / 解锁、分组、重命名和删除使用带文字的浮层，不再盖住标题。复制 ID 的成功 / 失败反馈保留在菜单内，失败可重试；运行中限制与删除确认沿用原有流程。手机菜单避开屏幕边界，键盘 Esc 关闭菜单后恢复到该会话的操作入口。

最近会话和项目会话列表都提供「复制会话配置」。点击立即显示复制进度，继承源会话的工作目录、引擎、模型、服务商、Auth、分组和附加目录，创建独立副本；原会话保留，历史消息和待发送队列不复制。确认副本就绪后切换并显示成功；切换 Auth 仍从当前会话配置进入，沿用原有授权链路复用。

复制期间阻止重复操作；失败保留实际原因，超时提示结果尚未确认，先检查会话列表再决定是否重试。已发送的复制不会在断线重连时再次提交。桌面、手机、专注 / 全屏和悬浮窗共用进度提示。此修复的后端行为待加载新版后验收，不能仅凭前端热更新判断已经生效。

本机账号仅对管理员或关闭认证的本地单用户开放。授权目录必须位于运行用户目录中，排除项目不可导入，预览十分钟过期，可刷新后重新选择。首期不回写桌面、不自动监听同步，不同步归档、图标、收藏或多根目录执行权限。CLI 缺少原生项目接口时明确报错；线程目录不受项目显示名推断影响。此前同步接口的后端和 Sidecar 已加载；本次新增的来源字段及侧栏 / 浮层依赖对齐尚待本次确认重启后加载，真实页面导入 / 续接验收状态见本功能 OpenSpec tasks。

## 订阅额度与本地用量

用量页顶部按已登记引擎和已加载会话的账号配置来源展示 **5 小时剩余 / 本周剩余**。当前会话账号优先；同一引擎同目录的会话共享一行，不同目录分别显示，不相加各账号百分比。可刷新全部或单行，最后获取时间保留真实服务商快照时间，缓存命中不会变成新读数。

Codex 读取账号 App Server 真实窗口；Claude 复用 OAuth usage 的真实五小时/七天窗口。未返回窗口、未登录、API计费、未绑定会话和其他引擎尚无核验接口时明确显示原因，不从本地 Token 或固定价格参照推算余额。不同配置目录也可能登录同一真实账号，汇总不宣称已识别全部本机身份。

本会话 Token 和默认目录日志汇总是独立辅助信息。Claude 新额度链路需后端加载更新后验收；普通前端构建应避免自动发布共享助手 SDK，独立执行 typecheck 和 Vite 验证构建。

页头显示当前对话方式：**开发助手**用于项目代码和任务，**自由对话**用于问答、写作和内容创作。点击名称展开选择；切换保留各自会话和适用草稿，不会把两种方式的消息混在一起。

## 提交记录与推送

在会话工具的 **提交记录** 中选择仓库，查看当前分支的远端目标及领先、落后数量。点击 **Push** 后核对目标地址、固定提交版本和全部待推送提交，再确认推送；此操作推送分支，不是单独推送选中的历史提交。

推送期间禁止重复提交和切换仓库。没有上游、分支落后或没有待推送提交时会说明原因；失败后保留结果，可刷新远端状态再决定是否重试。全屏会话与浮动会话使用同一入口，支持移动端。

## 新建会话默认选择

点击「开始会话」后，当前浏览器记住工作区完整路径、目录路径、引擎及服务商档案 ID。刷新或重新进入时恢复这些默认值；不同 Forge 用户分别保存，不自动同步到其他浏览器、设备或访问地址。只保存选择，不额外存储 Key、服务商地址、模型或会话别名；Codex Auth 目录沿用已有独立偏好。

工作区按路径匹配，顺序变化不会选错；失效工作区提示重新选择或手填。服务商未加载、已删除或引擎当前不可用时明确提示，仍可重新选择或重试，不静默换用官方。读取档案后模型默认值取当前档案，保留已经手填的值。本地存储拒绝时当前表单仍可使用，并说明刷新后可能无法记住。

打开、取消、功能导览和跨模块显式启动不保存新默认值，也不自动创建会话。目录和服务商仍受原有后端校验约束。

## 会话视图导航

桌面主栏显示对话、推进、用量、会话看板；绑定文档或有评审时显示相应入口。轨迹、站点统一收在末尾的「更多」中，仍查看当前会话；进入后「更多 · 轨迹 / 站点」标明当前位置，可随时切回对话。手机保留对话、推进、看板和更多，文档、用量、评审沿用更多入口。

Vibe Coding 已移除数据库页签、SQL 登记 / 管理弹窗及其自动查询，不再后台每 3 秒读取待执行 SQL。已有台账数据、Agent SQL 登记服务和独立数据库工具保留；此次界面清理不会删除或执行历史 SQL。

更多菜单支持键盘、Esc 关闭和焦点恢复；跨手机 / 桌面断点会关闭浮层，保留当前会话、视图、草稿与后台任务。功能导览和完整指南使用相同入口路径。

## 移动端对话工作台

最近消息缓存按登录凭据和会话 ID 隔离。切换时先恢复目标会话的缓存，并更换该页面的观察连接；旧会话的迟到输出不进入新消息列表，后台代码任务继续执行。

规划已过期而锁定的会话不进入最近会话或手机快速切换列表；需要查看或解锁时，在完整会话列表筛选「规划已过期」。

上滑阅读时保留当前位置。点击 **跳到最新** 会先核对权威最近页，显示获取中，更新完成后定位实际末条底部；失败原位重试。同条数缓存替换也会更新贴底目标，长回复重新测量时以当前末项校正位置；实际贴底后才隐藏按钮并恢复跟随新输出。获取期间主动上滑或切换会话会取消定位，不被迟到响应拉回。

跳转后随消息容器的高度测量补齐位置，不再因固定等待时间结束而停在旧末尾；主动滚动、触摸或键盘导航会取消跟随，无持续轮询。消息中的 `/D:/...` 本地文件链接会转换成 Windows 盘符路径后打开，Linux 绝对路径保持原样。

手机端优先保留消息阅读区。输入框上方的 **Agent Dock** 汇总运行状态和队列数量；点击展开当前执行、待发送消息、OpenSpec 监督及语音入口。暂停队列有明确提示，仍可逐条移除、清空或在允许时发送。

运行中点击输入区发送按钮，选择 **加入队列（默认）** 或适用的 **补充到当前轮**；打开或关闭选择器不会发送消息。停止按钮独立保留。手机回车换行；桌面回车在运行中加入队列。队列在本轮正常结束后继续，异常结束暂停。连接、恢复或错误中的语音控制仍显示，空闲语音通过 Dock 开启。

## 最近会话看板

工作区页签 **会话看板**（手机为“看板”）按最后活动时间从最新到最早展示最近 20 个未锁定的开发会话，不按收藏置顶。会话标题与项目用于了解近期工作，状态区分进行中、空闲、已中断、已结束与待恢复。

“有待发送”筛选同时包含运行、空闲或中断会话的服务端持久队列，显示条数及前三条任务摘要；尚未核对的队列也保留并明确提示。读取失败不视为零条，可以单独重试。每个队列显示实际获取时间，看板每 15 秒更新，离开后不继续轮询。点击“查看会话”回到对应对话处理；浏览看板不会发送任务。

## 会话记录大小

最近会话、项目内会话列表和会话看板在元信息行显示 **记录大小**。当前对话的输入区上方可以展开统计范围、各引擎已知大小、文件数和读取时间，并单独刷新。查询独立于消息加载，每 30 秒更新；不读取聊天正文，不运行模型。

统计当前 Forge 会话已保存的原生记录，按真实文件去重；Claude 包含主记录和子 Agent JSONL，Codex 按会话保存的授权目录查找 rollout，Pi 和 Antigravity 使用已适配的 transcript，Copilot 包含该会话独立目录的事件、计划及检查点。它是文件逻辑长度，不能代表 Token、模型上下文窗口或磁盘分配空间；工作区源码、Forge 上传附件、认证配置和共享数据库不计入。

Qwen、Trae、OpenCode 和 DeepSeek Harness 尚无完整文件归属适配，显示“记录暂无法获取”；未生成、未找到、读取失败分别说明。多引擎统计不完整时显示“部分已知”，不会冒充总大小或显示成 0。刷新失败保留原结果并注明“旧数据”。文件定位索引最多缓存 30 秒，新记录可能在下一次刷新时出现；已定位文件的长度每次重新读取。

本次代码、专项测试和界面夹具验证与真实服务验收分开记录；新查询需后端加载本次版本后才能在实际会话使用，尚未重启。

## Codex 续问建议

官方 Codex App Server 文本会话正常完成后，Forge 通过锁定的 Codex 0.162.1 实验协议 `thread/prediction/request` 请求建议，等待 `thread/prediction/updated` 返回真实文本。空输入框以浅灰文字预览；桌面按 **Tab**、手机点击 **采纳建议** 只填入草稿，再由用户发送。直接输入或按 Esc 可以忽略建议；没有建议时保留普通占位文字。

建议绑定 Forge 会话、原生 thread 和已完成 turn。发送下一条、切换会话／模型／服务商或账号后不沿用旧建议，附件及非空草稿不被覆盖。请求使用独立且可取消的只读辅助进程，不新增用户轮次，不执行工具；开始下一轮前等待辅助进程释放，失败不改变主任务结果。第三方 SDK、语音、咨询、评审及一次性任务不启用此能力。

账号是否支持、是否返回非空建议仍以实际通知为准。代码和定向协议／输入框验证已覆盖；目标后端及 Sidecar 加载后的真实账号运行验收待本次重启授权，不以请求应答或静态测试代替。

## 原生语音对话

在 Vibe Coding 的 **Code Agent → 官方 Codex** 会话中，点击输入区上方的 **语音对话**（手机端从 Agent Dock 展开）并允许麦克风。语音发起的代码任务仍在执行时，可以立即重新连接原会话音频，无需等待任务结束。显示“语音已连接”后可以连续说话，听取 Codex 回复并在聊天气泡中查看转写；桌面端同一通话内也可通过原有“补充到当前轮”补充文字。

**静音**只关闭麦克风输入；**结束通话**停止收音和播放，已启动的代码任务继续执行，仍沿用原有工具审批。原有文字草稿保留。你说的话和助手口头回复逐句显示在原有聊天消息列表里，转写过程中更新同一气泡，结束通话后保留在当前视图。语音文字尚未作为独立历史消息保存，刷新或切换会话后以原生线程历史为准；代码任务输出保持独立。

同一会话只保留一路音频，最后主动点击连接的设备接管：在手机点击恢复时，电脑停止收音和播放并显示“语音已转移到另一设备”，代码任务继续执行。旧设备不会自动抢回；连续多端点击以服务端最后收到的合法请求为准。连接仍受麦克风权限、网络和上游能力影响，失败可明确重试。

刷新、切换会话、隐藏页面或网络断开会结束通话，但不停止代码任务。同一浏览器标签页会记住该会话的恢复提示；返回后显示 **恢复语音**，需要点击才会重新收音。原语音线程仍在执行代码时，恢复操作立即协商新音频连接，不新建、排队或中断代码任务。重连会等待旧音频关闭确认，超时可重试；若原线程已退出或任务从未开启语音，会明确提示不能恢复。离开页面、断网或切换会话会释放本地音频；显式结束通话会清除恢复提示。浏览器禁用会话存储时仍可开启语音，但不能保留刷新恢复提示。授权拒绝、设备占用和连接失败会显示原因，可调整浏览器权限后重试，也可继续文字会话。请使用 HTTPS 或 localhost；手机通过局域网访问时也需要 HTTPS。

当前依赖锁定 Codex 0.162.1，语音继续使用实验性 realtime v3 和同一官方登录目录，账号及上游服务须支持 realtime。本次升级已校验语音协议，真实音频往返尚未复测。Claude、第三方网关、咨询、评审和委托会话不开放该入口。原有“语音输入”是转写为文字，仍使用其独立的 Whisper 配置。

## 实现与验证入口

### 彩虹胶囊与会话委托的边界

彩虹胶囊继续作为业务系统内的只读咨询入口；会话委托、邀请码、Grant、公共 Session Client 和委托 SDK 已移除。胶囊使用独立的 `CapsuleRelay*` 组件，复用宿主用户身份、项目绑定和咨询会话，不赋予开发助手权限。

为兼容已部署宿主，胶囊仍使用 `/api/session-client/v1/relay/capsule/ws`，凭据仍从配置中心 `toolbox.claude-chat.session-client.relay` 读取。该命名空间只配置胶囊宿主认证，不恢复其他 Session Client 路由。开关默认关闭；managed 多客户端模式的空列表拒绝所有客户端，配置撤销在下一条消息生效。

排障需要分别验证隧道、WebSocket 握手和会话就绪：普通 `/api/tools` 返回 200 只能证明 HTTP 可达。胶囊固定只读策略、拒绝开发命令，并使用现有会话所有权校验。回归入口：`CapsuleRelay*Test`、`SessionExecutionPolicyTest` 和 `ClaudeChatSessionAccessPolicyTest`。

### 原生语音实现

浏览器 WebRTC 媒体由 `lib/nativeVoice.ts` 管理，`hooks/useNativeVoice.ts` 管理通话状态，`hooks/useVoiceRecovery.ts` 管理显式恢复，`lib/voiceTranscript.ts` 组装语音消息，`hooks/useVoiceTransport.ts` 按通话隔离事件并交给现有聊天列表；Java `SessionVoiceService` 只转发给发起连接，sidecar `codexRealtime.ts` 在当前原生线程上启动或重连 realtime。SDP 不进入消息回放或前端调试记录，音频由 WebRTC 直接传输。

语音轮次包含多个原生代码轮次；只有通话结束且代码收口、受管进程释放后，才释放 Forge 消息队列。浏览器每 10 秒续租，sidecar 在 45 秒无心跳后清理通话；启动超时为 90 秒。

回归入口：前端 `nativeVoice.test.ts`、`useNativeVoice.test.ts`、`useVoiceTransport.test.ts`、`NativeVoiceControl.test.tsx`，sidecar `codexRealtime.test.ts`、`codexAppServer.test.ts`，后端 `SessionVoiceServiceTest`。`npm run app-server:schema:check` 校验锁定 CLI 的实验语音协议，升级 Codex 时必须重新检查并执行真实音频往返验收。

## 待提交文件

「会话工具 → 工作区 · 项目 → 待提交文件」可勾选「隐藏 Git 忽略项」，按当前仓库的 `.gitignore`、仓库排除和全局忽略规则过滤显示，包括已跟踪但匹配忽略规则的文件。取消勾选恢复完整列表；只改变显示，不修改 Git 配置、暂存区或跟踪状态。文件树与计数同步显示，并提示隐藏数量；全部被隐藏不代表工作区干净。新版后端未加载时筛选暂不可用，原列表仍可查看。

## 轮次变更记录

每轮开发开始时保存 Git 基线，正常结束、失败或中断后保存观察到的文件变化。在「会话工具 → 工作区 · 项目 → 变更记录」按路径检索当前会话的记录；新轮次结果旁的「本轮变更」查看对应记录。记录保留新增、修改、删除、重命名路径及提交区间，不保存文件正文。

共享工作区中的变化不能据此认定由当前 Agent 独占产生。未变化的原有脏文件不会计入；原有修改被提交时明确标注。旧轮次不补造基线，忽略文件、修改后完全还原及采集限制可能形成缺口；断线后未收口的记录保持明确提示。首次启用需要新版后端加载自动建表，服务尚未提供接口时可以重试。
