# 外观变体

## 边界与选择

只给 ForeConsultPage 根节点增加 `data-consult-skin`，原有组件树保持同一身份，不通过 key 或条件分支切换两套页面。新增受根标记约束的 CSS 变体，继承 Forge 全局的背景、文字、边框、主色与状态 tokens，覆盖原有渐变、玻璃、高光和装饰阴影。业务系统分类颜色继续表达原分类。

既有图谱位置、拖拽、窗口宽度、滚动归属、模块选择、会话及附件流程不变；无后端、权限、提示词或业务配置改动，无 AI 编程架构契约影响。原有 space.css 不修改。依据 [CSS 自定义属性的继承与作用域](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties)（2026-10-15 查阅），局部映射存量中性色到全局语义色，避免新建第二套明暗主题。

## 交互与原则

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、IDEM-01，无例外。

- 对象仍为当前咨询及业务系统，原身份和页面入口不变；工具栏第一项提供“Forge 风格”开关，不新建设置页。
- 开关按下表示 Forge 风格，取消按下回到原有玻璃风格，默认保留原有外观。本地键为 `toolbox.fore-consult.skin`，仅接受 glass/forge，非法值回退原风格。
- 即时切换不触发任何咨询创建、重连、发送、归档或保存业务配置请求；重复点击只改变外观偏好。
- 使用原生 button、aria-pressed、可见焦点、44px触摸高度。存储不可用时本次仍生效，显示“仅本次”，不影响咨询输入。
- 空状态、加载、错误及当前抽屉继续原有恢复流程；不为外观切换清除草稿或重挂组件。
- 验证原风格/Forge风格、全局浅色与深色/阅读材质、手机与桌面，并核对同一草稿/组件身份和既有显示范围策略。
