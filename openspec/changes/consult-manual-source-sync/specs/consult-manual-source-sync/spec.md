## ADDED Requirements

### Requirement: 管理员能够在咨询配置主动同步候选源码
系统 SHALL 在原咨询配置提供一键操作，使用已保存的前8个可用候选顺序逐项检查当前分支上游，并复用现有安全快进能力。发现和执行接口 SHALL 只允许管理员，且不接受任意目录或Git命令。

#### Scenario: 手动操作不复用自动检查时间缓存
- **WHEN** 管理员主动检查一个五分钟内已自动检查的候选项目
- **THEN** 系统重新获取远端差异，按现有安全快进条件执行，并记录本次检查时版本

#### Scenario: 项目在执行前或fetch后被排除
- **WHEN** 候选在执行前或fetch后不再属于当前可用范围
- **THEN** 系统拒绝该项目更新，不扩大到其他目录

#### Scenario: 局部失败与结果未知
- **WHEN** 一项失败或请求断连
- **THEN** 页面保留已完成结果并继续其他项目，断连显示结果未知，允许重新检查

#### Scenario: 并发及本地修改
- **WHEN** 项目已有Git操作、未提交文件或分叉
- **THEN** 系统保留本地状态并显示原因，不强制覆盖、不重复发起同目录同步
