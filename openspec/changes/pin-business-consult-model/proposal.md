## Why

业务系统咨询当前把空模型交给 Codex Auth 默认值，普通用户的实际模型会随账号目录漂移。需要由管理员从当前模型目录按展示名称选择并保存默认模型，普通用户统一使用该配置，同时保留管理员单次咨询的模型选择权。

## What Changes

- 管理员可从当前 Codex 模型目录按展示名称选择并持久化业务咨询默认模型，配置同时保存实际模型 ID 与展示名称。
- 普通用户新建业务咨询时由服务端强制使用管理员配置的默认模型，忽略客户端模型覆盖。
- 管理员新建咨询时仍可为单次会话选择模型；推理强度、速度、Auth 目录和调度版本维持现有权限规则。
- 已存在的咨询会话继续使用其创建时保存的模型快照，不回写历史数据。

## Capabilities

### New Capabilities

- `business-consult-model-policy`: 约束业务咨询新会话的固定模型及界面可见行为。

### Modified Capabilities

无。

## Impact

- 后端：`tool-fore-consult` 默认模型配置、权限边界、会话创建规则及回归测试。
- 前端：业务咨询默认模型管理、普通用户只读呈现和通用 Codex 配置组件的模型只读能力。
- 新增默认模型读写 API 和模块自有幂等配置表；无历史数据修改或人工迁移。
