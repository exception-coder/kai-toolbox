# 设计

适用OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、AI-01、CTRL-01、IDEM-01，无例外。对象仍为原咨询及附件草稿，拖拽只是新增输入方式，复用原handleFiles、首问会话就绪后上传、追问当前会话上传和既有服务端限制，不新增存储、接口或权限。

ConsultFileDropZone为首问和对话面板提供相同拖入反馈。面板保持原DOM布局与调整宽度能力；历史只读面板未配置onFiles，不启用拖拽。文件跨越窗口子节点时用层级计数保持提示，落下后只处理一次；普通文本和链接保留原行为，不下载远程地址、不遍历文件夹。窗口存在时拦截文件落在页面外部引起的浏览器导航，区域外不上传。暂不可操作时明确提示并保留原消息与草稿，附件超额显示未添加说明，上传失败保留既有恢复方式。

输入区保留键盘和手机文件选择，拖拽不会抢焦点或自动发送。临时高亮不占常驻高度，退出拖拽或窗口失焦后清除。验证覆盖嵌套目标、可用/禁用、外部文件、文本、文件夹、失败与原面板尺寸回归；真实文件管理器拖入需另记录。浏览器契约参照[MDN File drag and drop](https://developer.mozilla.org/en-US/docs/Web/API/HTML_Drag_and_Drop_API/File_drag_and_drop)，2026-10-16查阅。无架构责任或SQL变更，不需要重启服务完成源码与组件验证。
