# 必要设计

## 实现与边界

L3：改变外部默认响应合同，须保护既有任务及幂等。复用 ConsultAnalysisService、应用授权、模型策略和无工具 runner；不新增认证、账号或状态服务。不在 Forge 写 ITCS 分类/发送规则。原则 AI-01、EVID-01、CTRL-01、IDEM-01：对象仍为 clientId/requestId 对应任务，conversationId 仅关联，不新增 UI、键盘或移动交互。

先按调用方输入计算旧规则摘要并查找已有请求，再为新建任务缺省固化 FORGE_FLEX。旧存储输入保持原样；旧 null 模式仍按 CALLER 执行，避免重试或排队任务变更合同。新字段为空时不参与序列化，不改变旧摘要。修改资料/规则/模式须使用新请求号，相同号不同内容继续 409。

businessInstructions 是最多 8000 字符的业务表达/结果约束，仅放数据载荷，不能提升为系统身份、执行授权或工具策略。businessContext 为最多 16000 字符的 JSON，作为 CALLER_BUSINESS_CONTEXT 证据；人工经验不等于现场已核验事实。result.businessResult 是最多 16000 字符对象或 null，由调用方规则指导生成，Forge 只做边界验证，不声称校验任意调用方 JSON Schema。调用方仍须验证其业务字段。

FORGE_FLEX 结果 schemaVersion=1.2，replyCandidates 0–8 条，稳定 reply-N；空数组必须转人工并给非空真实原因。显式 FORGE 保留三条和 1.1，CALLER 保留旧合同。认证开关、票据、租户与项目授权、附件所有权、模型选择均不变，不轮换凭据、不自动开放未经授权的实例。

## 风险与验证

沿用后端集成测试覆盖既有凭据、租户隔离、旧请求摘要和恢复，补默认新版、规则/人工证据进入无工具模型载荷、0/1/多条候选、重复与伪造证据拒绝。SDK 覆盖业务字段原样传输及结果保存。所有模型测试使用替身；构建和测试不证明部署或真实回复效果。

目标域名与本机域名不同，不能通过改本机隧道冒充线上升级。源码可独立交付，目标实例加载、真实任务与稳定观察待确认目标及当次重启授权后执行。失败结果保留任务和来源，重试按既有合同，不自动重发未知请求。
