# 设计

- OBJ-01 / NAV-01：对象沿用当前会话或项目选择的仓库，筛选位于共享待提交弹窗，不增加导航或项目清单。
- CTX-01 / IDEM-01：默认不筛选，勾选仅在已读取的状态上投影；刷新保留勾选及仓库选择，不触发 Git 写操作。
- FEED-01 / EVID-01：后端使用 `git check-ignore --no-index -z --stdin` 判定当前路径，沿用 Git 的嵌套、反向、仓库排除及全局忽略规则。没有匹配的退出码 1 为正常结果；其他错误和截断不伪造成功。旧服务缺少匹配数据时禁用筛选并显示不可用说明。
- DENS-01：树和统计使用同一筛选结果，显示隐藏数量。全部被隐藏时明确为筛选空态，不宣称工作区干净。
- CTRL-01：仅隐藏显示，不修改 `.gitignore`、文件、暂存区、提交或推送行为。Checkbox 原生支持键盘和触屏，窄屏筛选栏换行。无产品原则例外。

Git 查询保留 normal 未跟踪目录合并模式，使用 NUL 分隔保留空格、中文、箭头及重命名原路径。Git 已忽略的未跟踪文件仍由 status 默认排除，不额外枚举产物。共用查询的 JSON 增加 `ignoredPaths`，已有 `entries` 契约保持兼容；变更记录的基线采集不应用此显示筛选。无 AI 编程架构契约变化。

验证限于真实临时 Git 仓库的规则匹配及精确路径、弹窗筛选与恢复；只执行相关测试和类型检查。运行加载及浏览器现场验收需新版后端，未授权重启时单列未覆盖项。
