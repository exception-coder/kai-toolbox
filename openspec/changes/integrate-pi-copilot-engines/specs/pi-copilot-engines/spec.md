## ADDED Requirements

### Requirement: Pi 与 Copilot 独立会话执行

系统 SHALL 提供 Pi 与 Copilot 引擎及模型选择，使用会话级服务商凭据，不覆盖本机默认配置。系统 MUST 保留原生会话身份并继承 Forge 权限边界。

#### Scenario: 执行与恢复
- **WHEN** 用户选择可用引擎并发送消息或恢复会话
- **THEN** 系统使用该引擎流式显示文本和工具反馈并复用原生会话

#### Scenario: 模型与凭据隔离
- **WHEN** 用户配置第三方服务商或切换模型
- **THEN** 系统仅更新目标会话，不使用其他引擎模型或修改本机全局配置

#### Scenario: 执行失败
- **WHEN** 依赖、认证、权限或执行失败
- **THEN** 系统报告可恢复错误，不回退其他引擎、不标记成功

#### Scenario: 中断与重复恢复
- **WHEN** 用户中断当前轮或重复恢复会话
- **THEN** 系统终止目标轮并释放监听；恢复复用原生身份，不重复创建或重放消息
