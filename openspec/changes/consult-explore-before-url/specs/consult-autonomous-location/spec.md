## ADDED Requirements

### Requirement: URL 缺失不阻止自主定位

系统 SHALL 将 URL 视为可选线索，在询问用户前先使用本轮已授权能力定位；不得将菜单知识未命中等同于无法定位。

#### Scenario: 截图与问题没有 URL

- **WHEN** 用户提供截图、页面文案或业务标识，但没有 URL
- **THEN** 先利用系统与模块上下文查询知识，必要时查询 Graphify 并精确读取候选源码
- **AND** 不因菜单知识未命中直接要求补地址，不进行无范围全仓扫描

#### Scenario: 探索后仍无法确认页面

- **WHEN** 已核对可用证据仍有关键歧义，或定位工具不可用且线索不足
- **THEN** 简述已核对内容与剩余问题，请用户补充页面 URL 等最少信息
- **AND** 不猜测唯一页面或具体单据根因，不扩大系统或数据权限

#### Scenario: 已发布或历史流程继续咨询

- **WHEN** 新咨询使用已发布流程，或历史咨询发起后续追问
- **THEN** 共用调度提示词仍包含自主定位与必要追问规则，原流程快照保持不变
