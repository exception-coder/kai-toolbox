## ADDED Requirements

### Requirement: 独立助理会话
系统 SHALL 为当前用户保存助理会话和绑定的 Skill 快照，复用平台引擎且不切换编码会话。

#### Scenario: 重复唤醒
- **WHEN** 用户连续点击同一机器人或重新进入
- **THEN** 复用最近会话，恢复草稿与任务状态，不重复执行；显式新任务创建独立会话

#### Scenario: 跨用户与并发
- **WHEN** 请求其他用户会话，或在同一会话运行时提交不同任务
- **THEN** 服务端拒绝；相同请求 ID 返回已有任务

### Requirement: 周报事实受控
系统 SHALL 仅从获准的目录与明确时间、作者收集 Git 事实，关闭模型工具执行。

#### Scenario: 越界或超量
- **WHEN** 项目被排除、范围超限或 Git 输出截断
- **THEN** 明确失败并要求修正范围，不生成貌似完整的周报

### Requirement: 安全资源登记
系统 SHALL 通过专用表单预览并确认登记原资源，不把密码交给模型或会话存储。

#### Scenario: 确认与重复
- **WHEN** 管理员核对目标后确认保存并重试同一请求
- **THEN** 只创建一次记录，返回资源 ID 与原管理入口；新写入凭据加密保存

### Requirement: 常驻与可恢复交互
系统 SHALL 提供机器人首页、跨页入口及按需语音转写，关闭面板不取消任务。

#### Scenario: 语音或失败
- **WHEN** 用户转写语音或任务失败
- **THEN** 转写先回填草稿，任务失败保留输入与明确恢复入口，不自动发送或重复写入

#### Scenario: 移动与收起入口
- **WHEN** 用户拖动浮动入口、将其拖到左右边缘或点击收起
- **THEN** 入口可移动并贴边收起，拖动不会打开助理；收起后可点击展开或拖出，取消拖动回原位，不修改会话和任务

#### Scenario: 移动端与本地偏好恢复
- **WHEN** 同一用户再次进入，或软键盘、缩放和屏幕尺寸改变可视区域
- **THEN** 在本浏览器恢复该用户的位置与收起状态，入口保持在可见安全区域内；存储损坏或不可用不阻断操作，键盘可移动、收起及恢复默认位置
