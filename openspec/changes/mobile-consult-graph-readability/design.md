# 手机图谱展示设计

## 范围与原则

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、IDEM-01，无例外。对象仍为配置中可见系统的稳定 `name`，复用原有显示清单、拓扑及分类；手机展示层不创建项目或咨询，不请求另一套数据。

## 页面与状态

保留咨询／系统图谱页签。手机首个有效对象为完整系统网络；顶部60px分类／关系数量／定位入口，其余空间由画布持有，底部不再常驻大图例。数据加载、错误重试、无系统与无分类结果均有明确反馈。底部关系区为非模态对象详情，不阻断背景图谱操作，无额外遮罩；关系区独立限高滚动，关闭恢复节点焦点，不移动或重置图谱。无需新增业务页面、数据库或任务状态。

## 布局与手势

逻辑像素环形分布，系统圆64px、下方名称最多两行，Forge为中间文字锚点，不伪造其系统调用关系。计算包含节点和标签的边界，按实际画布拟合，四周20px留边；初始最大缩放为1以保留64px节点。ResizeObserver读取实际可见区域，默认适配；手动平移／缩放后保留用户视角，定位全图清除手动视角并恢复自动适配。切换页签不卸载手机图谱，避免丢失位置。分类沿用父页面状态，更换分类明确恢复全图。相对位置仅表达布局，不代表重要性或业务层级。

移动端不绘制常驻边标签。选中节点仅强化直接关系及邻居，不改筛选范围，详情显示方向与关系类型；点击边进入其起点的关联详情。不添加不可信拓扑。节点点击只选中；“咨询此系统”才通过现有咨询草稿和系统标记逻辑切回咨询，保留原咨询与输入，不直接发送或创建第二条会话。重复选择／关闭只更新本地展示，不产生写请求。

触控使用 Pointer Events，缓存指针并处理取消／捕获丢失；`touch-action: none`仅限图谱手势区，其他页面保留浏览器默认行为。支持双指中点锚定缩放及单指平移，移过阈值后不触发节点点击。提供44px缩放按钮与定位恢复入口；键盘方向键平移、加减缩放、Escape关闭、原生select筛选。参考[MDN Pointer Events示例](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events/Pinch_zoom_gestures)（2026-10-22核对），不引入额外图谱库或改变桌面实现。

## 验证与边界

定向验证适配安全边距、缩放锚点与极值、关系按需展示、节点弱化、关闭保留视角及焦点、加载失败与重试、原页面显示范围和会话恢复。浏览器验证390px手机与桌面，检查节点和横向溢出。真机双指触控另行验收，不用桌面模拟宣称真机通过。无整体AI编程架构职责或执行生命周期变化。
