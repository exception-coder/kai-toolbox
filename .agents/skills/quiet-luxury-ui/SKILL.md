# Quiet Luxury Enterprise UI

视觉方向：Swiss editorial layout + Apple HIG hierarchy + Linear-level restraint + Vercel-level precision。用层级、对齐和阅读密度建立品质，而不是增加装饰容器。

## 先复用项目能力

- 导航与操作设计先读 [产品哲学](../../../docs/product-philosophy.md)，保持对象身份、反馈和返回上下文。
- 查找 `frontend/src/components/ui/` 与相邻业务组件，优先复用已有布局、表单、弹层和图标模式；不要为同一操作重新设计一套控件。
- 基础视觉读取 `frontend/src/index.css`；工作台主题使用 `frontend/src/features/claude-chat/lib/workbenchTheme.ts`、`artisticSkins.ts` 及 `styles/workbench-theme.css`、`immersive-skins.css`。颜色、边界、圆角、阴影与材质由适用 Token 决定，不在业务组件硬编码另一套主题。

## 信息与操作

- 页面采用 Page → Section → Content，避免每块内容套卡片或嵌套多重边框。标题、辅助信息和主要动作层级清楚。
- 数据、表单采用自然阅读顺序和稳定对齐。搜索控件与同行按钮对齐控件本体，不能因标签高度错位；数据区域优先获得剩余空间。
- 高频操作直接可见，低频操作按需展开；相同目的入口优先收敛。移动端不靠缩小触控区换空间。
- 反馈体现 Context → State → Explanation → Recovery Action。空、错、加载、成功等状态按实际工作流提供，不机械生成不适用状态。
- 错误提供可执行的恢复路径；覆盖层关闭恢复焦点，保留草稿、筛选、列表位置和对象上下文。

## 视觉语言与艺术皮肤

- 默认业务界面保持中性底色、少量功能强调、清楚文字阶梯、细边界和克制阴影。避免无意义渐变、霓虹、巨型状态图标、所有内容居中或所有按钮胶囊化。
- 已确认的艺术皮肤可使用纸张、终端、玻璃、金属等独特材质和组件表面。上述默认方向不覆盖皮肤 Token，也不要求固定色值、固定圆角或强制纯色。
- 材质不能削弱正文、代码、按钮和焦点对比；正文纹理弱化，装饰不接管点击。主题切换保持尺寸、触控区域、语义、草稿与任务状态。
- 保持统一 Lucide 图标语言；不用 Emoji 替代产品操作图标。辅助文本仍应清晰可读，不能为了层级把文字变成不可辨认的浅灰。
- 动效只服务状态过渡，尊重减少动效设置，避免持续高成本滤镜；复用现有过渡 Token。

## 交付核对

按实际改动验证桌面与移动断点、键盘焦点、触控范围、长文本和放大字体。主题相关修改检查适用的浅色、深色及艺术皮肤。浏览器未运行、真实设备未验证须明确说明；不要以截图生成或构建通过代替交互验收。
