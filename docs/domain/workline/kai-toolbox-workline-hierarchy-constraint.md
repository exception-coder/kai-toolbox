## 业务定义

一条工作线下的工作条目分两类：

- **顶层摘要条目**：没有父条目，代表相对完整、独立的一次工作记录；
- **明细子条目**：挂在某个顶层摘要条目下，是该工作单元内部更细粒度的补充记录。

层级约束（创建条目时校验）：

- 新建条目若不指定父条目，直接作为顶层摘要条目创建，不受此约束限制；
- 新建条目若指定了父条目，则该父条目必须本身是"顶层摘要条目"（即父条目自己没有父条目）——若父条目本身已经是一个明细子条目，创建请求会被拒绝；
- 效果是：层级最多两级（工作线 → 顶层摘要条目 → 明细子条目），不存在三级及以上嵌套。
- 附加约束：父条目必须与新条目属于同一条工作线，跨工作线挂靠会被拒绝。

## 适用范围 / 边界

- 该约束只发生在"新建条目并指定父条目"的时刻，是创建时的一次性校验，不是持续性约束（后续条目的归属关系不会被再次巡检）。
- 只限制层级深度（两级），不限制同一层级下的条目数量——一条顶层摘要条目下可以挂任意多个明细子条目。
- 仅约束单条工作线内部的条目组织，不同工作线之间的条目层级互不影响。
