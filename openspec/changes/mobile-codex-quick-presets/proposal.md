# 移动端 Codex 模型组合快捷选择

## Why
手机模型入口仅打开完整配置，常用模型与思考强度组合需要多次点选。用户要求参考提供的 Codex 移动截图，以离散滑动档位快捷选择，并保留自定义。

## What Changes
- 手机官方 Codex 的现有配置入口优先打开组合滑杆；显示当前模型与思考强度。
- 从当前模型目录投影常用 Luna / Sol / Astra 组合，过滤未明确支持的档位。
- 拖动预览、松手应用，支持点选及键盘；自定义在同一抽屉中直接选择模型、思考强度及其他参数。
- 桌面、其他引擎及第三方服务商继续使用原完整配置。

## Impact
仅 claude-chat 前端，复用模型目录和现有 setModel / setCodexOptions 会话配置能力，不新增后端、Sidecar 协议、偏好存储或引擎执行。
