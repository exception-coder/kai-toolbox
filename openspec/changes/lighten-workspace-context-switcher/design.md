# 设计

Page Anatomy：48px 手机 Header（导航 / 当前会话标题 / 状态点 / 更多）→ 原消息流 → 原 Dock / Composer。标题浮层只负责上下文；更多中的“工作视图”默认折叠，按需显示平级视图列表。没有常驻第二行导航，也没有弹框中的分段页签或第二层模式菜单。

适用 OBJ-01、NAV-01、CTX-01、DENS-01、FEED-01、EVID-01、IDEM-01，无例外。

- 主对象仍是现有 session ID；标题不复制项目或会话清单，“切换工作空间”打开原 SessionList。引擎状态读取原 ChatRuntimeContext。
- 有界上下文选择适合覆盖层；页面目的地由更多持有。MobileSessionViews 与桌面复用 viewOptions，原 SessionView 状态持有视图。展开工作视图仅增加一次按需展开动作，避免在标题弹框堆积导航。
- 模式直接复用 ChatControlModePicker 与原授权逻辑；当前项只关闭，不重复导航。切换通道保留路由 session ID / 查询参数以及已访问的 LLM 草稿。无权限项禁用并说明原因。
- 标题浮层复用 Radix Popover，Esc、外部点击、选择或进入桌面宽度关闭；原触发器恢复焦点；转入会话抽屉时显式交接标题触发器，抽屉关闭后回到该标题。切换通道后聚焦新通道的可见模式入口。没有新增请求或失败协议；数据加载与失败仍由原会话列表和视图处理。
- 浮层宽 320px，最大宽为视口减 32px，16px 外层圆角、弱阴影、主题底色；标题完整折行。模式行至少 56px，其他按钮至少 44px，选中项使用浅品牌底色、左边线与勾选。内容限高并独立滚动，短屏末项可达。
- 桌面模式菜单及页签不变；原“视图”显示选项组改名“显示设置”，与工作视图区分。

复用本会话已核对的 [WAI Disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) 交互参考（2026-10-14），不引入新的库或外部设计系统。验证限制：浏览器组件页面证明呈现与交互，不证明真实会话服务数据；实际登录后页面和真实华为设备分别待验收。

## 最终导航组合

本变更与 `organize-session-tools-menu` 一起组成最终导航闭环：原 MobileSessionViews 由 SessionWorkViews 实现并继续复用 viewOptions；工作视图入口归入「工作与进度」，阅读与外观归入「阅读与显示」。工具分类在同一浮层进入与返回，取代最初的工作视图折叠方式；标题仍只负责上下文与模式切换。共用 ChatPage 的视图、草稿和焦点交接，作为一个完整导航单元提交。真实登录 Chrome 的菜单导航已按手机、短屏与桌面验证；标题及模式的真实数据操作、物理设备验收仍保持原限制。
