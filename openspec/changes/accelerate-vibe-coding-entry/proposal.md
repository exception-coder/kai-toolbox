# 加快 Vibe Coding 首屏与最近会话恢复

## 原因

手机通过外网进入时，页面代码下载与最近会话列表查询串行呈现为“准备工作台”及空会话。聊天记录加载也与会话框架混在同一等待体验中。

## 方案

在会话深链的 HTML 阶段提前请求会话路由代码，使其与主应用同时下载；非 Mock 模式不加载六个 Mock 模块；低频面板按需下载。最近已确认会话的 ID 作为本机恢复提示，先发起切换，随后用服务端会话列表核验并更新。消息记录继续单独异步加载。提示只存 ID，不存聊天内容，也不取代服务端鉴权。

2026-10-20 补齐大 Codex 历史首屏：普通会话通过兼容的可选字节游标从文件尾部读取完整轮次，不等待整份文件索引。累计用量和评审边界仍走原职责；超长单轮明确提供完整历史兼容读取，不增加新的缓存服务或数据库。

2026-10-31 普通已登记编程会话按服务端会话身份读取最近页，与连接并行，先到的历史先显示；保留现有鉴权、缓存隔离、失败重试和其他通道。配合已有生产静态资源模式减少开发模块网络往返；首次切换、运行及公网手机性能待本次重启确认后核验。
